# Ph01 · 词法分析（Lexer）

> 源码对照：[`tenet-rs/src/lexer.rs`](../../tenet-rs/src/lexer.rs) · [`tenet-rs/src/token.rs`](../../tenet-rs/src/token.rs)
> 测试对照：`tenet-rs/src/lexer.rs` 末尾的 `#[cfg(test)] mod tests`

## 1. 概述

**词法分析（Lexing / Tokenizing）** 是语言管线的第一步：把原始源码字符串
切成一个个有意义的**词法单元（Token）**。它是"字符的世界"与"语法的世界"
之间的边界——从此往后，语法分析器只和 Token 打交道，不再关心字符。

```
"let x: int = 42;"
   │  Lexer
   ▼
[Let] [Ident("x")] [Colon] [IntType] [Assign] [Int(42)] [Semi] [Eof]
```

## 2. Token 的设计

Tenet 的 Token 由两部分组成（见 `token.rs`）：

| 部分 | 作用 | 例子 |
|------|------|------|
| `kind` | 种类 + 字面量载荷 | `Int(42)`、`Ident("x")`、`Let`、`Eq` |
| `pos`  | 行列位置（用于报错） | `Position { line: 1, col: 9 }` |

**为什么 Token 要带位置？** 没有位置的 Token 流在报错时只能说"这里有错"，
有了位置才能说"第 3 行第 5 列"。Tenet 的 `TenetError` 统一携带
`[行:列]`，从词法到代码生成全程可定位。

## 3. 词法规则

### 3.1 字面量

```rust
// 整数：连续数字
42        → Int(42)

// 浮点：小数点后不要求必须有数字（Go 风格）
3.14      → Float(3.14)
3.        → Float(3.0)      // 注意！不是 Int(3)

// 字符串：双引号包裹，支持转义
"a\nb"    → Str("a\nb")     // \n \t \" \\ 四种转义
```

### 3.2 标识符与关键字

标识符以字母或 `_` 开头，后续可以是字母、数字、`_`：

```rust
let x2 = 1;   // x2 是标识符
let 2x = 1;   // 词法错误！数字开头不是标识符
```

识别关键字是**查表**：先按标识符读完整串，再查是否命中关键字表。

```rust
"let" → Let        "fn" → Fn        "int" → IntType
"if"  → If         "while" → While  "true" → True
```

### 3.3 运算符：最长匹配

多字符运算符必须**贪心匹配**：读 `=` 时要看下一个字符是不是 `=`。

```rust
=   → Assign       == → Eq          != → NotEq
<   → Lt           <= → LtEq        -> → Arrow
&   → ???          && → And         || → Or
```

单个 `&` 不在 Tenet 的字符集里——直接报"无法识别的字符"。
这正是"最长匹配"的意义：`==` 绝不会被拆成两个 `=`。

### 3.4 注释与空白

```rust
let x = 1;  // 行注释：读到换行结束
/* 块注释：可以
   跨行 */  let y = 2;
```

空白（空格、制表、换行、回车）全部跳过，注释等价于空白。
注意：**换行不是语句分隔符**——Tenet 用 `;` 分隔语句（C 风格），
所以词法器跳过换行时还会更新行列号。

## 4. 错误处理

```text
输入:  let x = "abc
输出:  [1:9] 未闭合的字符串字面量

输入:  1 @ 2
输出:  [1:3] 无法识别的字符 `@`
```

词法错误是**立即失败**的：遇到非法字符就返回 `Err`，不尝试恢复。
这是教学语言的合理取舍——错误恢复是编译器工程里很后面的主题。

## 5. 必会概念清单

1. **Token = 种类 + 位置**：位置让全链路报错可定位
2. **最长匹配**：`==`、`&&`、`->` 不会被拆散
3. **关键字查表**：标识符读完整串后再判断是否关键字
4. **转义发生在词法层**：`\n` 在词法阶段就变成真正的换行符
5. **`.`, 的边界**：`3.` 是浮点，`3` 是整数，二者语义不同
