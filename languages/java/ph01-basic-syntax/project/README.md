# ph01 阶段项目：成绩统计工具

## 需求

对应 Roadmap「Java 基础语法阶段」推荐项目之一。实现一个命令行成绩统计工具：录入若干个 0~100 的成绩，统计人数、平均分、最高分、最低分和各等级（A/B/C/D/F）分布。

## 功能清单

- [ ] 询问录入成绩个数，逐个读入成绩（`Scanner`）
- [ ] 校验成绩范围 0~100，非法成绩要求重新输入
- [ ] 统计人数、平均分（保留两位小数）、最高分、最低分
- [ ] 统计等级分布：A（90~100）、B（80~89）、C（70~79）、D（60~69）、F（0~59）
- [ ] 以清晰格式输出全部统计结果

## 验收标准

- `javac GradeStats.java` 编译通过，`java GradeStats` 可运行
- 录入 5 个成绩 `90 85 78 62 55`，输出人数 5、平均分 74.00、最高 90、最低 55
- 上述样例的等级分布为：A=1、B=1、C=1、D=1、F=1
- 输入超出 0~100 的成绩（如 `-5`、`120`）会被拒绝并要求重新输入，程序不崩溃
- 平均分用浮点计算，不发生整数除法截断

## 扩展方向（可选）

- 用 `ArrayList` 替代定长数组，去掉"先问个数"的限制 —— 属于 ph04 集合框架阶段
- 从文件批量读取成绩 —— 属于 ph07 IO 与文件操作阶段
- 把统计逻辑拆成独立的方法/类 —— 属于 ph02 面向对象 OOP 阶段

## 验证环境

OpenJDK 17.0.16（建议 JDK 17+）。编译：`javac GradeStats.java`；运行：`java GradeStats`。已在本环境编译运行验证（样例 5 个成绩 `90 85 78 62 55` 输出平均 74.00、最高 90、最低 55，等级分布 A=1 B=1 C=1 D=1 F=1）。
