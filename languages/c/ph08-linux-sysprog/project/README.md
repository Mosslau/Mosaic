# ph08 阶段项目：多线程任务队列

对应 roadmap ph08 推荐项目第二个「多线程任务队列」：生产者-消费者模型，mutex + condvar 实现环形缓冲，支持多生产者多消费者与优雅关闭，可扩展为日志采集器。

## 需求

实现一个通用的有界任务队列（`task_queue.h` / `task_queue.c`），配一个演示程序（`main.c`）：多个生产者线程提交「区间求和」任务，多个工作线程消费执行，汇总结果并校验正确性。

## 功能清单

- [x] 通用任务抽象：一个任务 = 函数指针 + 参数（`task_t`），队列本身不关心任务内容
- [x] 有界环形缓冲：队列满时生产者阻塞等待，空时消费者阻塞等待
- [x] 多生产者多消费者：共享读写全部持锁，等待一律 `while` 重查（防虚假唤醒）
- [x] 优雅关闭：`tq_close` 后拒绝新任务，已入队任务消费完，消费者自动退出
- [x] Makefile 增量构建：`CC`/`CFLAGS`/`OBJS` 变量分离，改一个 `.c` 只重编它

## 验收标准
