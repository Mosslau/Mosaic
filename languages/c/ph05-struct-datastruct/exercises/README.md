# exercises —— 结构体与数据结构阶段练习

完成顺序建议：按 1~4 顺序完成。参考实现在 `sol-*` 文件中，做完再看。

## 练习 1：单链表增删改查

- **目标**：实现单链表（`int` 数据），支持头插/尾插/删除/查找
- **要求**：
  - 插入/删除用**二级指针** `Node **head`（修改头节点本身）
  - `node_create` 检查 malloc 失败
  - 完整释放：`list_destroy` 遍历 free 并置 NULL
- **验收**：`-Wall -Wextra` 零警告；头插 10/20/30、尾插 40、删除 20 后打印 `10 -> 30 -> 40`；销毁后 head 为 NULL

## 练习 2：数组栈实现括号匹配

- **目标**：用数组栈判断括号字符串是否匹配（`()[]{}` 三种）
- **要求**：
  - 栈容量 256，`push`/`pop` 检查满/空
  - 闭合括号必须与栈顶开口括号类型一致
  - 结束时栈必须为空
- **验收**：`"()"`、`"([]){}"` 匹配；`"([)]"`、`"((())"`、`"(]"` 不匹配

## 练习 3：队列模拟任务调度

- **目标**：链表队列 FIFO 调度，打印每个任务的入队/出队时间戳
- **要求**：
  - `head`+`tail` 双指针，入队 O(1)
  - 出队时队列变空要同步置 `tail = NULL`
  - 每个任务记录入队序号，出队时打印 `T<序号> 入队@<n> 出队@<m>`
- **验收**：入队 T0~T4，出队顺序 T0~T4；队列空时 `dequeue` 返回 -1

## 练习 4：哈希表统计词频

- **目标**：链地址法哈希表统计一段文本中单词出现次数
- **要求**：
  - 用 djb2 哈希（`hash * 33 + c`）或文档示例的 5381 变体
  - 表中存储**动态分配 key**（`malloc+strcpy`），不依赖输入字符串生命周期
  - 销毁时先 `free(key)` 再 `free(node)`
- **验收**：统计 `"hello world hello c world hello data"` 得 hello:3、world:2、c:1、data:1；销毁后无泄漏
