# ph01 基础语法 练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。
> 验证环境：Apple clang 17.0.0（gcc 兼容），标准 C99。编译统一加 `-Wall -Wextra -std=c99`。

## 练习 1：计算器（★）

**目标**：写一个支持四则运算的命令行计算器。
**要求**：读入形如 `3 + 4` 的算式（操作数 运算符 操作数），输出结果；除零时给出错误提示；不支持的运算符给出提示。
**验收**：输入 `3 + 4` 输出 `7.00`；输入 `1 / 0` 输出除零错误；输入 `5 ^ 2` 提示不支持。

## 练习 2：九九乘法表（★）

**目标**：打印标准九九乘法表。
**要求**：用嵌套循环；每行只打到行号（如第 3 行打 `1×3 2×3 3×3`）；乘积左对齐占两位。
**验收**：输出 9 行，最后一行以 `1×9=9` 开头、`9×9=81` 结尾。

## 练习 3：判断素数（★★）

**目标**：打印 1~100 内全部素数。
**要求**：把判断逻辑写成 `is_prime(int n)` 函数；只需试除到 √n。
**验收**：输出以 `2 3 5 7 11` 开头，共 25 个素数，最后一个是 `97`。

## 练习 4：数组最大值、最小值、平均值（★★）

**目标**：对一组成绩求最大值、最小值、平均值。
**要求**：成绩用数组存储（如 `{78, 92, 85, 63, 99, 71}`）；用一次循环同时求出三个值；平均值保留两位小数。
**验收**：输出人数、平均、最高、最低四项；对样例数组，平均约 `81.33`，最高 `99`，最低 `63`。
