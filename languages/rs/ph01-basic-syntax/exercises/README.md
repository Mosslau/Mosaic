# ph01 基础语法 练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。
> 验证环境：rustc 1.92.0，单文件直接用 `rustc sol-XX-*.rs -o solXX` 编译。
> 本阶段只用 std 标准库，不引入第三方 crate。

## 练习 1：Hello Rust（★）

**目标**：写出并运行第一个 Rust 程序，体会「表达式有值」。

**要求**：

- 打印 `Hello, Rust!`
- 用 `let` 绑定一个名字变量，用 `println!` 的 `{}` 占位符打印问候
- 加分项：用 `if <条件> { "a" } else { "b" }` 表达式绑定一个字符串并打印，体会 if 是表达式

**验收**：编译零警告；运行输出包含 `Hello, Rust!` 和对你名字的问候。

## 练习 2：温度转换器（★）

**目标**：写函数完成摄氏/华氏互转，练习「函数最后一行是返回值」。

**要求**：

- 写 `celsius_to_fahrenheit(c: f64) -> f64` 和 `fahrenheit_to_celsius(f: f64) -> f64` 两个函数
- 函数体最后一行不写分号（表达式返回）
- 用 match 根据模式字符（`'C'` / `'F'`）选择转换方向

**验收**：编译零警告；`0°C → 32.0°F`、`100°C → 212.0°F`、`98.6°F → 37.0°C` 均正确。

## 练习 3：猜数字游戏（★★）

**目标**：综合运用 loop、match、输入解析，写一个交互小游戏。

**要求**：

- 答案固定为某个 1~100 的数（随机数属于后续阶段，本阶段固定即可）
- 循环读入猜测，提示「太小！」「太大！」，猜中后退出
- 输入非数字时提示「请输入数字」并继续，**不允许 panic**（不许用 `unwrap`/`expect` 处理解析失败）

**验收**：编译零警告；输入正确答案输出「猜对了！」；输入 `abc` 不崩溃并提示重新输入。

## 练习 4：if-else 改 match（★★）

**目标**：把一串 if-else 分支改写成 match，体会 match 的穷尽检查。

**要求**：给定成绩分数（0~100），先写出 if-else 版本输出等级（90 以上 A、80~89 B、70~79 C、其余 F），再改写成 match 版本（用范围模式 `90..=100`）。

**验收**：两个版本对 95、85、75、60 输出一致（A、B、C、F）；match 版本编译零警告。

## 练习 5：命令行计算器（★★★）

**目标**：写一个循环读入算式的计算器，为阶段项目做铺垫。

**要求**：

- 循环读入形如 `3 + 4` 的一行（操作数 运算符 操作数），输出结果保留两位小数
- 支持 `+ - * /`；除零输出错误提示而不崩溃；不支持的运算符给出提示
- 输入 `q` 退出；输入格式错误提示后可以继续

**验收**：编译零警告；`3 + 4` 输出 `7.00`；`1 / 0` 提示除零且程序继续；`5 ^ 2` 提示不支持；`q` 正常退出。
