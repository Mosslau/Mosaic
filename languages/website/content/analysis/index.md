# 语言设计分析

学习笔记回答「这门语言有什么、怎么学」，分析笔记回答另一个问题：**它为什么这么设计，
代价是什么**。四张分析台覆盖 Rust、C++、Java、Python，每篇主题配一个可直接运行的 demo，
结论汇总到 [Tenet 架构设计](/tenet/Tenet架构设计) 作为语言设计的输入。

每篇笔记的结构一致：设计动机 → 机制拆解 → 代码验证 → 代价与取舍 → 对 Tenet 的启示。
如果只想知道结论，读最后一节；想自己验证，跑一遍对应的 demo。
