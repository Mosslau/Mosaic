# 六门语言

六条系统化的学习路线，每门都从语言基础讲到工程实践。每条路线由一篇 Roadmap 统领，
拆成若干编号阶段；每个阶段都有独立的展开文档，以及配套的示例、练习和阶段项目代码。

阶段文档的结构是固定的：来源与演变、语法与参数、底层原理、代码示例、总结验收。
按顺序读即可，也可以直接从兴趣所在的阶段切入。

## 怎么用这套笔记

先读某门语言的 Roadmap（每张卡片进入后的第一项），了解它分几个阶段、每阶段解决什么问题；
再逐阶段读展开文档。阶段文档里会链到本阶段的 `examples/`、`exercises/`、`project/`，
代码与文档是配套的——练习题先自己做，再对着参考实现复盘。

读完一门语言，可以去 [语言设计分析](/analysis/) 看它**为什么**这么设计，
再到 [Tenet](/tenet/) 看这些设计如何被吸收进一门自造语言。
