# exercises —— 自动化脚本阶段练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。与 roadmap「练习」小节一一对应：批量整理日志、生成 Excel 报表、定时拉取接口、解析 CAN 日志。

完成顺序建议：按 1~4 顺序完成（逐步叠加：文件批处理 → 报表生成 → 接口 + 定时 → 正则解析 + 统计）。

## 依赖与验证方式

- 依赖：练习 1、4 只用**标准库**（零安装）；练习 2 需要 `pip install openpyxl`（本环境 3.1.5 已装）；练习 3 需要 `pip install requests`（本环境 2.32.5 已装）
- 运行：`python3 sol-XX-*.py` 直接运行即自检（脚本内跑完整链路并打印结果）
- 产物纪律：sol 里所有样本文件、报表（`.csv`/`.xlsx`）、日志一律写到**系统临时目录**（`tempfile.mkdtemp`），HTTP 服务起在进程内线程、结束 `shutdown()` 干净关闭——运行后当前目录不得残留任何文件（`git status` 确认工作区干净）
- 参考实现文件头带**验证块**：环境、运行命令、实测输出（数字为本机实际运行结果）

## 练习 1：批量整理日志（★）

- **目标**：用 pathlib 批量整理日志目录：按文件名日期归档旧日志、清理临时文件，可安全重跑
- **要求**：
  - 造样本：`logs/` 下 4 个 `app-YYYY-MM-DD.log`（2 旧 2 新）+ 2 个 `*.tmp` 临时文件
  - 用正则从文件名提取日期，把「早于 cutoff（如 2026-09-01）的日志」移动到 `archive/`，删除 `*.tmp`
  - 每个动作写一行**审计日志**（`logging`）；最后生成 `report.csv`（logs / archive 两个位置的日志数与总字节）
  - **幂等**：同一批文件再跑一遍，移动与删除都应为 0——脚本必须能安全重跑
- **验收**：整理前统计正确（文件数、日志总字节）；归档/删除数量正确；再次运行全 0；审计日志行数 = 动作数；`report.csv` 数值与实测一致

## 练习 2：生成 Excel 报表（★★）

- **目标**：从 CSV 原始数据生成多 Sheet 的 Excel 报表（openpyxl）
- **要求**：
  - 造 CSV 输入：车辆遥测数据（时间、车辆、速度、电量，3 车 × 4 条 = 12 行）
  - 生成 xlsx：Sheet1「原始数据」全量 12 行；Sheet2「汇总」按车辆分组（记录数 / 平均速度 / 平均电量，`round(..., 2)`）
  - 表头加粗 + 底色；**用 `load_workbook` 重新打开核对**关键单元格再打印（数字可审计）
- **验收**：xlsx 两个 Sheet 的行列数正确；汇总行数字与手算一致（提示：EV-001 平均速度 = (52+58+55+60)/4）；重开核对单元格值正确

## 练习 3：定时拉取接口（★★）

- **目标**：轮询式「定时」拉取本地接口，带超时、重试与错误日志（requests + http.server）
- **要求**：
  - 进程内起临时 HTTP 服务（随机端口）：`GET /api/telemetry` 返回 JSON（车辆/速度）、`GET /api/error` 返回 500
  - `fetch_with_retry(url, retries=1)`：`timeout=2` + `raise_for_status()`，失败记 `errors.log` 并重试 1 次，仍失败返回 `None`
  - 主循环 3 轮（`time.sleep(1)` 模拟定时——理解这与 schedule 库的 `run_pending()` 是同一思想，见主文档 3.7），成功则把带时间戳的记录**追加**写入 `telemetry.csv`
  - 3 轮之后调用一次 `/api/error`，验证错误处理路径
- **验收**：`telemetry.csv` 4 行（含表头）、3 行数据；`errors.log` 恰好 2 条（500 首次失败 + 重试仍失败）；服务结束干净关闭；能说清「为什么轮询 + sleep 就是定时任务的最小实现」

## 练习 4：解析 CAN 日志（★★★）

- **目标**：用正则解析 candump 风格 CAN 日志，按 ID 统计信号值并输出 CSV 报表（格式规约解析的入门样本）
- **要求**：
  - 造样本：12 条有效帧 `(秒.微秒) can0 ID#负载HEX`（3 个 ID：0x123 车速、0x245 电池电压、0x301 电机温度，首字节即信号值）+ 1 条乱行
  - 正则逐行解析（ID 转 int、负载 `bytes.fromhex`），无效行计数
  - 按 ID 统计：条数 / 首字节 min / max / avg（`round(..., 2)`）；支持按 ID 过滤；输出 `can_report.csv`（含表头）
- **验收**：有效 12 条、无效 1 条；每个 ID 的条数与 min/max/avg 正确（提示：0x123 的 6 个值为 30, 40, 52, 44, 60, 42）；过滤 0x123 得 6 条；CSV 报表 4 行（含表头）
