# ph01 阶段项目：成绩等级判断工具

## 需求

对应 Roadmap「ph01 基础语法阶段」推荐项目第一个「成绩等级判断工具」。实现一个命令行工具：支持两种模式——单条查询（输入一个分数输出等级）和批处理（输入多个分数批量输出等级并统计）。规则：90 分以上 A，80~89 B，70~79 C，60~69 D，60 以下 F。

## 功能清单

- [ ] 单条模式：循环读入一个分数，输出等级，输入 `q` 退出
- [ ] 批处理模式：一次读入全部分数（空格分隔），逐个输出等级
- [ ] 批处理结束输出统计：总人数、各等级人数、平均分、最高分、最低分
- [ ] 非法输入（非数字、超出 0~100）给出提示并跳过，不崩溃
- [ ] 用 `if __name__ == "__main__":` 保护入口

## 验收标准

- `python3 grade_tool.py` 进入单条模式，输入 `95` 输出 `A`，输入 `q` 退出
- `echo "95 82 67 54 78" | python3 grade_tool.py --batch` 输出 5 条等级 + 统计（平均 75.20，最高 95，最低 54）
- 输入 `abc` 或 `120` 提示错误，程序不崩溃
- 全部代码符合 PEP 8

## 扩展方向（可选）

- 支持从文件读取成绩 —— 属于 ph05 文件操作与异常处理阶段
- 用 dataclass 封装学生记录 —— 属于 ph04 面向对象 OOP 阶段
- 支持自定义分数线配置 —— 属于 ph06 标准库阶段（argparse）

## 验证环境

Python 3.13.12（macOS）。运行：`python3 grade_tool.py`（单条模式）或 `echo "95 82 67" | python3 grade_tool.py --batch`（批处理模式）。已在本环境验证。
