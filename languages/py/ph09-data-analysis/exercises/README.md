## 练习 1：销售数据分析（★★）

- **目标**：自造一份门店销售 CSV，走"读取 → 清洗 → 分组统计 → 柱状图"的完整链路
- **要求**：
  - 数据至少含「门店、月份、销售额」三列，混入至少 1 个缺失值与 1 个重复行
  - 动手前先 `info()`/`describe()` 摸清类型与空值；缺失值显式决策（`fillna` 中位数或 `dropna` 二选一），重复行去重
  - `groupby("门店")["销售额"].mean()` 统计各门店月均销售额并降序排列；再 `pivot_table` 生成「门店 × 月份」透视表
  - 柱状图服务"哪家门店卖得好"的结论；脚本开头 `matplotlib.use("Agg")`，`savefig` 到临时目录
- **验收**：打印各门店月均销售额（降序）与透视表；生成 PNG 且文件大小 > 0；当前目录无残留 csv/png

## 练习 2：车辆速度分析（★★）

- **目标**：对时间序列遥测数据过滤 GPS 跳变异常值，再降采样看趋势
- **要求**：
  - 数据为 30 秒一条的速度记录，至少注入 1 个 >200 km/h 的异常值（物理上不可能的速度）
  - `set_index("time")` 转日期索引后，用 `0 <= speed <= 200` 过滤，打印原始/过滤后行数与剔除数
  - `resample("5min")["speed"].mean()` 降采样看趋势，另加一条 `rolling` 滚动均值平滑线
  - 折线图同时画原始、5min 均值、滚动均值三条序列并带图例，`savefig` 到临时目录
- **验收**：剔除数与注入的异常值数量一致；打印的平均速度在 0~200 合理范围；PNG 非空

## 练习 3：电池数据分析（★★★）

- **目标**：SOC 与电压关联分析 + 缺失值线性插值 + 散点图与拟合线
- **要求**：
  - 电压随 SOC 近似线性（可加噪声），人为挖掉 2~3 个点设为 NaN
  - 用 `interpolate()` 线性插值补缺（禁止用 `fillna` 均值糊弄），打印插值后缺失数应为 0
  - `df["soc"].corr(df["voltage"])` 计算相关系数，说明它量化了什么
  - 散点图 + `np.polyfit` 拟合线，`savefig` 到临时目录
- **验收**：插值后缺失数为 0；相关系数绝对值 > 0.95；PNG 非空

## 练习 4：CAN 日志统计（★★★）

- **目标**：解析 CAN 报文日志文本，按报文 ID 分组统计频次并画分布图
- **要求**：
  - 日志行格式 `时间 CAN 0x123 DLC 8 数据字节...`，用正则一次性提取时间、CAN ID、首字节（十六进制）
  - 样本至少 8 行、覆盖 3 个不同 ID，其中至少 1 个 ID 出现 3 次以上；解析失败的脏行要能跳过
  - `groupby("can_id").size()` 统计频次并降序；`nunique()` 统计不同 ID 数
  - 频次分布柱状图服务"哪些报文最频繁"的结论，`savefig` 到临时目录
- **验收**：打印各 ID 频次（降序）、总报文数与不同 ID 数，与样本一一对应；PNG 非空
