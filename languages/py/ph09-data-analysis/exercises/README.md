## 练习 1：销售数据分析（★★）

- **目标**：自造一份门店销售 CSV，走"读取 → 清洗 → 分组统计 → 柱状图"的完整链路
- **要求**：
  - 数据至少含「门店、月份、销售额」三列，混入至少 1 个缺失值与 1 个重复行
  - 动手前先 `info()`/`describe()` 摸清类型与空值；缺失值显式决策（`fillna` 中位数或 `dropna` 二选一），重复行去重
  - `groupby("门店")["销售额"].mean()` 统计各门店月均销售额并降序排列；再 `pivot_table` 生成「门店 × 月份」透视表
  - 柱状图服务"哪家门店卖得好"的结论；脚本开头 `matplotlib.use("Agg")`，`savefig` 到临时目录
- **验收**：打印各门店月均销售额（降序）与透视表；生成 PNG 且文件大小 > 0；当前目录无残留 csv/png

## 练习 2：服务延迟趋势分析（★★）

- **目标**：对 15 秒粒度的服务延迟序列过滤量程越界点，再降采样看趋势
- **要求**：
  - 数据为 15 秒一条的延迟记录（列：`ts, service_id, latency_ms`），至少注入 2 个 >2000 ms 的越界延迟（物理上不可能）
  - `set_index("ts")` 转日期索引后，用 `0 <= latency_ms <= 2000` 过滤，打印原始/过滤后行数与剔除数
  - `resample("5min")["latency_ms"].mean()` 降采样看趋势，另加一条 `rolling` 滚动均值平滑线
  - 折线图同时画原始、5min 均值、滚动均值三条序列并带图例，`savefig` 到临时目录
- **验收**：剔除数与注入的越界值数量一致；打印的平均延迟落在 0~2000 合理范围；PNG 非空

## 练习 3：资源用量分析（★★★）

- **目标**：CPU/内存分组统计与透视 + 缺失值线性插值 + 关联散点图
- **要求**：
  - 至少 3 个服务实例、每实例若干采样点，列为 `service_id, cpu_pct, mem_used_gb`；内存随 CPU 同向变化（可加噪声），人为挖掉 2~3 个内存值设为 NaN
  - **按服务实例分组**用 `interpolate()` 线性插值补缺（禁止用 `fillna` 均值糊弄），打印插值后缺失数应为 0
  - `groupby("service_id")` 统计 CPU/内存均值与峰值，并换算内存峰值利用率（峰值 / 256 GB）
  - `pivot_table` 出「CPU 档位 × 实例」的内存均值（可先用 `pd.cut` 分箱）；`df["cpu_pct"].corr(df["mem_used_gb"])` 计算相关系数
  - 散点图 + `np.polyfit` 拟合线，`savefig` 到临时目录
- **验收**：插值后缺失数为 0；CPU 与内存相关系数 > 0.95；透视表覆盖全部 CPU 档位；PNG 非空

## 练习 4：平台服务日志统计（★★★）

- **目标**：解析平台服务日志文本，按来源与级别分组统计并画分布图
- **要求**：
  - 日志行格式 `时间 级别 来源 消息`（级别为 INFO/WARN/ERROR，来源形如 svc-001），用正则一次性提取时间、级别、来源与消息
  - 样本至少 8 行、覆盖 3 个不同来源，其中至少 1 个来源出现 3 次以上；解析失败的脏行要能跳过并计数
  - `groupby("source").size()` 统计来源频次并降序，`groupby("level").size()` 看级别分布，`nunique()` 统计不同来源数
  - 来源频次柱状图服务"哪些来源最活跃"的结论，`savefig` 到临时目录
- **验收**：打印各来源频次（降序）、级别分布、总条数与不同来源数，与样本一一对应；PNG 非空
