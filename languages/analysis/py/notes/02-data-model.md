# 02 · 数据模型（魔术方法）

> demo: `python3 demos/02_data_model.py`

## 1. 设计动机

C++ 用运算符重载、Java 用接口让类型参与语言操作。Python 的命题：
**"一切皆对象"，运算符、内置函数、语法（`+`、`len()`、`for`、`in`）
统统翻译成对象的方法调用**——任何类只要实现对应的"魔术方法"
（`__add__`、`__len__`、`__iter__`），就能无缝参与语言本身的操作。

## 2. 机制拆解

| 语法 / 内置 | 调用的方法 | 语义 |
|------------|-----------|------|
| `a + b` | `a.__add__(b)` | 运算符重载 |
| `len(x)` | `x.__len__()` | 内置函数是协议调用 |
| `x[i]` / `x[i]=v` | `x.__getitem__(i)` / `__setitem__` | 下标访问 |
| `for i in x` | `x.__iter__()` | 迭代协议 |
| `str(x)` / `repr(x)` | `x.__str__()` / `__repr__()` | 字符串化 |
| `x == y` / `x < y` | `x.__eq__(y)` / `x.__lt__(y)` | 比较 |

**设计亮点**：`len(x)` 不是 `x.len()`——内置函数调协议方法，
让**内置函数和语法是"统一接口"**。你的类型实现了 `__len__`，
立刻就能被 `len()`、`bool()`（空为假）、`for` 循环使用。

## 3. 代码验证（demos/02_data_model.py）

demo 定义一个 `Vector2D`：实现 `__add__`/`__mul__`/`__len__`/`__repr__`/`__eq__`，
然后它就能用 `+`、`*`、`len()`、`repr()`、`==`——无缝融入语言。

## 4. 代价与取舍

| 代价 | 说明 |
|------|------|
| 魔法过多 | 魔术方法难查、难读（"隐式调用"藏得深） |
| 可滥用 | 重载 `__eq__` 而忘 `__hash__` 等一致性坑 |
| 性能 | 每个语法操作都是方法调用 + 动态查找 |

**换来的**：极致的统一性——**语言语法 = 协议**，自定义类型是一等公民。

## 5. 对 Tenet 的启示

- ✅ **吸收"操作是统一的、可被语法复用的"**：Tenet 的 `print` 对 4 种类型统一
  处理（`display` 函数分发），正是"内置操作走统一接口"的最小版
- ✅ **吸收"字符串化协议"**：Tenet 每个值都有唯一的显示规则
  （int→"42"、bool→"true"、float→"3.5"），对应 `__str__` 协议
- ❌ **拒绝运算符重载**：Tenet 的 `+` 只有固定语义（数值相加/字符串拼接），
  用户不能改变——这正是吸收了 C++ 教训后的克制
- ❌ **拒绝魔术方法/隐式协议**：对教学语言，"显式函数调用"远胜隐式协议
- 💡 Tenet 的运行时值系统（`value.rs` 的 `apply_binary` 分发）
  就是"按类型分发的操作表"——数据模型的雏形

**一句话**：Python 用「一切皆协议」让自定义类型融入语法；Tenet 把协议
收敛成一张固定操作表，吸收统一性、拒绝魔法。
