# exercises —— 构建与调试阶段练习

完成顺序建议：按 1~4 顺序完成。参考实现在 `sol-*` 文件中，做完再看。

## 练习 1：给前面项目写 Makefile

- **目标**：任选 ph05 通讯录或 ph06 日志系统，写 Makefile 管理构建
- **要求**：
  - `CC`/`CFLAGS`/`TARGET`/`OBJS` 变量分离
  - 每个 `.c` 对应 `.o` 目标，依赖含头文件
  - `make clean` 清理产物；`.PHONY: clean`
  - 改一个 `.c` 后 `make` 只重编该文件（增量构建生效）
- **验收**：`make` 构建成功、运行正确；`touch` 一个 `.c` 后 `make` 只重编它；`make clean` 清空产物

## 练习 2：用 GDB 调试段错误

- **目标**：故意写一个越界程序，用 GDB 完整走一遍定位流程
- **要求**：
  - 用 `-g` 编译（保留调试符号）
  - `gdb` 内执行：`run` → 崩溃 → `bt`（调用链）→ `print i`（变量值）→ 定位行号
  - 用 `break` + `watch` 主动设断点观察变量变化
- **验收**：能用 `bt` 定位到越界函数与行号、用 `print` 确认越界下标、修正后重新编译运行无段错误

## 练习 3：封装静态库

- **目标**：把 ph02 的 math_utils 打成 `libmath.a`，另写 main 链接使用
- **要求**：
  - `gcc -c` 编译 + `ar rcs` 打包 + `nm` 查看符号
  - 调用方只依赖头文件，不依赖 `.c`
  - 验证：删掉 `.a` 后调用方仍可运行（静态链接）
- **验收**：`libmath.a` 生成成功；调用方编译链接运行正确；`nm` 能看到 `T add` 等符号

## 练习 4：写一个多文件 C 项目

- **目标**：写 3+ 个 `.c` + 对应 `.h`，用 Makefile 或 CMake 构建
- **要求**：
  - 至少 3 个模块（如 `main.c` + `io.c`/`io.h` + `parse.c`/`parse.h`）
  - Makefile 或 CMakeLists.txt 二选一
  - `-Wall -Wextra` 零警告
- **验收**：构建成功、运行正确；模块间接口清晰（`.h` 只暴露必要声明）
