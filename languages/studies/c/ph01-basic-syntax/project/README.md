# ph01 阶段项目：命令行计算器

## 需求

对应 Roadmap「ph01 基础语法阶段」推荐项目之一。实现一个命令行计算器：循环读入形如 `3 + 4` 的算式，输出结果；支持 `+ - * /` 四则运算；除零、输入格式错误、不支持的运算符都要有明确提示；输入 `q` 退出。

## 功能清单

- [ ] 循环读入算式直到用户输入 `q` 退出
- [ ] 支持 `+ - * /` 四则运算，结果保留两位小数
- [ ] 除零时输出错误提示，不崩溃
- [ ] 输入格式不正确时给出提示并继续
- [ ] 不支持的运算符给出提示

## 验收标准

- `gcc -Wall -Wextra -std=c99 calculator.c -o calculator` 编译零警告
- 输入 `3 + 4` 输出 `7.00`，输入 `10 / 4` 输出 `2.50`
- 输入 `1 / 0` 输出除零错误，程序不退出
- 输入 `q` 正常退出，返回码 0
- 输入非法格式（如 `abc`）提示错误并可继续输入

## 扩展方向（可选）

- 支持浮点与整数混合运算（已默认支持）
- 支持括号与优先级 —— 属于 ph03 数组/字符串与 ph05 结构体的进阶内容
- 把计算逻辑拆成独立函数 —— 属于 ph02 函数与模块化阶段

## 验证环境

Apple clang 17.0.0（gcc 兼容），标准 C99。编译：`gcc -Wall -Wextra -std=c99 calculator.c -o calculator`；运行：`./calculator`。已在本环境验证。
