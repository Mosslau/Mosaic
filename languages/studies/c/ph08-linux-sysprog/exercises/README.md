# exercises —— Linux 系统编程阶段练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。

完成顺序建议：按 1~5 顺序完成（难度递增）。五题与 roadmap ph08「练习」小节一一对应。参考实现在 `sol-*` 文件中，做完再看。

## 练习 1：简单 shell（★★）

- **目标**：实现一个可交互的 mini shell：循环读命令 → fork + execvp 执行 → waitpid 回收
- **要求**：
  - 提示符后读取一行，按空白切分参数
  - 内置命令 `cd`、`exit` 不 fork（`cd` 必须改父进程自己的目录）
  - 外部命令用 `execvp`（依赖 PATH 查找），子进程 exec 失败要报错并以 127 退出
  - 父进程 waitpid 回收，不产生僵尸进程；EOF（Ctrl+D）正常退出
- **验收**：`echo hi`、`ls`、`pwd` 正常执行；`cd /tmp` 后 `pwd` 显示 /tmp；`badcmd` 报错不崩溃；运行 `ps` 确认无僵尸子进程

## 练习 2：多线程下载器（★★）

- **目标**：每个 URL 开一个线程下载（HTTP GET），主线程 join 汇总成功数
- **要求**：
  - 每个线程：socket → connect → 发送 `GET /path HTTP/1.0` → recv 循环落盘（处理短读短写）
  - 共享的"已完成计数"必须用 mutex 保护（体会数据竞争）
  - 传给线程的参数必须保证线程运行期存活（堆分配或全局数组）
  - `-Wall -Wextra -pthread` 零警告
- **验收**：对一个本地 HTTP 服务（如 `python3 -m http.server`）同时下载 3 个路径，输出文件齐全、汇总计数正确

## 练习 3：多客户端 TCP echo server（★★）

- **目标**：改造 examples/ex04 的阻塞 echo server，支持多客户端同时连接
- **要求**：
  - 每个连接 fork 一个子进程处理（或自选 pthread 方案）
  - 用 SIGCHLD + waitpid(WNOHANG) 回收子进程，handler 内只调 async-signal-safe 函数
  - 父进程关闭连接 fd（防泄漏），子进程关闭监听 fd
  - 设 `SO_REUSEADDR`；send 处理短写
- **验收**：两个 `nc 127.0.0.1 8888` 同时连接互不影响；客户端断开后 `ps` 无 defunct 僵尸；服务端重启不报 `Address already in use`

## 练习 4：简单 HTTP server（★★★）

- **目标**：解析 `GET /path HTTP/1.1` 请求，返回 docroot 下对应文件或 404
- **要求**：
  - 累积缓冲直到收到 `\r\n\r\n` 再解析（处理半包，不能假设一次 recv 收全）
  - 响应带 `Content-Length` 与 `Connection: close`；拒绝含 `..` 的路径（防目录穿越）
  - 文件内容循环读、send 处理短写
- **验收**：`curl -v http://127.0.0.1:8080/<存在的文件>` 返回 200 且内容完整；请求不存在的文件返回 404；用 `nc` 分两次发送请求头（模拟半包）仍能正确响应

## 练习 5：日志采集程序（★★★）

- **目标**：多线程生产日志 → 有界队列 → 单写线程 `open(..., O_APPEND)` 落盘
- **要求**：
  - 队列容量有界（如 16），满则生产者等待、空则消费者等待（mutex + 两个 condvar，while 防虚假唤醒）
  - 优雅退出：所有生产者结束后，写线程排空队列再退出（不能用"投毒"以外的说不清机制，计数或终止信号均可）
  - `O_APPEND` 打开日志文件，write 处理短写
  - 可用 examples/ex03 的任务队列改造
- **验收**：4 个生产者各写 250 行后退出，`wc -l app.log` 恰好 1000 行（无丢行、无重复）；重跑程序日志追加不覆盖

> **提示**：练习 1~5 分别对应主文档 3.2/3.4/3.6/3.6+4.5/3.5 的知识——先独立完成，再对照 `sol-*` 复盘。练习 2/3/4 需要本机回环网络（127.0.0.1），无需 root 权限。
