# ph01 阶段项目：命令行计算器

## 需求

对应 Roadmap「Rust 基础语法阶段」推荐项目。实现一个命令行计算器：循环读入形如 `3 + 4` 的算式并输出结果；支持 `+ - * /` 四则运算；除零、输入格式错误、不支持的运算符都要有明确提示且不崩溃；输入 `q` 退出；核心逻辑附带 `#[test]` 单元测试。

## 功能清单

- [x] 循环读入算式直到用户输入 `q`（或 `Q`）退出
- [x] 支持 `+ - * /` 四则运算，结果保留两位小数
- [x] 除零时输出错误提示，不崩溃
- [x] 输入格式不正确时给出提示并继续
- [x] 不支持的运算符给出提示
- [x] `calc` / `parse_line` 核心逻辑有单元测试覆盖（7 个用例）

## 验收标准

- `cargo test` 全部通过
- `cargo run` 后输入 `3 + 4` 输出 `7.00`，输入 `10 / 4` 输出 `2.50`
- 输入 `1 / 0` 输出除零错误，程序不退出
- 输入非法格式（如 `abc`）提示错误并可继续输入
- 输入 `q` 正常退出
- 代码不滥用 `unwrap`/`expect`：解析失败用 `match`/`Option` 处理

## 扩展方向（可选）

- 支持括号与运算优先级 —— 需要更复杂的解析，可在学完 ph03 数据结构、ph05 模式匹配后实现
- 随机数版猜数字（`rand` crate）—— 属于后续阶段引入第三方依赖的内容
- 把计算逻辑拆成独立模块 —— 属于 ph06 模块化与 Cargo 阶段

## 验证环境

rustc/cargo 1.92.0，edition 2021。构建：`cargo build`；运行：`cargo run`；测试：`cargo test`。已在本环境验证：7 个单元测试全部通过，交互行为符合验收标准。
