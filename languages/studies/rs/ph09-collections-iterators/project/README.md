# ph09 阶段项目：日志数据聚合器

对应 roadmap ph09 推荐项目「日志数据聚合器：过滤异常记录并计算错误分布、延迟分布和来源统计」。在主文档示例 4 的基础上扩展为"文本解析 + 四类报告 + 单元测试"的完整版本。

## 需求

数据基础设施里，日志聚合是"迭代器链"最典型的应用场景：读入多行日志 → 逐行解析成结构化条目 → 过滤异常记录 → 分维度聚合统计。本项目用一条条迭代器链完成全部数据处理——**过滤、分组、映射分档、折叠聚合**正是本阶段必会概念的集合，全程零第三方依赖、单文件可编译。

- `LogEntry`：一条日志（来源、级别、耗时毫秒）
- `parse_log(text) -> Vec<LogEntry>`：逐行解析，空行、`#` 注释、格式非法行（段数不足/多余、耗时非数字）自动跳过
- 异常判定：非 `INFO` 级别，或延迟超过 500ms
- 四类输出：异常记录总数、错误分布（按级别）、延迟分布（按分档 `<=100ms` / `101ms-1s` / `>1s`）、来源统计（异常条数 + 平均延迟，按条数降序）
- 教学要点：`filter_map` 同时完成"解析 + 跳过非法行"；`fold` 聚合来源统计（累加器是 `HashMap<&str, (条数, 总延迟)>`）；`map` 把延迟映射成分档标签再分组计数

## 功能清单

| 功能 | 说明 |
|------|------|
| 文本解析 | `lines()` + `filter_map`，空行/注释/非法行跳过，`parse_line` 返回 `Option` |
| 异常过滤 | `is_abnormal`：非 INFO 或延迟 > 500ms，`filter` 消费器 |
| 错误分布 | `entry(key).or_insert(0) += 1` 按级别分组计数 |
| 延迟分布 | `latency_bucket` 分档 + `entry` 计数（`0..=100` / `101..=1000` / 其余） |
| 来源统计 | `fold` 构建 `HashMap<&str, (u32, u64)>`（条数 + 总延迟），再算平均 |
| 排序报表 | HashMap → 迭代器 → `Vec<(String, u32, f64)>`，按条数降序 |
| 单元测试 | `#[cfg(test)]` 模块 12 个用例：解析、边界分档、异常判定、统计正确性、空输入 |
