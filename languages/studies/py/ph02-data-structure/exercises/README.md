# ph02 数据结构 练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。
> 验证环境：Python 3.13.12（macOS arm64），仅用标准库。运行统一用 `python3 <文件>`。

## 练习 1：list 管理成绩（★）

**目标**：用 list 完成一组成绩的统计分析。
**要求**：给定成绩列表，计算平均分（保留两位小数）、最高分和最低分；把成绩按降序排序后输出前三名；统计及格（>= 60）人数。不准用 `max()` / `min()` 以外的库函数做统计（平均分用 `sum` / `len` 即可）。
**验收**：对 `[78, 92, 85, 67, 88, 91, 73]`，输出平均分 `82.00`、最高 `92`、最低 `67`、前三名 `[92, 91, 88]`、及格人数 `7`。

## 练习 2：dict 做通讯录（★★）

**目标**：用 dict 实现一个支持增删改查的通讯录。
**要求**：联系人结构为 `{姓名: {"phone": str, "city": str}}`；实现添加联系人、按姓名查询（查不到要提示而不是抛 KeyError）、修改电话、删除联系人、列出全部联系人五个功能；用 `main` 依次演示。
**验收**：添加 Alice、Bob 后查询 Bob 能输出其电话与城市；修改 Alice 电话后再查显示新号码；删除 Bob 后查询 Bob 提示未找到；列出时只剩 Alice。

## 练习 3：set 去重与集合运算（★）

**目标**：用 set 完成列表去重和集合运算。
**要求**：给定一个含重复元素的单词列表，输出去重后的单词集合（个数）；再给定两个标签集合 `a`、`b`，输出交集、并集、a 独有的元素（差集）。
**验收**：`["apple", "banana", "apple", "orange", "banana"]` 去重后个数为 3；`a = {"red", "green", "blue"}`、`b = {"green", "blue", "yellow"}` 时，交集 `{"green", "blue"}`、并集 4 个元素、`a - b` 为 `{"red"}`。

## 练习 4：统计词频（★★）

**目标**：读取一段文本，统计每个单词出现的次数并按频率降序输出。
**要求**：把文本按空白切分成单词；用 dict 计数（用 `dict.get` 或 `in` 判断均可）；按出现次数降序输出每个词及次数；额外输出不重复单词总数。提示：`sorted(freq.items(), key=lambda x: x[1], reverse=True)`。
**验收**：对 `"apple banana apple orange banana apple"`，输出 `apple: 3`、`banana: 2`、`orange: 1`（按此顺序），不重复词数 `3`。
