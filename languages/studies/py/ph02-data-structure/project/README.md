# ph02 阶段项目：购物车

## 需求

对应 Roadmap「数据结构阶段」推荐项目第一个。实现一个交互式命令行购物车：用 list of dict 管理商品，每条记录包含名称、单价、数量；支持添加商品、删除商品、查看购物车、计算总价、按单价排序展示，直到用户选择退出。

## 功能清单

- [ ] 添加商品（名称 + 单价 + 数量），重名商品累加数量而不是重复条目
- [ ] 删除商品（按名称，删除不存在的商品要提示）
- [ ] 列出购物车全部商品（名称、单价、数量、小计）
- [ ] 计算并输出购物车总价（保留两位小数）
- [ ] 按单价升序排序展示
- [ ] 交互式菜单循环，输入 0 退出

## 验收标准

- `python3 cart.py` 启动后显示菜单，输入 1~5 执行对应功能，输入 0 退出
- 依次添加 `apple 5.5 3` 和 `banana 3.0 2` 后，总价为 `22.50`
- 再次添加 `apple 5.5 2` 后 apple 数量变为 5，总价为 `33.50`
- 按单价排序时 banana 排在 apple 前
- 删除不存在的商品时输出提示且不崩溃
- 仅用标准库，PEP 8 风格（4 空格缩进、snake_case）

## 扩展方向（可选）

- 用 `dataclass` 表达商品条目 —— 属于 ph04 面向对象阶段
- 把购物车保存到 JSON 文件、启动时加载 —— 属于 ph05 文件操作与异常处理阶段
- 用 `collections.Counter` 简化数量统计 —— 属于 ph06 标准库阶段

## 验证环境

Python 3.13.12（macOS arm64），仅用标准库。运行：`python3 cart.py`；自动化验证（管道喂输入）：`printf '1\napple\n5.5\n3\n1\nbanana\n3.0\n2\n4\n3\n5\n0\n' | python3 cart.py`。已在本环境验证。
