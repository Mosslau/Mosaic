# exercises —— 标准库阶段练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。参考实现都在临时目录内构造测试数据，可直接 `python3 sol-XX-*.py` 运行验证。

完成顺序建议：按 1~5 顺序完成。

## 练习 1：批量移动文件（★）

- **目标**：用 `pathlib` 遍历目录，把散落的日志按文件名中的日期归类到 `archive/YYYY-MM-DD/` 子目录
- **要求**：
  - 用 `Path.glob` 遍历，正则提取文件名中的日期（`YYYY-MM-DD`）；无日期的文件跳过（不报错）
  - 目标子目录不存在时自动创建（`mkdir(parents=True, exist_ok=True)`）
  - 支持 `dry_run` 参数：为 `True` 时只打印计划、不实际移动
- **验收**：对含 4 个带日期日志 + 1 个无日期文件的目录，`dry_run=True` 后目录内容不变；`dry_run=False` 后文件按日期归入子目录且计数正确

## 练习 2：正则提取日志（★★）

- **目标**：用 `re.findall` + 命名分组提取日志中的时间、级别、IP、错误码，用 `Counter` 统计错误码分布
- **要求**：
  - 预编译正则（`re.compile`），提取字段用命名分组
  - 无法匹配的行忽略（不崩溃）
  - 输出错误码按次数降序的分布
- **验收**：对给定样例日志正确提取全部行；混入的非法行不影响结果；错误码分布与人工统计一致

## 练习 3：命令行参数工具（★★）

- **目标**：用 `argparse` 实现批量重命名工具，参数 `--dir`/`--ext`/`--prefix`/`--dry-run`
- **要求**：
  - 所有参数带默认值；`--help` 由 `argparse` 自动生成
  - `--ext` 未带 `.` 前缀时自动补全
  - `--dry-run` 用 `action="store_true"` 实现，预览不改名
- **验收**：`--help` 输出包含全部 4 个参数；`--dry-run` 后目录内容不变；实际执行后文件名前缀正确

## 练习 4：subprocess 调命令（★★）

- **目标**：用 `subprocess` 调用外部命令并捕获输出，正确处理非零返回码与超时
- **要求**：
  - 传参数列表而非拼接字符串（不用 `shell=True`）
  - `capture_output=True` + `text=True` 捕获输出；`check=True` 处理非零返回码
  - 用 `timeout` 防止外部命令卡死脚本
- **验收**：统计文件行数返回码为 0 且输出正确；非零返回码场景被捕获并打印退出码；超时场景被 `TimeoutExpired` 捕获

## 练习 5：批量重命名工具升级（★★★）

- **目标**：把 ph05 阶段（`05-file-exception.md`）的批量重命名示例升级为 logging + argparse 版本
- **要求**：
  - 核心逻辑改造 `ph05/examples/ex05-batch-rename.py`，把 `print` 换成 `logger.info`
  - 用 `argparse` 暴露 `--dir`/`--old-ext`/`--new-ext`/`--dry-run`
  - 用 `logger = logging.getLogger(__name__)`，`basicConfig` 配置 INFO 级别、带时间戳格式
- **验收**：CLI 支持 4 个参数；`--dry-run` 只输出日志不改文件；实际执行后扩展名全部替换、旧文件消失
