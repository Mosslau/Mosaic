# ph01 基础语法 示例

> 每个示例是主文档第 6 章对应示例的完整可运行版。验证环境：Python 3.13.12。

| 文件 | 说明 | 运行 |
|------|------|------|
| ex01-guess-number.py | 猜数字游戏：随机 1~100，循环猜直到命中 | `python3 ex01-guess-number.py`（交互输入） |
| ex02-grade-judge.py | 成绩等级判定：分数 → A/B/C/D/F | `python3 ex02-grade-judge.py` |
| ex03-word-count.py | 词频统计：统计字符串中每个单词出现次数 | `python3 ex03-word-count.py` |
| ex04-multiplication-table.py | 九九乘法表 | `python3 ex04-multiplication-table.py` |
| ex05-text-stats.py | 文本统计：从 stdin 读文本，输出字符/单词/行数 | `echo "hello world" \| python3 ex05-text-stats.py` |

全部已在本环境用 Python 3.13.12 验证通过。
