# ph01 基础语法 练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。
> 验证环境：Python 3.13.12。

## 练习 1：猜数字游戏（★）

**目标**：写一个猜数字游戏程序。
**要求**：程序随机生成 1~100 的整数；用户循环输入猜测；程序提示"太大了"/"太小了"；猜中时输出尝试次数并退出。
**验收**：用管道喂入 `50`、`75`、`88` 等值，程序能正确提示大小并在猜中时退出。

## 练习 2：成绩等级判定（★）

**目标**：根据分数输出等级。
**要求**：90 分以上为 A，80~89 为 B，70~79 为 C，60~69 为 D，60 分以下为 F；对列表 `[95, 82, 67, 54, 78, 91]` 逐个输出等级。
**验收**：输出 `学生 1: 分数=95, 等级=A` …… `学生 6: 分数=91, 等级=A`。

## 练习 3：词频统计（★★）

**目标**：统计一段文本中每个单词出现的次数。
**要求**：用 `split()` 分词；用字典统计；按字母序输出。
**验收**：输入 `"apple banana apple orange banana apple"` 输出 `apple: 3`、`banana: 2`、`orange: 1`。

## 练习 4：九九乘法表（★★）

**目标**：打印标准九九乘法表。
**要求**：用嵌套循环；每行只打到行号；乘积左对齐占两位。
**验收**：输出 9 行，最后一行以 `1×9=9` 开头、`9×9=81` 结尾。

## 练习 5：简单命令行脚本（★★）

**目标**：写一个从 stdin 读文本、输出统计信息的命令行脚本。
**要求**：统计字符数（含空格）、单词数、行数；用 `if __name__ == "__main__":` 保护入口。
**验收**：`echo "hello world" | python3 sol-05-text-stats.py` 输出字符数 12、单词数 2、行数 2。
