# ph03 函数与模块化 示例

> 每个示例是主文档第 6 章对应示例的完整可运行版。验证环境：Python 3.13.12。

| 文件 | 说明 | 运行 |
|------|------|------|
| ex01-mutable-default.py | 可变默认参数陷阱与 None 哨兵纠正 | `python3 ex01-mutable-default.py` |
| ex02-args-kwargs.py | `*args`/`**kwargs` 打包与拆包综合演示 | `python3 ex02-args-kwargs.py` |
| ex03-math-module/ | 数学工具模块（`math_utils.py` + `main_math.py`） | `cd ex03-math-module && python3 main_math.py` |
| ex04-legb-scope.py | LEGB 作用域完整追踪 | `python3 ex04-legb-scope.py` |
| ex05-strtools.py | 字符串处理 CLI（count/reverse/stats） | `python3 ex05-strtools.py reverse "hello"` |

全部已在本环境用 python3（3.13.12）运行验证。
