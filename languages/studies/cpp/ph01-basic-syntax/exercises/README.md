# ph01 基础语法 练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。
> 验证环境：Apple clang 17.0.0（g++ 兼容），标准 C++17。编译统一加 `-Wall -Wextra -std=c++17`。
> 所有题目要求：优先用 `std::string` 和 `std::vector`，不用 C 风格字符串与裸数组，不出现裸 `new`/`delete`（Core Guidelines R.11）。

## 练习 1：姓名与年龄问候（★）

**目标**：读入姓名和年龄，格式化输出一句问候。
**要求**：姓名可能含空格，用 `std::getline(std::cin, name)` 读整行姓名；年龄用 `int` 读入；输出形如 `你好，张三！今年 25 岁。`。
**验收**：输入两行 `张三` 和 `25`，输出 `你好，张三！今年 25 岁。`；输入 `Li Ming`（含空格）和 `30`，姓名部分完整读入不被空格截断。

## 练习 2：字符串拼接与子串（★）

**目标**：用 `std::string` 完成拼接、查找、截取。
**要求**：给定 `std::string s = "hello cpp world"`，输出：(1) 在末尾拼接 `"!"` 后的完整字符串；(2) `s.find("cpp")` 找到的起始下标；(3) 用 `substr` 截取出 `"cpp"` 子串并输出。
**验收**：输出三行——`hello cpp world!`、`6`、`cpp`。

## 练习 3：vector 统计最值与平均（★★）

**目标**：用 `std::vector<double>` 替代 C 数组，求一组成绩的最大值、最小值、平均值。
**要求**：成绩初始化为 `{78, 92, 85, 63, 99, 71}`；用 range-for 一次遍历同时求出三个值（遍历时用 `const auto&`）；平均值保留两位小数输出。
**验收**：输出人数 `6`、平均 `81.33`、最高 `99`、最低 `63` 四项。

## 练习 4：改写 C 风格字符串（★★）

**目标**：把一段 C 风格字符串处理代码改写为 `std::string` 版本，体会两者的差别。
**要求**：实现函数 `std::string to_upper(std::string s)`，把字符串中的小写字母转大写后返回（提示：遍历每个字符，用 `std::toupper`，注意其返回 `int` 需 `static_cast<char>`）；`main` 中读入一行字符串，输出转换结果；全程不出现 `char[]`、`strlen`、`strcpy`。
**验收**：输入 `hello World 123`，输出 `HELLO WORLD 123`。
