# ph01 阶段项目：简单通讯录

## 需求

对应 Roadmap「C++ 基础语法阶段」推荐项目第一个。实现一个命令行交互式通讯录：循环显示菜单，支持添加、列出、查找、删除联系人，输入 `0` 退出。数据在内存中用 `std::vector<Contact>` 存储，联系人字段用 `std::string`——全程不使用 C 风格字符串、裸数组和裸 `new`/`delete`。

## 功能清单

- [x] 添加联系人（姓名 + 电话，姓名允许含空格）
- [x] 列出全部联系人（带序号）
- [x] 按姓名精确查找
- [x] 按姓名删除，未找到时给出提示
- [x] 非法命令与空输入给出提示，程序不崩溃
- [x] 输入 `0` 或 EOF 正常退出，返回码 0

## 验收标准

- `g++ -Wall -Wextra -std=c++17 contact_book.cpp -o contact_book` 编译零警告
- 依次添加 `Alice 138-0001`、`Bob 138-0002` 后，列出显示 2 条带序号的记录
- 查找 `Bob` 输出 `Bob  138-0002`；查找 `Carol` 输出未找到提示
- 删除 `Alice` 后再列出，只剩 `Bob`
- 输入 `9`（无效命令）提示后可继续操作；输入 `0` 退出，返回码 0
- 添加姓名 `Li Ming`（含空格）能被完整保存和查找

## 扩展方向（可选）

- 把联系人拆成 `class ContactBook` 封装操作 —— 属于 ph02 面向对象 OOP 阶段
- 用 `std::map` 按姓名索引加速查找 —— 属于 ph04 STL 标准库阶段
- 退出时保存到文件、启动时加载 —— 属于 ph09 文件、网络与系统编程阶段
- 查找结果返回 `std::optional<size_t>` —— 属于 ph06 现代 C++ 阶段

## 验证环境

Apple clang 17.0.0（g++ 兼容），标准 C++17。编译：`g++ -Wall -Wextra -std=c++17 contact_book.cpp -o contact_book`；运行：`./contact_book`。已在本环境验证（编译零警告，上述验收标准逐项通过）。
