# README 结构（两篇式）——结构层唯一权威

> 本文件是 README 结构的**唯一权威**：骨架、阅读路线、章节归属判定都以此为准。
> 其余文件只写各自层的细节：基础篇 → `learning-path-template.md`；进阶篇 → `advanced-track-template.md`；素材 → `visual-assets.md`。
> SKILL.md 只保留结构要求与指向本文件的链接，不再复制骨架（避免多点维护）。

---

## 一、结构的目的：两条读者路径，各自能独立走完

| 读者 | 只读哪一部分 | 读完后应当能做到 |
|---|---|---|
| 零基础学习者 | 基础篇 | **能懂**（复述规则）· **能算**（手算小例子）· **能自测**（对照能力清单判定自己过没过） |
| 复现 / 审查者 | 进阶篇 | **能推导**（跟着公式走一遍）· **能跑**（按命令复现数字）· **能验证**（对照验证声明判定真假） |

由此推出两条硬要求：

1. **基础篇自足**：不依赖进阶篇的术语、公式与数字；零基础读者跳过进阶篇也能走通全部七节。
2. **进阶篇自足**：不假设读者读过基础篇；公式符号自洽、命令可独立执行、结论有数据支撑。

允许同一主题在两篇各出现一次，但**形态必须不同**：基础篇给直觉与结论，进阶篇给形式化与证据（详见「三、章节归属判定」）。

## 二、骨架（唯一权威版本）

```markdown
# <算法名>

> 状态：⬜ 未开始 | 🚧 进行中 | ✅ 已完成（YYYY-MM-DD）
> 对应文档章节：`algorithms/docs/人工智能代表算法演进路线.md` 第 <X.Y.Z> 章
> 阅读路线：零基础读者读「基础篇」（生活类比 → 手算 → 白话证明 → 自测）；要看推导与复现实验读「进阶篇」

<可选：一句话说明本实验所属算法族与目录形态，如"搜索求解器：本目录不是 sklearn 估计器，接口由算法自身形态决定">

# 基础篇 · 先搞懂它

## 1. <生活类比：它解决什么问题>      ← 概念图
## 2. <三个核心量 / 一句话规则>        ← 概念图
## 3. <主循环>                        ← 流程图
## 4. <小地图手算示例>                 ← 分步图 + 逐步表
## 5. <白话版：为什么它是对的>          ← 可无图
## 6. <常见误区>                      ← 对比图（如有）
## 7. <能力清单 + 自测关卡>            ← 五级清单的本题版本

# 进阶篇 · 实验档案

## 设计原理
## 数学推导
## 目录形态（本算法的"类型"）（可选但推荐）
## 手写实现要点
## 基线对照 | 框架对照（段名按算法族二选一）
## 实验结果
## 局限与延伸
```

固定约束：

- **六段式是硬契约**：`设计原理 / 数学推导 / 手写实现要点 / 对照（框架或基线）/ 实验结果 / 局限与延伸`，位置固定在「进阶篇」内、以 `##` 出现——`validate.py` 按 `##` 匹配，与篇标题层级无关
- 标题区必须是 blockquote 四行内：状态、章节锚点、阅读路线（状态与锚点由 `validate.py` 核对）
- 「目录形态」表为可选，位置固定在「手写实现要点」之前

## 三、章节归属判定（边界三测试）

写下一个章节前，先过三个测试，**任一条回答"是"就归进阶篇**：

| 测试 | 问什么 | 判"是"的例子 |
|---|---|---|
| ① 前置测试 | 这段内容是否假设读者已经知道某个术语或工具？ | 提到堆（heapq）、`f` 单调性、复杂度 |
| ② 目的测试 | 读它是为"建立直觉"还是为"复现与审查"？ | 复现命令、耗时、验证声明 |
| ③ 可判决性测试 | 它是解释，还是可证伪的陈述 / 证据？ | 实测数字（361→37）、最优性证明、失效反例 |

判定流程：

```text
写下一个章节 →
├─ 需要前置术语 / 代码常识？ ──是──▶ 进阶篇
├─ 目的是复现 / 审查 / 证明？ ──是──▶ 进阶篇
├─ 含数字、耗时、复现命令？ ──是──▶ 进阶篇（数字只在「实验结果」出现一次）
├─ 服务于五级清单 1–3 级（说清 / 走通 / 判断）？ ──是──▶ 基础篇
└─ 只是"换个说法的直觉"？ ──▶ 基础篇；若与进阶篇重复且无新信息，删掉
```

## 四、三条硬规则

1. **数字单源**：实验数字（指标、耗时、扩展数…）只在进阶篇「实验结果」段维护一次；基础篇与其它段只给结论或指向，不复制表格——复制即漂移风险
2. **基础篇不越界**：不引入进阶篇没有的新结论；引用实验数字时只给结论（如"多走 4 步"），不给表格
3. **进阶篇不假设前置**：公式符号在段内自洽定义；命令可独立执行；不出现"见基础篇"式的依赖

## 五、自查清单（写完自己先过一遍）

- [ ] 零基础读者只读基础篇：能复述规则、能手算、能对照第 7 节自测
- [ ] 复现者只读进阶篇：能跟着推导走、能按命令跑出数字、能核对验证声明
- [ ] 每个数字只出现一次（在「实验结果」），其它位置全是结论或指向
- [ ] 六段齐全且都在 `# 进阶篇` 之下；标题区三行（状态 / 锚点 / 阅读路线）齐全
- [ ] 新写的章节能通过「边界三测试」归位，无两边都写同一层的重复内容
