## 写作要点

1. **单元必须可独立验收**：写不出"通过标准"的单元说明切错了——按"一条能跑起来的链路"重切，不要按技术分层切
2. 第 ③ 节的「不做」是硬要求：没有"不做"的单元一定会膨胀
3. 第 ④ 节是**唯一**的验收编号来源；L4 单元 README 的验收清单只引用编号，不另起编号体系
4. 「工作量」要给人力假设与串并行口径，否则数字没有意义
5. 第 ⑧ 节只写摘要，长历史可放附录；每次改完都要回看第 ② 节的状态列与 L1 索引表是否同步
