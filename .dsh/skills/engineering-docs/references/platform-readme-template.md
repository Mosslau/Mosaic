## 写作要点

1. 索引表是**唯一现状快照**：完成一个单元就改这一行（状态 + 日期），不要去别处维护进度
2. 第 ④ 节矩阵是"域视角"，第 ② 节是"单元视角"——两者是同一批工作的两个切面，不要互相复制文字
3. 平台还没开工时，第 ④ 节矩阵允许只有设计意图（格子按 L3 的规划填），但要在表下注明"按规划填，未开工"
4. 第 ⑥ 节的"边界"是硬要求：两个平台在仓库内必须有明确分工，重叠能力要写清谁拥有
