# 建模与指标（p2）

> 状态：⬜ 未开始
> 所属平台与单元：data-platform · p2 建模与指标（类别：期）
> 对应文档：../通用数据平台建设路线.md（工程路线：§6 p2 排期、§7 V18–V26 通过标准）；../../roadmap/智能通用大数据平台工程师.md（职业路线）

## 目标

数据可用（**分层建模**）+ 口径唯一（**指标语义层**）+ 质量可拦（**阻断下游**）+ 核心链路有 SLA（**破线前预警**）。

本单元是**纵切型**（形态：纵切）：交付一条"源表 → ODS → DWD → DWS → ADS → 指标 → 消费"的可演示链路，并把口径与质量两件事一次性固定下来。

## 范围与不做

- **范围**：数仓分层落地（ODS / DWD / DWS / ADS + DIM，含分区与幂等规范）；`metric_def` 唯一来源 + MQL→SQL 翻译器 + 指标视图再生成；SQL 质量规则集与**阻断下游**；DWD 清洗与 DWS 聚合模板；Doris 物化与降采样；数据标准与落标检查；基线 SLA 与破线预警；表级血缘最小闭环；集中日志（Loki）。
- **不做**：字段级血缘（p3）、权限与脱敏（p3）、数据服务（p4）、AI 问数（p5）。

## 技术栈

- **Spark**（批加工，集群模式；与 SeaTunnel 共用 JdbcCatalog，验证并发提交正确性——§3② Catalog 约定 2）
- **Calcite**（语义层翻译器；原型结论来自 [`../p0-selection-validation/README.md`](../p0-selection-validation/README.md) 的语义层 spike，**p2 开工前评审**）
- **Doris**（p0 已就位，本期扩建 DWS / ADS 与指标视图）+ **SeaTunnel**（复用 p0 / p1）
- **Loki**（集中日志，横切栈第二期落地，见 §3 横切）
- 版本与兼容矩阵以 [`../p0-selection-validation/README.md`](../p0-selection-validation/README.md) 为准

## 系统架构

```text
【分层链路】
源 → ODS(Iceberg) ──DWD 清洗模板（Spark / SeaTunnel）──▶ DWD
                        │  质量规则（block 名单）卡在加工出口
                        ▼        命中 → **下游不产出**（不是仅告警）
                     DWS 聚合模板 ──▶ DWS ──▶ ADS ──▶ Doris 物化（1m / 1h / 1d 降采样）

【语义层链路】
     metric_def（平台 PG：唯一来源，含派生关系 / 负责人 / 版本）
                        │  定义变更 → 触发生成作业
              ┌─────────┴─────────┐
              ▼                   ▼
     Doris 指标视图        查询网关执行 SQL
     （BI / API 消费）     （与视图**同源同版本**，§3⑦ 约定 4）

【治理与观测】
  表级血缘：加工模板声明输入 / 输出表 → 随 DWD/DWS 落地即上报 DataHub（字段级留 p3）
  基线 SLA：核心链路登记承诺产出时间 → 按依赖链推算余量 → **破线前**预警
  数据标准：字段命名 / 类型 / 值域标准 → 建表与指标定义时引用，违标可检出
  集中日志：Loki
```

## 前置与复用

- **前置单元**：**p1**（湖表、命名族、配置库、门禁全绿）；p0 的版本矩阵。
- **前置条件**：语义层 spike 结论已评审（自研 Calcite / MetricFlow / 受约束 MQL DSL 三选一）；分层模型与质量 block 名单经评审；Spark 集群模式可用。
- **复用**：不复用 `algorithms/` 的实验。
- **产出被谁引用**：p3（字段级血缘在表级基础上补全、成本按数据集归因）、p4（API 与看板口径一致依赖指标视图）、p5（问数复用语义层，只产 MQL）、p6（压测口径引用基线 SLA）。

## 验收标准

- [ ] **V18** 指标一次定义、多处复用 —— 同一指标两处取数数值一致；改定义 → 两处同时生效
- [ ] **V19** 改指标定义自动生效 —— 引用处同步变化
- [ ] **V20** 口径可追溯 —— 任一指标可查定义 / 来源 / 表达式 / 负责人 / 版本
- [ ] **V21** 分层可追溯（表级血缘）—— 任一 ADS 指标可沿 DWD→ODS 追到源表；血缘图可见该链路，且随任务变更自动更新
- [ ] **V22** 脏数据阻断 —— 注入越界数据 → 规则命中 → **下游任务未产出**（不是仅告警）
- [ ] **V23** DWD upsert 正确 —— update / delete 正确反映到 DWD
- [ ] **V24** 物化延迟 —— DWS 1 分钟粒度可查延迟 ≤ 3 分钟
- [ ] **V25** 基线 SLA 破线预警 —— 人为拖延上游任务 → 在承诺产出时间**之前**收到预警
- [ ] **V26** 数据标准落标 —— 违反命名 / 值域标准的建表被拦截；改标准 → 引用处同步生效

**交付物**：数仓分层模型（ODS→DWD→DWS→ADS + DIM）+ `metric_def` 字典与 MQL→SQL 翻译器 + 质量规则集（含阻断链路与分级）+ 数据标准与落标检查器 + 基线 SLA 登记表 + 表级血缘（最小闭环）+ 集中日志（Loki）。

## 实施笔记

- **开工前置条件**（2026-09 拟定）：① 语义层 spike 结论已评审并定稿（p0 交付，p2 开工前必须收口）；② 分层模型与分区 / 幂等规范评审通过；③ 质量规则 block 名单评审通过（block 会真的断下游，必须业务确认）；④ Spark 与 SeaTunnel 共用 JdbcCatalog 的并发提交已由 p0 的 V7 验证。
