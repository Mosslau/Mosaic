## 1. 架构总览

```text
┌─ 接入层 ───────────────────────────────────────────────────────────────┐
│  Web UI          REST API          CLI            SDK                  │
│  （开发者 / 管理员 / 业务系统）                                          │
└───────────────────────────────┬───────────────────────────────────────┘
                                │
┌─ 控制面（自研 · Java + PostgreSQL）────────────────────────────────────┐
│                                                                        │
│  【元数据中枢】                                                          │
│   元数据采集 · 数据集目录 · Schema 目录 · 血缘解析 · 影响分析              │
│                                                                        │
│  【开发与运行】                                                          │
│   项目管理 · 源与凭证 · 配置生成器 · 作业定义与版本 · 调度适配            │
│   作业实例与水位 · DLQ 与重放                                            │
│                                                                        │
│  【治理】                                                                │
│   质量规则引擎 · 权限与脱敏 · 审计 · 成本归因 · 治理看板                  │
│                                                                        │
│  【服务与语义】                                                          │
│   指标语义层（metric_def / MQL）· 数据服务网关 · 调用统计                 │
│                                                                        │
│  【平台工程】                                                            │
│   GitOps（配置即代码）· CI/CD · 版本管理 · 环境隔离                       │
└───────────────────────────────┬───────────────────────────────────────┘
                                │ 下发配置 / 提交作业 / 采集状态
┌─ 数据面（引擎：开源，不自研）───────────────────────────────────────────┐
│  SeaTunnel(Zeta)  集成：源→总线→湖/仓                                    │
│  Flink / SeaTunnel 流计算：实时聚合、CEP、告警                            │
│  Spark / SeaTunnel 批计算：离线加工、DWD/DWS 生成、compaction             │
│  DolphinScheduler  调度：周期 / 事件触发（**只调度批**）                   │
└───────────────────────────────┬───────────────────────────────────────┘
                                │
┌─ 存储层 ───────────────────────────────────────────────────────────────┐
│  Kafka        总线（缓冲 / 重放 / 多消费者）                              │
│  Iceberg+MinIO  湖（ODS / DWD / DIM，明细与历史）                        │
│  ClickHouse   仓（DWS / ADS，聚合与服务化）                              │
│  PostgreSQL   平台元数据与业务库                                         │
│  Redis        缓存与状态（实体最新状态、幂等窗口）                         │
│  Qdrant/Milvus 向量库（非结构化检索，SeaTunnel 有 sink）                  │
└────────────────────────────────────────────────────────────────────────┘

横切：元数据采集 · 质量校验 · 权限策略 · 血缘解析 · 可观测（Prometheus/Grafana/OTel）
```

**一句话读法**：控制面自己写，数据面用开源引擎，存储层用成熟组件；**元数据中枢横跨控制面与治理面**。

## 2. 控制面模块清单

| 模块 | 职责 | 输入 | 输出 | 关键依赖 |
|---|---|---|---|---|
| **项目管理** | 项目/租户隔离、成员与角色 | 管理员操作 | 隔离边界 | PG |
| **源与凭证** | 源注册、凭证引用解析、轮换 | 源声明 YAML | 源实例 + 凭证句柄 | 密钥服务 / K8s Secret |
| **配置生成器** | 源声明 + 模板 → 引擎作业配置 | 源声明、模板、变量 | `.conf`（进 Git） | 模板引擎 |
| **作业与版本** | 作业定义、版本、发布、回滚 | 配置生成物 / 手写作业 | 作业版本 | PG + Git |
| **调度适配** | 把批作业挂到调度器；回补、重跑 | 作业定义、依赖 | 调度任务 | DolphinScheduler API |
| **作业实例与水位** | 运行记录、源侧游标、上次成功水位 | 引擎回调 / 轮询 | 实例状态 | PG |
| **DLQ 与重放** | 按原因分类、按时间窗重放 | DLQ 消息、重放请求 | 重放作业 | Kafka + PG |
| **元数据采集** | 从源采集库表字段、周期更新 | 源连接 | dataset / field | PG（+ 可选开源 Catalog） |
| **血缘解析** | 从作业 + 运行时上报生成血缘边 | 作业配置、SQL 解析 | lineage_edge | PG |
| **质量规则引擎** | 规则模板 + 自定义 SQL；事前/事中/事后；**阻断** | 规则、数据 | 校验结果、阻断指令 | PG + 调度器 |
| **权限与脱敏** | 表/字段级权限、PII 脱敏、审批 | 策略、申请 | 策略生效 | PG（Ranger 可选） |
| **指标语义层** | `metric_def` 唯一来源；MQL → SQL | 指标定义、查询 | SQL / 结果 | PG |
| **数据服务网关** | 查询 API 生产与管理、鉴权、限流 | API 定义 | HTTP 响应 | PG + 仓 |
| **可观测聚合** | 健康四态、SLA、告警归因 | 引擎指标、总线指标 | 看板 / 告警 | Prometheus |
| **成本归因** | 存储/计算成本按项目与数据集分摊 | 用量数据 | 成本报表 | PG |

## 3. 数据面：引擎职责与作业形态

| 引擎 | 承担 | 作业形态 | 备注 |
|---|---|---|---|
| **SeaTunnel（Zeta）** | 集成：CDC → 总线；总线 → 湖；文件 → 湖；JDBC 抽数 | 常驻流 + 定时批 | **连接器依赖逐 job 隔离**（选 Zeta 的主因） |
| **Flink / SeaTunnel** | 流计算：实时聚合、窗口、CEP、告警 | 常驻流 | 与集成作业**分开**，各自消费组 |
| **Spark / SeaTunnel** | 批计算：DWD/DWS 生成、回刷、compaction | 定时批 | 与集成作业分开 |
| **DolphinScheduler** | 批任务的周期与依赖 | 调度计划 | **不跑常驻流作业** |

**作业分层原则**（避免巨型作业）：

```text
集成作业（一源一作业）      ← 只做"搬"，不做业务加工
   ↓
加工作业（按主题域）        ← 清洗、关联、聚合
   ↓
服务作业（按指标域）        ← 物化到 ClickHouse / API
```

## 4. 存储层

| 组件 | 用途 | 关键约定 |
|---|---|---|
| **Kafka** | 总线：缓冲、重放、多消费者 | 主题族命名规范；事件流按时间保留；状态流用 compacted topic |
| **Iceberg + MinIO** | 湖：ODS/DWD/DIM | 分区按 `event_date`；**compaction 是常态作业**；schema evolution 开启 |
| **ClickHouse** | 仓：DWS/ADS | `ReplacingMergeTree` 做 upsert；降采样 1m/1h/1d 三级 |
| **PostgreSQL** | 平台元数据 + 业务库 | 控制面的唯一状态源；水位/游标在此 |
| **Redis** | 缓存、幂等窗口、实体最新状态 | 无 compacted topic 时的状态替代方案 |
| **Qdrant / Milvus** | 向量检索 | SeaTunnel 有 sink，向量入库可白拿 |

## 5. 治理面与可观测（横切）

| 能力 | 挂载点 | 说明 |
|---|---|---|
| 元数据采集 | 数据集 | 周期采集源的表/字段，是血缘与质量的输入 |
| 质量校验 | 作业 + 数据集 | **事前**（入湖前校验）、**事中**（加工中）、**事后**（产出后） |
| 阻断 | 调度 | 质量不达标 → **拦住下游任务**（不只是发报警） |
| 血缘 | 作业 + 数据集 | 由作业定义 + SQL 解析 + 运行时上报三路合成 |
| 权限 | 数据集 + 字段 | 表级 + 字段级（PII）+ 审批流 |
| 可观测 | 全部 | 作业指标、总线指标、端到端 SLI、健康四态、**静默检测** |
| 成本 | 存储 + 计算 | 按项目/数据集分摊，出治理看板 |

## 6. 技术选型总表（自研 vs 开源）

| 能力 | 选型 | 自研程度 | 理由 |
|---|---|---|---|
| 集成引擎 | **SeaTunnel（Zeta）** | 配置生成 + 按 SPI 二开连接器 | ~200 连接器；逐 job 依赖隔离 |
| 流 / 批计算 | Flink / Spark | 作业模板化 | 不重造计算引擎 |
| 调度 | **DolphinScheduler** | 元数据打通 + 封装 | 纯投入无差异，不自研 |
| 湖 / 仓 | Iceberg+MinIO / ClickHouse | DDL + 作业 | —— |
| 总线 | Kafka | 主题族规范 | 见 `数据集成设计.md` §3 |
| 平台元数据库 | PostgreSQL | —— | —— |
| **元数据 / Catalog / 血缘** | **自研**（OpenMetadata/DataHub 可兜底） | 高 | 需要贴合自己的模型 |
| **质量规则引擎** | **自研**（单规则可复用 GX/Soda） | 中高 | 要能"阻断" |
| **指标语义层** | **自研** | 高 | 差异化所在；AI 问数的前提 |
| **数据服务网关** | **自研** | 中 | —— |
| 权限与脱敏 | 自研（Ranger 可选） | 中 | 表/字段级 + 审批 |
| 可观测 | Prometheus + Grafana + OTel | 低 | 不重造 |
| 配置与发布 | Git + CI（如 GitHub Actions / GitLab CI） | 低 | GitOps |

## 7. 关键链路（端到端）

### 链路 1：新增一个源（**P1 的核心验收**）

```text
① 人写 sources/xxx.yaml（连接 + 凭证引用 + collections）
② 控制面校验：连通性 · 权限 · schema · 配额
③ 配置生成器渲染 jobs/xxx.conf（注入信封 transform）
④ CI：配置语法 + 契约校验 → 合并
⑤ 提交引擎（SeaTunnel）→ 采集状态与指标
⑥ 元数据采集：把源表字段写入 dataset/field
⑦ 血缘：dataset → 主题 → 湖表
```
**判据**：全程不改代码、不登录服务器。

### 链路 2：一次离线抽数（批）

```text
调度器触发
  → 控制面取水位 → 渲染 conf（注入 watermark / 分片参数）
  → SeaTunnel BATCH 作业（分片并行读 → 信封 → Iceberg upsert）
  → 成功后回写水位（PG）
  → 质量校验（事前/事后）→ 不达标则阻断下游
```

### 链路 3：一次实时 CDC 到湖仓

```text
MySQL-CDC 作业 → Kafka 主题族
   ├─ 落湖作业（独立消费组）→ Iceberg ODS（+ 定期 compaction）
   ├─ 实时聚合作业（独立消费组）→ ClickHouse DWS
   └─ 质量/告警作业（独立消费组）→ 告警与 DLQ
```

### 链路 4：一次问数（**P5，依赖语义层**）

```text
用户问题 → Agent 解析为 MQL（指标 + 维度 + 过滤）
        → 语义层把 MQL 确定性翻译成 SQL（含口径、join、聚合规则）
        → 数据服务网关执行（鉴权 + 限流）
        → 返回结果 + 口径说明 + 数据时间范围
```
**关键**：Agent **不直接生成 SQL**（避免"概率性猜测"），口径由语义层保证唯一。

## 8. 部署形态

| 环境 | 形态 | 说明 |
|---|---|---|
| 开发 | docker-compose | 单机全栈；**沿用旧项目踩出来的纪律**：healthcheck、`mem_limit`、宿主端口避让、单一配置源 |
| 测试 | compose 或小 K8s | 与开发同构 |
| 生产 | **K8s** | 引擎与网关无状态化；状态在有状态组件与 PG |

**从旧实现继承的工程纪律**（不是代码，是踩坑换来的）：

1. **资源预算要算清**：把所有容器的 `mem_limit` 加总，与宿主机内存对比——旧实现曾因"六容器 + 1 万长连接"打穿 6GB VM
2. **健康检查必须端到端**（探端点），不是"进程还在"
3. **端口显式避让**（不与宿主常用端口冲突）
4. **单一真相源**：同一份配置/口径只定义一次
5. **门禁脚本化**：资源预算、文档一致性、链路健康、端到端 e2e、重启恢复

## 9. 非功能要求

| 维度 | 要求 |
|---|---|
| **性能** | 端到端可见延迟：实时路径秒级、批路径分钟级；lag 可观测 |
| **可用性** | 一源故障不影响其它源；引擎作业可重启并从 checkpoint/水位恢复 |
| **一致性** | 幂等优先；能 exactly-once 则 exactly-once，否则"至少一次 + 幂等键" |
| **安全** | 凭证不落明文；表/字段级权限；PII 打标与脱敏；全操作审计 |
| **可演进** | schema 演进不中断管道；新增源不改主链路；引擎/连接器版本可灰度 |
| **成本** | 存储分层（热/冷）、计算配额、成本归因可查 |
| **可观测** | 健康四态 + 静默检测；端到端 SLI 有分位 |

## 10. 自研边界（明确不做什么）

| 不写 | 用谁 |
|---|---|
| 集成引擎与通用连接器框架 | SeaTunnel（缺口才按 SPI 二开） |
| 流/批计算引擎 | Flink / Spark |
| 调度引擎 | DolphinScheduler |
| 消息中间件 | Kafka |
| 湖/仓存储引擎 | Iceberg / ClickHouse |
| 监控与追踪底座 | Prometheus / Grafana / OTel |
| 表格式与元数据存储格式 | Iceberg |

**只写这四样**：

1. **控制面**（元数据中枢 + 开发运行 + 治理 + 服务语义）
2. **推式接入网关**（若 P1 决定收推式源；只做鉴权 + 幂等 + 写 Kafka，不做解析）
3. **非结构化管道**（Python：解析 / 分块 / 向量化，向量入库可白拿 SeaTunnel sink）
4. **私有协议编解码**（Rust，通过 FFI 或独立进程）

## 11. 代码组织（建议）

```text
engineering/data-platform/
├── design/                    ← 本套设计文档
├── control-plane/             Java：元数据中枢 · 开发运行 · 治理 · 服务语义
│   ├── metadata/              元数据采集 · Catalog · 血缘
│   ├── integration/           源 · 凭证 · 配置生成 · 提交 · 水位 · DLQ
│   ├── governance/            质量 · 权限 · 审计 · 成本
│   ├── semantic/              指标定义 · MQL → SQL
│   ├── service/               数据服务网关
│   └── common/                契约定义（信封 / 命名规范 / schema）
├── jobs/                      引擎作业（生成物 + 手写）
│   ├── integration/           SeaTunnel 集成作业
│   ├── transform/             加工作业（DWD/DWS）
│   └── ops/                   compaction · 兜底扫描
├── gateway/                   推式接入网关（可选，见待定项 #1）
├── unstructured/              Python：文档解析 / 分块 / 向量化
├── codec/                     Rust：私有协议编解码
├── deploy/                    compose（开发）· K8s manifests（生产）
└── scripts/                   门禁脚本（资源预算 / 链路健康 / e2e / 重启恢复）
```
