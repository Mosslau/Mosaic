# 数据模型（草案 · M0 / 02）

> 状态：草案，待评审。
> 关联文档：`00-主线项目书.md` · `01-原型架构.md` · `03-里程碑与验收.md` · `数据集成设计.md`
> 定位：定义平台的**元数据中枢模型**、**物理表结构**与**跨模块契约**。平台的能力上限由本模型决定。

---

## 1. 设计原则

| # | 原则 | 说明 |
|---|---|---|
| 1 | **元数据是中枢** | 血缘、影响分析、成本、权限、质量**全部挂在「数据集 dataset」上** |
| 2 | **状态与定义分离** | 作业**定义**（版本化）与作业**运行状态**（水位/实例）分开存 |
| 3 | **源侧与引擎侧状态分离** | 源侧游标（读到哪）= 重放起点；引擎 checkpoint（落到哪）由引擎自管 |
| 4 | **一切可版本化** | 作业、schema、指标、权限策略都有版本；变更可追溯、可回滚 |
| 5 | **软删除 + 审计** | 定义类实体不物理删除；所有变更入审计 |
| 6 | **契约集中定义** | 信封、命名规范、MQL、规则 DSL 只在 `common/contracts` 定义一次 |

## 2. 概念模型

```text
        ┌──────────┐
        │ project  │ 项目/租户（隔离边界）
        └────┬─────┘
             │ 1..n
   ┌─────────┼──────────────┬───────────────┬──────────────┐
   │         │              │               │              │
┌──▼───┐ ┌───▼────┐   ┌─────▼─────┐   ┌─────▼─────┐  ┌─────▼────┐
│source│ │  job   │   │  metric   │   │  policy   │  │   api    │
│数据源│ │  作业  │   │  指标定义 │   │  权限策略 │  │ 数据服务 │
└──┬───┘ └───┬────┘   └─────┬─────┘   └───────────┘  └──────────┘
   │ 1..n    │ 1..n         │
┌──▼─────┐ ┌─▼──────────┐  │
│dataset │ │job_version │  │
│数据集  │ │job_instance│  │
│(中枢)  │ │job_cursor  │  │
└──┬─┬───┘ └─┬──────────┘  │
   │ │       │             │
   │ │  ┌────▼────────┐    │
   │ │  │lineage_edge │◀───┘（指标血缘同构，单独表）
   │ │  │  血缘边     │
   │ │  └─────────────┘
   │ │
   │ └─▶┌───────────────┐
   │    │quality_rule   │
   │    │quality_result │
   │    └───────────────┘
   └───▶┌───────────────┐
        │dataset_field  │ → PII 标签 / 数据标准
        │schema_version │
        └───────────────┘
```

**核心关系**：`project → source → dataset → field`，`job` 通过血缘边与 `dataset` 相连。

## 3. 命名对齐（与《数据集成设计》）

《数据集成设计》v2 用的是"同步任务"语汇，本模型统一为"作业"语汇。**以本模型为准**：

| 数据集成设计里的叫法 | 本模型统一为 | 说明 |
|---|---|---|
| `data_source_collection` | **`dataset`** | 更通用（表/主题/文件前缀都是数据集） |
| `sync_task` | **`job`（type=integration）** | 作业是统一抽象，集成只是其中一类 |
| `sync_run` | **`job_instance`** | —— |
| `sync_cursor` | **`job_cursor`** | —— |
| `source_health` | **`job_health`（视图）** | 健康是按作业算的 |

> `数据集成设计.md` 后续修订时同步替换这几处命名。

## 4. 物理模型（PostgreSQL DDL）

### 4.1 项目与源

```sql
-- 项目/租户：隔离边界
CREATE TABLE project (
  id            BIGSERIAL PRIMARY KEY,
  code          TEXT NOT NULL UNIQUE,              -- 短码，用于命名前缀
  name          TEXT NOT NULL,
  owner         TEXT NOT NULL,
  status        TEXT NOT NULL DEFAULT 'active',    -- active | archived
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 数据源
CREATE TABLE data_source (
  id            BIGSERIAL PRIMARY KEY,
  project_id    BIGINT NOT NULL REFERENCES project(id),
  code          TEXT NOT NULL,                     -- 源短码，如 biz-mysql
  name          TEXT NOT NULL,
  source_type   TEXT NOT NULL,                     -- cdc | jdbc | kafka | http | s3 | socket | ...
  dialect       TEXT,                              -- 库方言（jdbc 用：mysql | postgres | Dameng | Kingbase | ...）
  conn_config   JSONB NOT NULL,                    -- 连接参数（不含明文凭证）
  cred_ref      TEXT,                              -- 凭证引用，如 secret://prod/biz-mysql-ro
  owner         TEXT NOT NULL,
  limits        JSONB NOT NULL DEFAULT '{}',       -- {"qps":2000,"max_parallelism":8}
  status        TEXT NOT NULL DEFAULT 'draft',     -- draft | validating | active | paused | archived
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (project_id, code)
);
-- 凭证明文绝不入库：cred_ref 只是引用，由密钥服务解析

-- 数据集（**中枢实体**）
CREATE TABLE dataset (
  id            BIGSERIAL PRIMARY KEY,
  source_id     BIGINT NOT NULL REFERENCES data_source(id),
  name          TEXT NOT NULL,                     -- 表名 / 主题名 / 对象前缀
  dataset_type  TEXT NOT NULL,                     -- table | topic | file_prefix | api_resource
  entity_type   TEXT,                              -- 业务实体类型（信封的 entity_type 来源）
  primary_keys  TEXT[],                            -- 主键（决定幂等与 upsert）
  cursor_field  TEXT,                              -- 增量水位字段（如 updated_at）
  partition_keys TEXT[],                           -- 目标分区键
  target_topic  TEXT,                              -- 落到哪条主题族
  target_table  TEXT,                              -- 落到哪张湖/仓表
  write_mode    TEXT NOT NULL DEFAULT 'append',    -- append | upsert | overwrite
  is_pii        BOOLEAN NOT NULL DEFAULT false,    -- 是否含 PII（粗粒度）
  owner         TEXT,
  status        TEXT NOT NULL DEFAULT 'active',
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (source_id, name)
);

-- 字段（元数据采集的产物）
CREATE TABLE dataset_field (
  id            BIGSERIAL PRIMARY KEY,
  dataset_id    BIGINT NOT NULL REFERENCES dataset(id) ON DELETE CASCADE,
  ordinal       INT NOT NULL,
  name          TEXT NOT NULL,
  data_type     TEXT NOT NULL,                     -- 源类型
  mapped_type   TEXT,                              -- 平台类型（BOOLEAN/INT/BIGINT/TIMESTAMP/STRING/...）
  nullable      BOOLEAN NOT NULL DEFAULT true,
  is_pii        BOOLEAN NOT NULL DEFAULT false,
  pii_class     TEXT,                              -- 如 id_card | phone | email
  std_code      TEXT,                              -- 数据标准编码（配置中心）
  comment       TEXT,
  UNIQUE (dataset_id, name)
);

-- schema 版本（演进追踪）
CREATE TABLE schema_version (
  id            BIGSERIAL PRIMARY KEY,
  dataset_id    BIGINT NOT NULL REFERENCES dataset(id) ON DELETE CASCADE,
  version       INT NOT NULL,
  schema_json   JSONB NOT NULL,                    -- 该版本的字段快照
  change_type   TEXT NOT NULL,                     -- create | add_column | drop_column | type_change
  change_detail JSONB,
  detected_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (dataset_id, version)
);
```

### 4.2 作业与运行状态

```sql
-- 作业定义（统一抽象）
CREATE TABLE job (
  id            BIGSERIAL PRIMARY KEY,
  project_id    BIGINT NOT NULL REFERENCES project(id),
  code          TEXT NOT NULL,
  name          TEXT NOT NULL,
  job_type      TEXT NOT NULL,                     -- integration | transform | quality | service | ops
  mode          TEXT NOT NULL,                     -- stream | batch | event | service
  owner         TEXT NOT NULL,
  schedule      JSONB,                             -- {"type":"cron","expr":"0 2 * * *"} / {"type":"continuous"}
  depends_on    BIGINT[],                          -- 上游 job id（跨周期依赖另见 job_dependency）
  status        TEXT NOT NULL DEFAULT 'draft',     -- draft | validating | active | paused | archived
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (project_id, code)
);

-- 作业版本（配置生成物绑定版本）
CREATE TABLE job_version (
  id            BIGSERIAL PRIMARY KEY,
  job_id        BIGINT NOT NULL REFERENCES job(id) ON DELETE CASCADE,
  version       INT NOT NULL,
  config_path   TEXT NOT NULL,                     -- jobs/xxx.conf 的仓库路径
  config_hash   TEXT NOT NULL,                     -- 内容哈希，便于比对
  engine        TEXT NOT NULL,                     -- seatunnel | flink | spark | sql
  engine_version TEXT,                             -- 引擎版本（兼容矩阵）
  created_by    TEXT NOT NULL,
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (job_id, version)
);

-- 作业实例（运行记录）
CREATE TABLE job_instance (
  id            BIGSERIAL PRIMARY KEY,
  job_id        BIGINT NOT NULL REFERENCES job(id),
  job_version   INT NOT NULL,
  engine_job_id TEXT,                              -- 引擎侧作业 id（用于查询/停止）
  status        TEXT NOT NULL,                     -- running | success | failed | cancelled
  started_at    TIMESTAMPTZ,
  finished_at   TIMESTAMPTZ,
  rows_read     BIGINT,
  rows_written  BIGINT,
  error_class   TEXT,                              -- retryable | data | fatal
  error_detail  TEXT,
  triggered_by  TEXT,                              -- scheduler | manual | replay | backfill
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_job_instance_job_time ON job_instance (job_id, started_at DESC);

-- 游标与水位（**源侧状态，重放起点**）
CREATE TABLE job_cursor (
  id            BIGSERIAL PRIMARY KEY,
  job_id        BIGINT NOT NULL REFERENCES job(id) ON DELETE CASCADE,
  dataset_id    BIGINT REFERENCES dataset(id),
  cursor_type   TEXT NOT NULL,                     -- offset | lsn | updated_at | etag | seq | hash
  cursor_value  TEXT,                              -- 当前游标（读到哪）
  watermark     TEXT,                              -- 上次成功窗口（批任务用）
  checkpoint_ref TEXT,                             -- 引擎 checkpoint 引用（落点）
  updated_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (job_id, dataset_id)
);
-- 注意：cursor_value（读到哪）与 checkpoint_ref（落到哪）分列存储，
-- 重放时回拨 cursor_value，由下游幂等吸收重复

-- 作业依赖（含跨周期）
CREATE TABLE job_dependency (
  id            BIGSERIAL PRIMARY KEY,
  job_id        BIGINT NOT NULL REFERENCES job(id) ON DELETE CASCADE,
  upstream_job_id BIGINT NOT NULL REFERENCES job(id),
  dep_type      TEXT NOT NULL DEFAULT 'same_cycle',-- same_cycle | cross_cycle | custom
  offset_cycles INT NOT NULL DEFAULT 0,            -- 跨周期偏移
  UNIQUE (job_id, upstream_job_id, dep_type)
);
```

### 4.3 血缘（含指标血缘）

```sql
-- 表/数据集级血缘（边表，支持递归影响分析）
CREATE TABLE lineage_edge (
  id            BIGSERIAL PRIMARY KEY,
  upstream_type TEXT NOT NULL,                     -- dataset | metric | job
  upstream_id   BIGINT NOT NULL,
  downstream_type TEXT NOT NULL,
  downstream_id BIGINT NOT NULL,
  transform_type TEXT NOT NULL,                    -- copy | aggregate | join | filter | derive
  job_id        BIGINT REFERENCES job(id),         -- 由哪个作业产生
  discovered_by TEXT NOT NULL,                     -- config | sql_parse | runtime
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (upstream_type, upstream_id, downstream_type, downstream_id, job_id)
);
CREATE INDEX idx_lineage_up ON lineage_edge (upstream_type, upstream_id);
CREATE INDEX idx_lineage_down ON lineage_edge (downstream_type, downstream_id);

-- 字段级血缘（P3 需要）
CREATE TABLE lineage_field_edge (
  id            BIGSERIAL PRIMARY KEY,
  upstream_dataset_id BIGINT NOT NULL,
  upstream_field TEXT NOT NULL,
  downstream_dataset_id BIGINT NOT NULL,
  downstream_field TEXT NOT NULL,
  expression    TEXT,                              -- 变换表达式
  job_id        BIGINT REFERENCES job(id),
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

### 4.4 质量

```sql
-- 质量规则（模板 + 自定义 SQL）
CREATE TABLE quality_rule (
  id            BIGSERIAL PRIMARY KEY,
  project_id    BIGINT NOT NULL REFERENCES project(id),
  code          TEXT NOT NULL,
  name          TEXT NOT NULL,
  target_type   TEXT NOT NULL,                     -- dataset | metric
  target_id     BIGINT NOT NULL,
  rule_kind     TEXT NOT NULL,                     -- not_null | unique | range | enum | regex | referential | custom_sql | freshness | volume
  rule_config   JSONB NOT NULL,                    -- 规则参数（阈值、字段、SQL）
  severity      TEXT NOT NULL DEFAULT 'warn',      -- warn | error | **block**（阻断下游）

  status        TEXT NOT NULL DEFAULT 'active',
  owner         TEXT NOT NULL,
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),

-- 校验结果

  job_instance_id BIGINT REFERENCES job_instance(id),
  biz_date      DATE,                              -- 业务日期（分区）
  passed        BOOLEAN NOT NULL,
  metric_value  NUMERIC,
  threshold     NUMERIC,
  sample        JSONB,                             -- 失败样本（限量）
  blocked       BOOLEAN NOT NULL DEFAULT false,    -- 是否已阻断下游
  checked_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_quality_result_rule_time ON quality_result (rule_id, checked_at DESC);
```

### 4.5 指标语义层

```sql
-- 指标定义（**口径唯一来源**）
CREATE TABLE metric_def (
  id            BIGSERIAL PRIMARY KEY,
  project_id    BIGINT NOT NULL REFERENCES project(id),
  code          TEXT NOT NULL,                     -- 指标编码
  name          TEXT NOT NULL,                     -- 中文名
  definition    TEXT NOT NULL,                     -- 口径描述（人读）
  metric_type   TEXT NOT NULL,                     -- atomic | derived | composite
  expr          TEXT NOT NULL,                     -- SQL 表达式（口径落地）

  grain         TEXT,                              -- 粒度（day/hour/1m）
  dimensions    JSONB NOT NULL DEFAULT '[]',       -- 可用维度

CREATE TABLE metric_dependency (
  id            BIGSERIAL PRIMARY KEY,
  metric_id     BIGINT NOT NULL REFERENCES metric_def(id) ON DELETE CASCADE,
  depends_on_metric_id BIGINT NOT NULL REFERENCES metric_def(id),
  UNIQUE (metric_id, depends_on_metric_id)
);

-- MQL 查询记录（问数审计与效果度量）
CREATE TABLE mql_query (
  id            BIGSERIAL PRIMARY KEY,
  question      TEXT NOT NULL,                     -- 自然语言
  mql           JSONB NOT NULL,                    -- 解析出的 MQL
  generated_sql TEXT,
  api_id        BIGINT,
  caller        TEXT,
  latency_ms    INT,
  success       BOOLEAN NOT NULL,
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

### 4.7 健康（视图，不是表）

```sql
-- 健康四态由指标聚合得出，不落表
CREATE VIEW job_health AS
SELECT j.id AS job_id,
       j.code,
       CASE
         WHEN i.status = 'failed'  THEN 'failed'
         WHEN i.status = 'running' AND i.started_at < now() - interval '2 hours' THEN 'degraded'
         WHEN max(i.finished_at) < now() - interval '2 days' THEN 'silent'   -- **静默也是异常**
         ELSE 'healthy'
       END AS health
FROM job j
LEFT JOIN job_instance i ON i.job_id = j.id;
```

## 5. 跨模块契约

### 5.1 统一事件信封（`contracts/envelope.json`）

所有源进总线前必须转成它。字段与《数据集成设计》§5 一致：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `envelope_version` | string | ✅ | 契约版本 |
| `source` | string | ✅ | 源短码（`project.source`） |
| `source_type` | string | ✅ | cdc / jdbc / kafka / http / s3 / socket |
| `tenant` | string | ✅ | 租户/项目 |
| `entity_type` | string | ✅ | 业务实体类型（来自 dataset.entity_type） |
| `entity_id` | string | ✅ | 实体主键值 |
| `event_type` | string | ✅ | created / updated / deleted / snapshot |
| `event_time` | timestamp | ✅ | 事件时间（水位与分区依据） |
| `ingest_time` | timestamp | ✅ | 接入时间（延迟度量） |
| `schema_version` | int | ✅ | 对应 `schema_version.version` |
| `idempotency_key` | string | ✅ | **去重唯一依据** |
| `trace_id` | string | | 链路追踪 |
| `payload` | object | ✅ | **源字段原样**（不改名、不丢字段） |

**两条铁律**：`payload` 保持原貌；`event_time` 与 `ingest_time` 必须都留。

### 5.2 命名规范（`contracts/naming.md`）

| 对象 | 规范 | 示例 |
|---|---|---|
| 主题族 | `{env}.{source_type}.{source}.{entity}.v{major}` | `prod.cdc.mysql_biz.order.v1` |
| DLQ 主题 | `{env}.dlq.{source}.{reason}` | `prod.dlq.mysql_biz.schema_mismatch` |
| 湖表 | `{layer}_{entity}_{suffix}` | `ods_order_event` / `dwd_order_event` / `dws_order_1m` |
| 仓表 | `{layer}_{entity}_{grain}` | `dws_order_1m` / `ads_order_daily` |
| 作业 | `{env}-{source}-{dataset}` | `prod-biz-mysql-orders` |
| 指标 | `{domain}_{measure}_{grain}` | `order_amt_1d` |
| 数据集 | `{schema}.{table}` 原样 | `biz.orders` |

### 5.3 DLQ 原因枚举（`contracts/dlq_reason.md`）

`parse_error` · `schema_mismatch` · `validation_error` · `auth_error` · `overflow`
（决定排查路径；不要只存 error 字符串）

### 5.4 MQL 结构（`contracts/mql.json`）

```json
{
  "metrics": ["order_amt_1d"],
  "dimensions": ["region", "channel"],
  "filters": [{"field": "order_status", "op": "in", "value": ["paid"]}],
  "time_range": {"start": "2026-09-01", "end": "2026-09-23", "grain": "day"},
  "order_by": [{"field": "order_amt_1d", "direction": "desc"}],
  "limit": 100
}
```
**语义层负责** MQL → SQL（表关系、聚合规则、口径、权限过滤），**Agent 不直接生成 SQL**。

```json
  "severity": "block",
  "phase": "before",
  "window": {"biz_date": "${biz_date}"}
}
```

## 6. 状态与水位模型

```text
作业一次运行涉及三种状态，必须分开理解：

① 源侧游标 job_cursor.cursor_value   —— "读到哪"（重放起点，平台托管）
② 引擎 checkpoint job_cursor.checkpoint_ref —— "落到哪"（引擎托管）
③ 批任务水位 job_cursor.watermark    —— "上次成功窗口"（平台托管）

重放 = 回拨 ① → 引擎从 ② 之前重写 → 由幂等键吸收重复
```

**规则**：
- 批任务**先写成功、再提交水位**（顺序反了会丢数据）
- 水位 = **上次成功窗口**，不是"上次开始时间"
- 重放必须可指定时间窗，不只能"从头来"

## 7. 演进策略

| 对象 | 演进方式 |
|---|---|
| 源 schema | 采集检测 → 写 `schema_version` → 默认**向后兼容**（允许加可选字段，禁止删改） |
| 事件信封 | `envelope_version` 版本化；加字段兼容，改语义升版本 |
| 湖表 schema | Iceberg `schema-evolution-enabled`，加列自动合并 |
| 指标口径 | 改口径必须升 `version` 且记录变更原因（口径变更要能追溯） |
| 作业配置 | `job_version` 版本化 + `config_hash`；发布/回滚都留审计 |
| 平台表结构 | Flyway/Liquibase 迁移脚本，禁止手工改生产库 |
