## 二、八域说明（选型与落期）

| 能力域 | 职责（文档原话） | 首选选型 | 落期 | 状态 |
|---|---|---|---|---|
| ① 数据集成 | 把所有形态的数据接进来 | SeaTunnel(Zeta) 2.3.x；CDC 用 SeaTunnel CDC 连接器（Flink CDC 备选） | P0 连通 → P1 自助接入 | ⬜ |
| ② 存储底座 | 一份数据、多处可用 | Iceberg 1.6+ / MinIO / Doris 2.x；Trino（可选） | P0 起，P2 分层，P6 备份 | ⬜ |
| ③ 计算引擎 | 三类负载、三类引擎，各司其职 | Flink 1.20 / Spark 3.5 / Doris / Ray（P5） | P0 起，P5 接 Ray | ⬜ |
| ④ 统一目录 | Data+AI 一个 Catalog，一处注册处处可见 | DataHub（Gravitino 持续跟踪） | P0 采集 → P3 全量 + 字段级血缘 | ⬜ |
| ⑤ 开发工作台 | 让生产者自助 | DolphinScheduler + StreamPark（专业工作台不自研） | P1 模板 A/C + 双环境发布 | ⬜ |
| ⑥ 数据治理 | 让数据可信、可控、可追责 | SQL 规则 + DS → Great Expectations；DataHub + OpenLineage；平台内 RBAC（Ranger 后置） | P2 质量 → P3 权限/审计/成本 | ⬜ |

| ⑧ AI 工程化 | AI 从 Demo 到生产，与数据共栈 | LangChain/LangGraph、Milvus、Ray；vLLM / MLflow（规模触发后置） | P5 单期落地 | ⬜ |

## 六、维护规则

1. **不复制结论**——本页只写"哪个域在哪一期有什么"，不重述选型理由、契约条款与通过标准；有冲突以设计文档为准。
2. **状态取值**：⬜ 未开始 / 🚧 进行中 / ✅ 已验收。**✅ 的判据是该期的 V 全部有实测记录**（不是"文档写完"）。
3. **目录创建规则**：只在**该期或该自研件开始产生独立产物**时新建目录（选型报告、实测记录、脚本、部署清单、代码、验证日志）；**不为未开工的期预建空目录**。
4. **同步时机**：完成一条 V 的记录 → 更新状态列；设计文档升版（§ 指针或 V 编号变化）→ 同步本页的指针与 V 列。
5. 本页与设计文档**均无自动化校验**（引用一致性靠人工维护）。
