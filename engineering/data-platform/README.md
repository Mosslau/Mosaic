# 数据平台（data-platform）

> 定位：Mosaic 第 ③ 部分的通用数据平台——以「集成成熟开源 + 薄自研胶水」构建企业级 Data+AI 数据平台，对标 DataWorks / WeData 的能力集。
> 当前状态：**设计阶段（D 阶段路线 v44 · 待评审）；实现未开工**——本目录下没有代码、没有实测记录、没有部署清单。

## 定位与状态

**本页是视图，不是真相源。** 架构、选型、契约、D 阶段细节与验收标准都在 [`通用数据平台建设路线.md`](通用数据平台建设路线.md)；本页只维护：**D 阶段状态、能力域覆盖视图、文档导航**。

建设按**能力域 D 阶段**推进：一个阶段建一个能力域，阶段结束必须有一条端到端证明；D0/D1 先建底座与契约内核，后续每个域完成即注册，D11 做控制面收口，D12 做生产化。

**能力域是 9 个**：8 个数据/业务域 + 第 9 个「平台控制面与运营」（D11）。因为 ⑦ 语义/服务在建设上拆成 D6 语义、D9 服务，所以共 **13 个 D 阶段**。

## 依赖与开工顺序

**默认顺序**：`D0 → D1 → D2 → D3 → D4 → D5 → D6 → D7 → D8 → D9 → D10 → D11 → D12`。

| 阶段 | 前置 | 关键约束 |
|---|---|---|
| D0 | — | 组件一条命令起；先 compose，不追生产 K8s |
| D1 | D0 | 只做契约/注册/健康/trace/账本；门户/配置/作业提交留到 D5 |
| D2 | D1 | Iceberg 为真相源；Doris 只做 serving |
| D3 | D2 | SeaTunnel 批/流/CDC；重放必须幂等 |
| D4 | D2、D3 | Flink/Spark 只在已入湖数据上加工 |
| D5 | D3、D4 | DS 唯一编排 + StreamPark 托管；门户是关键路径 |
| D6 | D2–D5 | 分层建模 + `metric_def` + MQL→SQL |
| D7 | D2–D6 | DataHub/血缘；字段级 ≥90% |
| D8 | D2–D7 | 质量/权限/审计/成本/多租户；**先能管** |
| D9 | D6–D8 | 查询网关/API/BI；**后能放** |
| D10 | D6、D9 + AI 模型网关 | NL→MQL 只产 MQL，不直产 SQL |
| D11 | D0–D10 | 统一控制台/API、跨域编排、trace/成本/台账/可替换性 |
| D12 | D0–D11 + 真实环境 | HA/备份/压测/回滚/TLS；不承诺“无 D12 的生产可用” |

> 门禁：下游阶段可以在契约冻结后先用 stub/fake 并行，但**不得跳过依赖阶段的端到端证明**。
