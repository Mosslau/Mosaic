# 服务化（P4）

> 状态：⬜ 未开始
> 所属平台与单元：data-platform · P4 服务化（类别：期）
> 对应文档：../通用数据平台建设路线.md（工程路线：§6 P4 排期、§7 V33–V37 通过标准）；../../roadmap/智能通用大数据平台工程师.md（职业路线）

## 目标

业务系统能**安全、可控地直接消费数据**——不是把库开放出去，而是经统一网关按口径取数，并且每次调用都可鉴权、可限流、可审计、可统计。

本单元是**纵切型**（形态：纵切）：交付一条"业务系统 → 网关 → 语义层 → serving 层"的可演示取数链路，同时把 BI 通道拉回同一口径。

## 范围与不做

- **范围**：查询网关（鉴权 / 限流 / 审计 / 三种查询模式 `metric_mql` / `sql_template` / `dataset_query`）；API 生命周期（定义 / 版本 / 发布 / 下线）；调用统计（QPS / 延迟 / 错误率 / 调用方排行）；BI 接入（Superset 走 serving 层 + 语义层生成的指标视图）；门户服务目录页。
- **不做**：API 市场、计费、拖拽式编排。

## 技术栈

- **Spring Cloud Gateway**（查询网关：鉴权 / 限流 / 审计 / 路由）
- **Superset**（BI 通道；只接 Doris serving 层与指标视图）
- **OTel**（网关链路追踪，横切栈第二期落地）
- 语义层与指标视图复用 [`../P2-建模与指标/README.md`](../P2-建模与指标/README.md)（**同源同版本**）

## 系统架构

```text
【API 通道】
业务系统 ──▶ 查询网关
                │ ① 鉴权（token → 租户 / 角色 / 表与字段权限）
                │ ② 限流（按调用方配额，超限返回明确错误码，不超时）
                │ ③ 审计（谁、何时、取什么）
                │ ④ 路由三选一：metric_mql │ sql_template │ dataset_query
                ▼
          语义层 MQL → SQL（P2，同源同版本）
                ▼
          Doris serving（只读 serving 层表与指标视图；湖表不直连）

【BI 通道】
Superset ──▶ Doris（同一批指标视图）── 与 API 数值一致（V35）

【生命周期与观测】
定义 → 版本 → 发布 → 下线；调用统计：QPS / 延迟 / 错误率 / 调用方排行（门户服务目录页展示）
OTel 链路：网关 → 语义层 → Doris 一次调用一条 trace
```

## 前置与复用

- **前置单元**：**P2**（语义层与指标视图——没有它就没有"口径唯一"）；**P3**（权限与审计——先能管，才能放出去）。
- **前置条件**：API 版本策略与"破坏性变更"判定标准定稿；限流配额口径（按调用方 / 按租户）评审；Superset 与网关的**同源校验机制**明确（V35 的一致性不能靠人眼看）。
- **复用**：不复用 `algorithms/` 的实验；复用 P1 的身份与密钥方案。
- **产出被谁引用**：P5（问数入口复用网关的鉴权与审计）、P6（压测对象；API 是容量的主要消费者）。

## 验收标准

- [ ] **V33** 业务系统调 API —— 取数正确
- [ ] **V34** 鉴权 / 限流生效 —— 无 token / 过期 / 越权 token 被拒；超配额返回**明确错误码**（不超时）
- [ ] **V35** API 与看板口径一致 —— 同一指标 API 与看板数值相同
- [ ] **V36** API 调用统计可观测 —— 每 API 的 QPS / 延迟 / 错误率可查
- [ ] **V37** API 版本与变更安全 —— 破坏性变更升版本，旧版本仍可用

**交付物**：查询网关（三种查询模式）+ API 生命周期管理 + 调用统计大盘 + Superset 看板（走语义口径）+ 门户服务目录页。

## 实施笔记

- **开工前置条件**（2026-09 拟定）：① P3 的权限与审计可用（否则网关没有可下发的规则）；② 指标视图的再生成链路已在 P2 验证（V18–V20）；③ 网关的限流与审计字段清单评审（审计字段一旦上线，删字段等于破坏合规）。
- **待决策项**：① 三种查询模式各自的默认配额与准入（`sql_template` 是否对业务开放，还是只对内部）；② 破坏性变更的判定标准（返回字段删除 / 类型变化 / 口径变化）；③ 调用统计的保留期与成本。
