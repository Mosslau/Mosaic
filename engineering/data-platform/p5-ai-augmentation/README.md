# AI 增强（P5）

> 状态：⬜ 未开始
> 所属平台与单元：data-platform · P5 AI 增强（类别：期）
> 对应文档：../通用数据平台建设路线.md（工程路线：§6 P5 排期、§7 V38–V44 通过标准）；../../roadmap/智能通用大数据平台工程师.md（职业路线）

## 目标

数据"**能问**"，而且**问得准**——自然语言提问经语义层落到同一套口径上，答案带来源、可复现、越权不泄露。

本单元是**纵切型**（形态：纵切）：交付一条"问题 → MQL → SQL → 答案 + 来源"的可演示链路，外加一条诊断助手链路（RAG + 工具调用）。

## 范围与不做

- **范围**：NL→MQL 解析（LLM **只产 MQL，不产 SQL**）；复用 P2 的 MQL→SQL；问数评测集（≥100 题，可持续回归）；诊断助手（RAG + 工具调用，结论必带引用）；兜底（低置信度转人工、越权返回空、幻觉检测）；模型中心最小版（接入 AI 平台的模型网关 + 本域 Prompt 内容与版本登记）；探索取数通道设计（Jupyter）。
- **不做**：写操作自动化（写库 / 发货 / 退款）、**无评测集上线**。

## 技术栈

- **Milvus**（向量库：指标定义、口径文档、血缘与知识切片检索）
- **Python 栈**：LangChain / LangGraph（编排与工具调用）+ **Jupyter**（探索取数通道）
- **Ray**（批量推理 / embedding——§2.1 与 §3③ 的"P5 启用"在此落地）
- **AI 平台的模型网关**（跨平台依赖：统一模型出口 = 路由 / 审计 / Token 计量；**网关本体由 AI 平台自研**，本平台作为调用方接入）
- 语义层复用 [`../P2-建模与指标/README.md`](../P2-建模与指标/README.md)；网关鉴权与审计复用 [`../P4-服务化/README.md`](../P4-服务化/README.md)

## 系统架构

```text
【问数链路】
问题 ──▶ NL → MQL 解析（LLM）
              │  **只产 MQL，不产 SQL**；全部调用经 AI 平台的模型网关（路由 / 审计 / Token 计量）
              ▼
         语义层 MQL → SQL（P2，同一口径，同源同版本）
              ▼
         Doris serving ──▶ 答案 + 来源（指标定义 / 口径 / 数据时间 / 版本）
              │
   低置信度 ──▶ 明确"需人工确认"      越权 ──▶ 返回空（不报错、不泄露存在性）

【诊断助手】
问题 ──▶ RAG（Milvus 检索指标定义 / 文档 / 血缘）+ 工具调用 ──▶ 结论逐条带引用（无出处不生成）

【评测与兜底】
问数评测集（≥100 题 + 标准答案）──持续回归──▶ 门槛：与人工核对一致率 ≥ 80%
兜底：置信度阈值 → 转人工；越权 → 空；幻觉检测 → 无引用即拒答

【探索取数通道】
Jupyter 直连**湖上明细**（不直连 Doris；承载候选 Kyuubi / Trino，规模触发、启用前评审——§3⑦ 约定 3）
```

## 前置与复用

- **前置单元**：**P2**（语义层是"问得准"的物理前提）、**P4**（网关的鉴权与审计）。
- **跨平台前置**：**AI 平台的模型网关**（其工程路线的 P5 单元底座）——两平台边界按 v36 定稿：模型出口只有一处，本平台不自建 LLM Gateway；若网关未就绪，本单元只能在 mock 模型下完成逻辑层验证（如实标注，不假装跑通）。
- **前置条件**：评测集先于上线（≥100 题，含负例与越权用例）；模型网关的接口契约与配额谈定；PII 在检索与 Prompt 中的处理口径明确。
- **复用**：不复用 `algorithms/` 的实验。
- **产出被谁引用**：P6（生产化压测含问数链路；成本口径含 Token）。

## 验收标准

- [ ] **V38** 问数准确率 —— 评测集（如 100 题）与人工核对一致率 ≥ 80%
- [ ] **V39** 问数口径一致 —— 同问题多次提问结果一致；与人工 SQL 结果一致
- [ ] **V40** 日志证明不直生成 SQL —— 日志可见 Agent 产出 MQL，SQL 由语义层生成
- [ ] **V41** 结论必带来源 —— 每条结论带引用，无出处不生成
- [ ] **V42** 低置信度转人工 —— 低于阈值时明确提示"需人工确认"
- [ ] **V43** 问数越权返回空 —— 不报错、不泄露存在性
- [ ] **V44** 模型出口统一（经 AI 平台模型网关）—— 本域 LLM 调用全经 AI 平台模型网关（日志可证），Token 成本可归因；Prompt 版本可回溯

**交付物**：NL→MQL 链路 + 问数评测集（≥100 题，可回归）+ 诊断助手（RAG + 工具调用，结论带引用）+ 兜底与调用审计 + 门户问数入口 + 模型网关接入（含 Prompt 版本登记）+ 探索取数通道设计。
