## 机制速览（国内代码级框架的通用机制）

**共同机制**：① **多模型适配层**——统一 Provider 接口（OpenAI 兼容 / 国产模型 SDK），应用层不感知模型差异；② **私有化部署机制**——Docker/裸机部署、离线模型接入、数据不出内网；③ **工具注册**——函数调用 schema 声明 + 权限控制。

**代表拆解**：
- **AgentScope（AOP）**：把"智能体"作为一等编程抽象——`AgentMsg` 消息传递 + 分布式 Agent 通信（同进程/跨进程统一），多 Agent 协作靠消息协议而非共享状态
- **DeerFlow（/goal）**：`/goal` 设定完成条件 → 主 Agent 派生子 Agent 并行执行 → 上下文工程（激进摘要 + 子 Agent 隔离上下文）→ 跨会话持续直到目标达成

---
### 机制深挖：MetaGPT 的 SOP 角色流水线

```
用户需求 → PM 角色(写 PRD) → 架构师(出设计) → 工程师(写代码) → QA(验收) → 汇总
```

**机制要点**：角色流水线 = 串行消息传递 + 每角色独立的 system prompt（SOP 文档驱动）；与 CrewAI 的 hierarchical process 同构——都是"把软件工程流程编码为角色链"，差异在 MetaGPT 偏研究演示、CrewAI 偏产品化。

## MetaGPT — 多智能体模拟软件公司

**定位**：把软件开发流程模拟成一家公司——PM 写需求、架构师出设计、工程师写代码、QA 验收，角色流水线协作。

**特点**：多智能体角色分工的经典范式；SOP（标准作业流程）驱动；研究多智能体协作的标杆。

**适合**：研究多 Agent 角色协作范式；需要"软件公司流水线"式产出的实验项目。

## DeerFlow — 字节跳动 SuperAgent harness

**定位**：字节开源的长时域（long-horizon）SuperAgent harness——不只是多 Agent 框架，而是给 Agent 提供完整运行时基础设施。

**特点**：
- `/goal` 命令设定完成条件，Agent 跨多个会话持续工作直到目标达成
- 沙箱执行环境、长期记忆、子 Agent 编排、技能系统、上下文工程（激进摘要 + 子 Agent 隔离上下文）
- 2.0 重写：内置 IM 接入（Telegram/Slack/飞书/微信/钉钉）、TUI、定时调度

**适合**：长期自主任务底座；数据平台 / AI 平台等需要"给定目标、持续执行、跨会话记忆"的场景。

## AgentScope — 阿里通义智能体导向编程

**定位**：智能体导向编程（Agent-Oriented Programming, AOP）——把"智能体"作为一等编程抽象。

**特点**：
- Python/TS/Java 2.0 全面落地（国内稀缺的多语言 Agent 框架）
- 主打企业级分布式多智能体：消息传递、分布式编排、容错
- 支持私有化部署，中文文档完善

**适合**：国内企业级多语言技术栈；需要分布式多智能体 + 私有化的团队。

## Qwen-Agent — 通义官方框架

**定位**：阿里 Qwen 官方 ReAct + 工具调用框架，与通义模型深度绑定。

**特点**：轻量、跟 Qwen 模型能力同步；内置常用工具；文档中文。

**适合**：Qwen 生态开发者；快速原型验证。

## DB-GPT — 数据智能体

**定位**：开源 agentic AI 数据助手框架——面向数据库场景的智能体（自然语言→SQL、数据洞察、报表生成、数据治理）。

**特点**：Text2SQL + 私域数据问答；含多 Agent 协作与 RAG；AWEL 工作流编排；私有化部署。

**适合**：数据平台 / AI 应用层——对数据平台 / AI 平台的 API、指标解释、报表生成有直接参考价值（数据见 [`Agent工具与框架合集.md`](../Agent工具与框架合集.md) 主表）。

## OpenManus — Manus 开源复刻

**定位**：现象级 Agent 产品 Manus 的开源复刻——通用自治 Agent，给定目标自主完成。

**特点**：通用任务执行（浏览、操作、产出）；社区迭代快（当前 ⭐ 639，热度主要来自 Manus 现象而非 Star 量）。

**适合**：体验"通用自治 Agent"范式；作为自主 Agent 参考实现。

## Spring AI Alibaba — Java 生态

**定位**：阿里出品的 Java/Spring 生态 AI 应用框架——让 Spring Boot 项目接入 LLM 与 Agent。

**特点**：与 Spring 生态无缝集成（Bean、自动配置、AOP）；国产模型适配好；Java 企业栈友好。

**适合**：Java 技术栈的企业团队；存量 Spring 项目加 AI 能力。
