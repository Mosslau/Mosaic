# 海外 · 现象级项目详解

> 3 个现象级海外 Agent 项目（2025-2026 新秀 + 2023 鼻祖 AutoGPT）。速览表见 [README.md](README.md)。

| 框架 | 热度 | 定位 |
|:--|:--|:--|
| [**Hermes Agent**（"爱马仕"，Nous Research）](https://github.com/nousresearch/hermes-agent) | ⭐ 23.6万 | 增速最快的 Agent 框架之一：四层持久记忆 + 闭环自我进化，模型无关 |
| [**OpenClaw**（"龙虾"）](https://github.com/openclaw/openclaw) | ⭐ 38.8万 | 本地优先的电脑操控 Agent，2026 年黑马 |
| [**AutoGPT**](https://github.com/Significant-Gravitas/AutoGPT) | ⭐ 18.7万 | 自主 Agent 鼻祖，现为 AutoGPT Platform 持续维护 |

## 机制速览（新秀的通用机制）

**共同机制**：① **持久记忆分层**——短期（会话）/ 长期（跨会话向量库）/ 工作（任务上下文）/ 团队（共享），各层读写权限与生命周期不同；② **闭环自我进化**——任务完成后把经验沉淀为可复用 Skill，下次自动加载（越用越强）；③ **模型无关**——适配层解耦，不绑单一模型。

**代表拆解**：
- **Hermes（四层记忆）**：记忆不是"聊天记录"，而是分层持久化 + 检索注入——回答前先查记忆（brain-first lookup 模式），与 TencentDB-Agent-Memory 等团队记忆方案可对接
- **OpenClaw（电脑操控）**：GUI 操作通过计算机使用（Computer Use）机制——截图 → 视觉定位 → 点击/输入 → 验证，把"Agent 动手"从文件系统扩展到整个桌面

---
### 机制深挖：Hermes 的记忆检索注入

```
任务开始 → brain-first lookup(先查记忆再推理)
  → 检索: 长期记忆(向量) + 工作记忆(会话) + 团队记忆(共享) 分层召回
  → 注入: 相关记忆拼入上下文(带引用) → 模型基于记忆作答
  → 任务结束 → 沉淀: 关键经验压缩为可复用 Skill(下次自动加载)
```

**机制要点**："brain-first lookup"（先查后想）是记忆 Agent 的核心机制——模型不再从零推理，而是**站在记忆上推理**；自我进化 = 任务 → Skill 沉淀 → 复用的闭环，本质是把"经验"转成"可加载的资产"。

## Hermes Agent（爱马仕）— 记忆 + 自我进化

**定位**：Nous Research 出品，2025-2026 增速最快的 Agent 框架（⭐ 23.6万），核心是**四层持久记忆 + 闭环自我进化**。

**特点**：
- **四层持久记忆**：分层记忆架构（短期/长期/工作/团队），跨会话不丢
- **闭环自我进化**：每次任务自动沉淀可复用的 Skill，下次直接调用——"越用越强"
- **模型无关**：不绑定单一模型
- 生态：与 TencentDB-Agent-Memory（团队记忆）等记忆方案集成

**适合**：重视"记忆 + 自我进化"的长期运行 Agent；个人知识助理类场景。

## OpenClaw（龙虾）— 电脑操控

**定位**：本地优先的电脑操控 Agent，2026 年最大黑马之一（⭐ 38.8万）——直接操作你的电脑（文件、应用、浏览器）。

**特点**：
- 本地优先：数据不出本机
- 电脑操控：GUI 操作、跨应用工作流
- 与 Hermes 同为"能动手的 Agent"方向的代表

**适合**：桌面自动化、个人电脑助手；"Agent 动手操作"范式体验。

## AutoGPT — 自主 Agent 鼻祖

**定位**：自主 Agent 的开山鼻祖（⭐ 18.7万）——给定目标自主规划、执行、迭代的范式开创者。

**特点**：现转型为 AutoGPT Platform（平台化）持续维护；自主循环范式（目标 → 规划 → 执行 → 评估 → 迭代）的教科书案例。

**适合**：理解"自主 Agent"历史与范式；平台化自主 Agent 场景。
