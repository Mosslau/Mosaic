# 选型速查

> 快速决策用。规则 + 许可 + 决策矩阵，配合 [README.md](README.md) 的全表。

---

## 一、八条选型规则

```text
数据不能出内网     → Dify / FastGPT 自托管，或 AgentScope 私有化
纯知识库问答       → FastGPT；要复杂工作流 → Dify
非技术团队快速上线  → Coze
Java 企业技术栈    → AgentScope Java 2.0 / Spring AI Alibaba
.NET 企业技术栈    → Microsoft Agent Framework
深度定制 + 写代码   → LangGraph（海外）/ AgentScope（国内）
快速验证多 Agent    → CrewAI
单模型厂商深度绑定  → 对应官方 SDK（OpenAI / Google ADK / Claude）
```

**逐条解读**：

| 规则 | 为什么 | 备选 |
|:--|:--|:--|
| **数据不能出内网** | Dify/FastGPT 支持 Docker 自托管，AgentScope 主打私有化 | 大厂平台私有化版（百炼/千帆） |
| **纯知识库问答** | FastGPT 专精且轻；复杂工作流才需要 Dify 的全套 | RAGFlow（文档解析要求高时） |
| **非技术团队快速上线** | Coze 零代码 + 插件 + 国内渠道一键发布 | Dify（要自托管时） |
| **Java 企业栈** | AgentScope 是少数多语言（含 Java）框架；Spring AI Alibaba 无缝进 Spring | — |
| **.NET 企业栈** | Microsoft Agent Framework 是 AutoGen+SK 的官方继任 | 无 |
| **深度定制 + 写代码** | LangGraph 图编排 + 状态持久化最强；国内对应 AgentScope | dsh（要自建底座时，见 Agent产品对比） |
| **快速验证多 Agent** | CrewAI 上手最快（角色/任务/流程三件套） | OpenAI Agents SDK（Python 极简） |
| **单模型厂商深度绑定** | 官方 SDK 永远跟最新模型能力同步 | 无 |

## 二、开源许可（企业合规必查）

| 许可 | 框架 | 说明 |
|:--|:--|:--|
| **MIT** | LangChain/LangGraph、CrewAI、OpenAI Agents SDK、AutoGen、Pydantic AI、LlamaIndex、MetaGPT | 宽松，商用无忧 |
| **Apache-2.0** | smolagents、AgentScope、Mastra、Google ADK、RAGFlow、Flowise、Dify（社区版，带例外条款） | 宽松 + 专利授权 |
| **fair-code** | n8n | ⚠️ 商用需订阅（可持续许可） |
| **闭源** | Coze（平台版）、阿里云百炼、腾讯云 ADP、百度千帆 | 平台服务，无源码（注：Coze Studio 开源） |

## 三、决策矩阵（按团队画像）

| 团队画像 | 首选 | 理由 |
|:--|:--|:--|
| 个人开发者，写代码 | LangGraph / CrewAI / OpenAI Agents SDK | 生态全、上手快 |
| 国内企业，私有化 | AgentScope / Dify 自托管 | 私有化 + 中文 + 合规 |
| 业务团队，零代码 | Coze / Dify | 可视化 + 渠道/运维 |
| 数据团队，知识库 | RAGFlow / FastGPT / DB-GPT | 解析/RAG/数据智能 |
| 大厂生态内 | 百炼 / ADP / 千帆 / Vertex(Gemini) / Azure(微软) | 云服务 + 治理 |
| 要自建 Agent 底座 | **dsh**（见 [Agent产品对比](../Agent产品对比/README.md)） | 唯一 MIT 开源可换循环 |
