# 🦅 agent-core

**完全自研的 Agent 核心（agent-core）** —— 服务端部署的企业级 Agent 执行引擎设计。

> 状态：**设计存档**（2026-08-27 决定暂不开发，先归档设计；未来如需开发按实施计划推进）

## 定位

在 [frameworks/](../frameworks/) 的**统一平台底座**架构下，agent-core 是**第五个运行时适配器**——唯一完全自研、最可控的 Agent 内核；其《技术架构方案》同时是底座"自研运行时蓝本"与"AI 基础设施（模型网关等）蓝本"。

| | 框架适配器（agentscope / langchain-graph / codex / dsh） | agent-core 自研适配器 |
|---|---|---|
| 技术基座 | 基于框架组装（Python / TS / 闭源） | **完全自研**（Rust，不依赖任何 Agent 框架） |
| 核心循环 | 框架提供的运行时（适配器翻译） | 自研运行时：循环 / 工具 / 策略 / 路由全部自有代码 |
| 接入底座方式 | 运行时端口适配（扩展点注入 / 进程编排 / 插件树） | HTTP/gRPC 直连（端口最干净、最可控） |
| 适用场景 | 快速平台化、多端生态 | 深度定制、性能与可控性优先、长期演进 |

## 设计要点（摘要）

- **技术栈**：Rust + tokio，单二进制部署；HTTP/gRPC API + 会话管理 + 多租户
- **模型接入**：多提供商抽象层（Anthropic / OpenAI / DeepSeek / Qwen / GLM），
  统一接口 + 路由 + fallback + 成本预算
- **场景**：通用任务执行（代码仓库、文档、数据库、运维、审批流），工具按需插拔
- **模式来源**：[tutorials/](../tutorials/) 教学轨道的生产化（s11 错误恢复、s13 并发、s08 压缩、
  s15-18 团队与隔离），逐章移植对照见技术文档第 13 节
