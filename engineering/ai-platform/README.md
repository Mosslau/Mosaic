# AI 平台（ai-platform）

> 定位：Mosaic 第 ③ 部分的 AI 平台——数据（语料/向量/湖仓）+ 算力（K8s/GPU）+ 模型（微调/推理）+ 应用（RAG/Agent）共栈，以「成熟开源集成 + 薄自研胶水」构建企业级 AI 数据中心。
> 当前状态：**设计阶段（D 阶段路线 v12 · 待评审）**；**0/11 完成**；D8 的 Part 1 资料已完成，运行时代码未开始。

## 定位与状态

**本页是视图，不是真相源。** 架构、选型、契约、D 阶段细节与验收标准都在 [`AI平台建设路线.md`](AI平台建设路线.md)；本页只维护：**D 阶段状态、能力域覆盖视图、文档导航**。

建设按**能力域 D 阶段**推进：一个阶段建一个能力域，阶段结束必须有一条端到端证明；D0/D1 先建底座与契约内核，后续每个域完成即注册，最后 D9 收口、D10 生产化。

## 依赖与开工顺序

**默认顺序**：`D0 → D1 → D2 → D3 → D4 → D5 → D6 → D7 → D8 → D9 → D10`。

| 阶段 | 前置 | 关键约束 |
|---|---|---|
| D0 | — | 一条命令起停；先 compose/kind，不追生产 K8s |
| D1 | D0 | 四契约冻结；只做注册/健康/trace/账本，不做门户 |
| D2 | D1 | 10GB 需流式；去重与分片 id 必须幂等 |
| D3 | D2 | 向量库与 LLM 可先用本地/兼容接口 |
| D4 | D2、D3 | 语料与向量同一次提交；snapshot 可复现 |
| D5 | D1、D4（可选） | 无 GPU 用 mock/API；有卡再换 vLLM |
| D6 | D0 | **真实 GPU + K8s 是硬约束**；无卡只做逻辑层 |
| D7 | D6 | 真实微调需要卡；数据/超参/种子入档 |
| D8 | D3、D5 | 沙箱/MCP/网关与 D9 的控制面不重复建设 |
| D9 | D0–D8 | 一条命令拉起全部；trace/成本/台账统一 |
| D10 | D0–D9 + 真实环境 | HA/备份/加密/压测/多租户/SLO |

**有 GPU**：D6 提到 D5 前，先有算力再压推理。
**无 GPU**：D5 先用 mock/API 做逻辑层，D6 等卡；其余阶段不阻塞。

> 门禁：下游阶段可以在契约冻结后先用 stub/fake 并行，但**不得跳过依赖阶段的端到端证明**。
