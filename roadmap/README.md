# roadmap —— 路线图

写给「人、能力、职业」的文档入口。**平台文档不在这里**——平台与平台支撑的业务方向统一在 [`../engineering/docs/`](../engineering/docs/)。

## 内容分层

判据是**看主语**：主语是「人」→ 本目录；主语是「平台 / 系统 / 业务域」→ `engineering/docs/`。

| 层 | 目录 | 回答什么 | 主语 | 典型读者 |
|---|---|---|---|---|
| ① 资料层 | [`01-资料/`](01-资料/) | 该读什么 | 书 / 地图 | 所有人 |
| ② 能力层 | [`02-能力/`](02-能力/) | 一个人能到什么水平、怎么交付、怎么独立商业化 | 「你」 | 个人 |
| ③ 职业层 | [`03-职业/`](03-职业/) | 到什么岗位、按什么顺序走 | 「岗位 / 角色」 | 转型中的人 |

> **为什么没有「个体层」**：原四层里的「④ 个体层（一人公司）」主语仍是「你能独立交付什么」，不是岗位；把它放进 `02-能力/` 作为系列第五篇，避免一个人被拆成两种层级。
>
> 三个目录与三层一一对应，**目录即层级**；新增文档先定层，再定目录，不要平铺回根目录。
