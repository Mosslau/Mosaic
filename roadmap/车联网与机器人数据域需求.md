## A0. 端到端闭环流程（总览）

> 三个模块的共同主线：所有业务域最终都要落到这条链上。

### A0.1 一句话

从设备数据出发，经过语义、知识、推理，变成业务动作，再把动作结果回流，修正下一轮。

### A0.2 流程图

```text
数据 D3 接入 → D2 湖 → D4 计算 → D6 本体/指标 → D9 服务
                                              │ EntityRef / MetricRef
AI D2 文档/多模态 → AI D3 知识引擎 → AI D5 推理 → AI D8 Agent
                                              │
                                  业务动作：工单/派单/调度   ← 外部系统
                                              │
数据 D6/D8 修正 ← AI D9 反馈 ← AI D10 飞轮 ← 业务结果
```

### A0.3 在线环与离线环

| 环 | 时间尺度 | 步骤 | 产出 |
|---|---|---|---|
| 在线环 | 秒~分钟 | D3 → D2 → D4 → D6 → D9 → AI D2/D3 → AI D5 → AI D8 | 诊断、建议、工单/调度动作 |
| 离线环 | 小时~天 | 业务结果 → AI D9 → AI D10 → D6/D8 | 评测集、训练集、本体/指标修正 |

### A0.4 阶段映射

| 步骤 | 做什么 | 阶段 | 产物 |
|---|---|---|---|
| ① 接入 | 遥测、故障、工单、文档进来 | 数据 D3 | Kafka/原始事件 |
| ② 入湖 | 原始数据落湖，保留快照 | 数据 D2 | ODS、Iceberg 快照 |
| ③ 计算 | 清洗、关联、聚合、故障事件 | 数据 D4 | DWD/DWS、故障事件 |
| ④ 语义 | 车辆/机器人、故障码、工单、指标、关系、规则 | 数据 D6 `V6-5` | 实体、关系、指标 |
| ⑤ 服务 | 查询网关/API，带权限和证据 | 数据 D9 | `EntityRef`/`MetricRef` |
| ⑥ 文档加工 | 手册、维修记录、图片、视频切片 | AI D2 `A2-9` | 可检索块、引用定位 |
| ⑦ 知识 | 检索、重排、实体链接、引用 | AI D3 `A3-5`–`A3-7` | 带证据的知识上下文 |
| ⑧ 推理 | 模型生成诊断/建议 | AI D5 | 答案、置信度 |
| ⑨ 行动 | Agent 调工具：建工单、派单、调度 | AI D8 `A8-1`–`A8-3` + 外部系统 | 工单/任务/动作 |
| ⑩ 结果 | 维修完成、误诊、返工、任务完成、成本 | 外部业务系统 | 业务结果 |
| ⑪ 反馈 | 反馈日志、质量看板、漂移告警 | AI D9 `A9-5`/`A9-6` | 反馈数据、评测样本 |
| ⑫ 飞轮 | 反馈 → 评测集 → 训练集，人工审批 | AI D10 `A10-7`/`A10-8` | 新评测集/训练集 |
| ⑬ 修正 | 修正本体、指标、规则、质量 | 数据 D6/D8 | 新版本语义/指标 |

### A0.5 一个例子：车辆故障诊断

```text
车辆上报故障码 P0A1
→ D3 接入 → D2 入湖 → D4 生成故障事件
→ D6 关联车辆/车型/电池/工单
→ D9 提供 EntityRef/MetricRef
→ AI D2 取维修手册/历史工单/图片
→ AI D3 检索 + 实体链接 + 引用
→ AI D5 生成“可能原因/排查步骤”
→ AI D8 建工单/派单
→ 门店维修 → 维修结果回写
→ AI D9 记录误诊/一次修复
→ AI D10 进入评测/训练
→ D6/D8 修正故障码映射/知识
```

没有“工单结果回写”，这条链就是问答，不是闭环。

### A0.6 闭环判据

1. **有动作**：结论能生成工单/派单/调度，不是只输出文字。
2. **有结果**：维修完成、误诊、返工、成本、任务完成能记录。
3. **有回流**：结果进入评测集/故障库/训练数据/本体。
4. **有度量**：诊断准确率、一次修复率、接管率、MTTR 有数字。
5. **有 owner**：谁对“下一轮变好”负责。

缺一条，都是开环。

### A0.7 当前状态

- 数据 D3/D2/D4/D6/D9：设计有，代码没有；
- AI D2/D3/D5/D8/D9/D10：设计有，代码没有；
- 业务动作/结果：只有本文档的场景定义，没有系统；
- 反馈回流：只有 `A9-6`/`A10-8` 验收，没有真实数据。

所以当前是**设计闭环、运行开环**；跑通一条纵切，才叫运行闭环。

# 模块 A：企业级业务域全景

## A1. 业务模型与边界

### A1.1 两条业务线

| 业务线 | 典型产品 | 收入模式 | 核心运营 |
|---|---|---|---|
| 车联网 | 两轮车/电动车/智能硬件 | 卖车、配件、服务、保险、软件订阅 | 渠道、售后、保修、电池、OTA |
| 机器人 | 服务机器人/工业机器人/配送机器人 | 卖机、租赁、RaaS、服务 | 站点、任务、车队、遥操作、安全 |

### A1.2 企业价值链

```text
研发/产品 → 供应链 → 制造 → 销售/渠道 → 交付 → 使用/运营 → 售后 → 电池/能源 → 回收/残值
```

| 环节 | 核心系统 | 核心数据 | 主要问题 |
|---|---|---|---|
| 研发/产品 | PLM、需求/测试管理 | BOM、车型配置、DV/PV、仿真 | 车型/软件版本追溯 |
| 供应链 | SRM、ERP、WMS | 供应商、来料、批次、库存 | 来料质量、缺料、批次召回 |
| 制造 | MES、EOL、QMS | 工单、工位、下线检测、返修 | 良率、EOL 一次通过、追溯 |
| 销售/渠道 | CRM、DMS、订单 | 订单、合同、经销商、交付 | 渠道库存、交付周期 |
| 使用/运营 | TSP、BMS、机器人调度 | 遥测、位置、任务、故障 | 在线率、利用率、安全 |
| 售后 | 工单、备件、呼叫中心 | 报修、诊断、维修、换件 | 一次修复率、MTTR |
| 电池/能源 | BMS、充电/换电 | SOH、循环、充电、换电 | 电池安全、资产、残值 |
| 回收/残值 | 二手/回收/保险 | 车况、里程、维修、残值 | 残值定价、保险损失 |

### A1.3 企业级边界

**做**：

- 车辆/机器人、客户、渠道、售后、质量、电池、OTA、机器人车队的数据平台与 AI 数据侧。
- 与 PLM/ERP/MES/SRM/CRM/DMS 的系统集成。
- 企业级主数据、指标、本体、治理、权限、审计。

**不做**：

- 自动驾驶感知/决策/控制算法。
- 整车 CAN 安全控制、远程驾驶指令。
- OTA 执行引擎（只做数据与审计）。
- 全量标注/合成平台、大规模预训练/RLHF 实跑。
- 多云、商业计费。

## A2. 利益相关者与 RACI

| 角色 | 关心什么 | 关键数据 |
|---|---|---|
| 研发/产品 | BOM、车型配置、软件版本、试验 | PLM、BOM、测试 |
| 供应链 | 供应商、来料质量、库存、批次 | SRM、ERP、WMS |
| 制造/质量 | 良率、EOL、返修、追溯 | MES、QMS、EOL |
| 销售/渠道 | 订单、交付、渠道库存 | CRM、DMS、订单 |
| 售后 | 工单、故障、一次修复 | 工单、诊断、备件 |
| 电池/能源 | SOH、充电/换电、安全 | BMS、充电桩、换电站 |
| 机器人运营 | 任务、站点、遥操作、安全 | 调度、地图、机器人日志 |
| 财务/保险 | 成本、保修、索赔、残值 | 财务、索赔、保险 |
| 法务/合规 | 隐私、数据出境、召回、认证 | 合规、审计、同意 |
| 数据/AI 平台 | 接入、湖仓、本体、指标、Agent | 全量 |

**RACI 原则**：

- 每个数据域必须有业务 owner + 数据 steward。
- 主数据（客户、车辆、机器人、车型、供应商、门店）由业务 owner 定义。
- 数据平台负责“可接入、可治理、可服务”，不替代业务定义。

## A7. 跨域统一模型与契约

企业级统一模型至少包括：

- 客户、车辆/机器人、车型、供应商、门店、工单、故障码、电池、OTA、文档。
- 关系：客户拥有车辆、车辆属于车型、工单维修车辆、索赔关联工单、OTA 适配车型、供应商供应该批次。
- 契约：`EntityRef` / `MetricRef` / `EvidenceRef` / `Policy`。

与平台验收的对应：

- 本体 MVP：D6 `V6-5`（10 实体/20 关系/50 术语/10 规则）。
- 知识引擎：AI D3 `A3-5`–`A3-7`。
- 企业级生产化：数据 D12 `V12-6`、AI D10 `A10-9`。

## A10. 企业级风险与开放问题

| 风险/问题 | 说明 |
|---|---|
| 主数据不统一 | 各系统 ID 不一致，跨域分析失真 |
| 系统边界不清 | PLM/ERP/MES 数据 owner 争议 |
| 制造/供应链数据质量差 | 批次、工位、来料数据缺失 |
| 多品牌/多区域 | 口径、合规、租户隔离差异 |
| 数据出境/隐私 | 位置、车主、影像数据合规 |
| 机器人安全认证 | 事故责任、记录、上报 |
| OTA 合规 | R155/R156、召回、软件版本追溯 |
| 组织 RACI | 数据 owner 不明确，平台背锅 |

**开放问题**：

1. 业务边界：是否包含自动驾驶/ADAS？是否包含 RaaS？
2. 制造模式：自产/代工/混合？MES 是否自有？
3. 渠道模式：直营/经销/混合？
4. 区域：国内/海外？数据驻留要求？
5. 机器人：室内/室外？是否有人身安全风险？
6. 主数据：自建 MDM 还是用 ERP/CRM 主数据？
7. 预算与人力：平台团队、业务 owner、数据 steward 是否到位？

# 模块 B：车联网数据域

## B1. 范围

覆盖两轮车/电动车/智能硬件的车辆、电池、OTA、渠道、售后、保修、保险、残值数据。

不含：自动驾驶感知/控制、整车 CAN 安全控制、OTA 执行引擎。

## B2. 对象与事件

### B2.1 对象

| 对象 | 关键字段 | 来源 |
|---|---|---|
| 车辆 | `vehicle_id`、VIN/SN、车型、状态、车主 | TSP/MES/CRM |
| 车型 | `model_id`、配置、版本 | PLM |
| 电池 | `battery_id`、SOH、循环、批次 | BMS |
| 固件 | `firmware_id`、版本、兼容车型 | OTA |
| 车主 | `owner_id`、区域、联系方式 | CRM |
| 门店/经销商 | `dealer_id`、区域、能力 | DMS |
| 工单 | `workorder_id`、故障码、维修、费用 | 工单 |
| 故障码 | `fault_code`、含义、严重度 | 诊断库 |
| 围栏/区域 | `geofence_id`、多边形 | 地图 |
| 保单/索赔 | `claim_id`、保单、金额、状态 | 保险/保修 |

### B2.2 事件

遥测、故障、告警、离线、碰撞/倾倒、报修、派单、维修、换件、OTA、索赔、召回、进出围栏。

### B2.3 关系与规则

```text
车主 → 拥有 → 车辆
车辆 → 属于 → 车型
车辆 → 装配 → 电池/固件
故障 → 发生在 → 车辆
工单 → 维修 → 车辆
工单 → 引用 → 故障码
门店 → 处理 → 工单
车辆 → 位于 → 围栏
OTA → 适配 → 车型
索赔 → 关联 → 工单/故障码
```

规则：一车一 active 车主；工单必须关联车辆；故障码必须存在；OTA 必须兼容；电池 SOH 低触发告警；索赔必须关联工单；位置/车主脱敏。

## B3. 数据源

TSP、BMS、OTA、CRM、DMS、工单、保修/索赔、保险、地图/围栏、文档/图片、充电/换电。

## B4. 指标

在线率、故障率、MTBF/MTTR、一次修复率、SOH、里程、OTA 成功率、索赔率、召回完成率、残值、保险损失率、围栏违规率。

## B5. AI 场景

| 场景 | 输入 | 输出 | 证据 | 人工 |
|---|---|---|---|---|
| 故障诊断 | 车辆、故障码、遥测、工单、手册 | 原因/步骤/置信度 | 快照/文档/工单 | 高风险转人工 |
| 预测维护 | 遥测、电池、里程、故障史 | 风险名单/保养建议 | 特征/模型版本 | 不自动派单 |
| 保修反欺诈 | 索赔、工单、图片、历史 | 风险分/理由 | 图片/工单/规则 | 人工审核 |
| 门店助手 | 车辆上下文、知识库 | 维修建议/备件 | 引用/工单 | 门店确认 |
| 残值/保险 | 车况、里程、维修、事故 | 残值/风险 | 快照/规则 | 人工复核 |

## B6. 车联网合规

- 车辆认证/homologation、召回、R155 网络安全、R156 软件更新。
- 位置/车主/影像隐私；数据出境；保留/删除。
- 保险/金融合规；事故/安全事件上报。

## B7. D/A 映射

| 能力 | 数据 | AI | 验收 |
|---|---|---|---|
| 车辆/车型/电池/固件 | D6 | — | `V6-5` |
| 遥测/故障/位置 | D3/D4 | — | `V3-1`–`V3-3`、`V4-1` |
| 工单/保修/索赔 | D3/D6/D8 | D3 | `V6-5`、`V8-1`、`A3-5`–`A3-7` |
| 诊断/门店/反欺诈 | D9/D10 | D3 | `V9-1`–`V9-3`、`A3-5`–`A3-7` |
| OTA/安全/合规 | D8/D12 | D10 | `V8-2`、`V12-6`、`A10-9` |

## B8. 验收场景

- S1 故障诊断：车辆→故障→工单→文档→原因/证据。
- S2 预测维护：特征→风险名单→门店确认→工单。
- S3 保修反欺诈：索赔→工单/图片/规则→风险分→人工审核。
- S4 门店助手：车辆上下文→知识库→建议/引用。
- S5 残值/保险：车况/维修/事故→残值/风险。

## B9. 非目标

不做自动驾驶、整车控制、OTA 执行、全量标注/合成、大规模预训练。

# 模块 C：机器人数据域

## C1. 范围

覆盖服务/工业/配送机器人的站点、地图、任务、遥测、感知、遥操作、安全、车队、RaaS。

不含：机器人本体控制、自动驾驶算法训练、全量感知标注平台。

## C2. 对象与事件

### C2.1 对象

| 对象 | 关键字段 | 来源 |
|---|---|---|
| 机器人 | `robot_id`、型号、状态、所属站点 | 调度/资产 |
| 站点 | `site_id`、地址、地图版本 | 站点/地图 |
| 地图 | `map_id`、版本、区域 | 地图 |
| 任务 | `task_id`、类型、起止、状态 | 调度 |
| 行程/路径 | `trip_id`、路径、里程、耗时 | 调度/日志 |
| 遥操作 | `teleop_id`、操作员、原因、时长 | 遥操作 |
| 事故/告警 | `incident_id`、类型、严重度 | 安全/日志 |
| 工单/维保 | `workorder_id`、故障、备件 | 维保 |
| 客户/站点主 | `customer_id`、合同、SLA | CRM/合同 |
| 感知片段 | `clip_id`、类型、时间、位置 | 机器人/对象存储 |

### C2.2 事件

任务开始/结束、路径偏离、围栏、急停、碰撞、人工接管、遥操作、故障、维保、地图更新、软件升级、事故。

### C2.3 关系与规则

```text
机器人 → 属于 → 站点
机器人 → 执行 → 任务
任务 → 关联 → 地图/区域
遥操作 → 接管 → 机器人
事故 → 关联 → 机器人/任务
维保 → 维修 → 机器人
客户 → 拥有 → 站点/机器人
```

规则：机器人必须归属站点；任务必须关联地图；遥操作必须记录操作员/原因；事故必须关联任务；地图版本变更需回归；安全事件不可删除。

## C3. 数据源

机器人调度、机器人日志、地图、遥操作、感知/视频、维保、CRM/合同、RaaS 计费、仿真。

## C4. 指标

任务完成率、利用率、接管率、遥操作率、MTBF/MTTR、事故率、路径偏离率、地图更新频率、RaaS 毛利、SLA 达成率。

## C5. AI 场景

| 场景 | 输入 | 输出 | 证据 | 人工 |
|---|---|---|---|---|
| 车队调度 | 任务、地图、状态、SLA | 调度建议 | 任务/位置/指标 | 调度员确认 |
| 异常诊断 | 日志、遥测、事故 | 原因/步骤 | 日志/快照 | 高风险转人工 |
| 遥操作辅助 | 视频、告警、地图 | 建议动作 | 视频/事件 | 操作员确认 |
| 预测维保 | 遥测、任务、故障史 | 风险/保养 | 特征/模型 | 不自动派单 |
| 地图 QA | 地图、路径、事故 | 地图问题 | 地图/轨迹 | 人工复核 |
| 知识助手 | 手册、工单、事故 | 答案/引用 | 文档/工单 | 低置信转人工 |

## C6. 机器人安全与合规

- 安全认证/风险评估；事故记录/上报；急停/接管审计。
- 摄像头/麦克风/位置隐私；数据保留/删除；跨境。
- RaaS 合同/SLA；责任边界。

## C7. D/A 映射

| 能力 | 数据 | AI | 验收 |
|---|---|---|---|
| 机器人/站点/地图 | D6 | — | `V6-5` |
| 任务/遥测/事故 | D3/D4 | — | `V3-1`、`V4-1` |
| 车队调度 | D9 | D8 | `V9-1`–`V9-3`、`A8-1`–`A8-3` |
| 诊断/知识 | D9/D10 | D3 | `A3-5`–`A3-7` |
| 安全/合规 | D8/D12 | D10 | `V8-2`、`V12-6`、`A10-9` |

## C8. 验收场景

- R1 任务调度：任务→机器人→路径→完成/失败。
- R2 事故诊断：事故→日志/视频→原因/证据。
- R3 遥操作：告警→接管→操作记录→复盘。
- R4 预测维保：遥测→风险→维保工单。
- R5 地图 QA：地图/路径/事故→问题清单→更新。

## C9. 非目标

不做机器人本体控制、自动驾驶算法训练、全量感知标注、远程控制指令下发。
