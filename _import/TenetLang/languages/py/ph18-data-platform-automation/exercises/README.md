## 练习 1：平台日志解析器（★★）

- **目标**：解析文本行格式的平台采集日志，按日志来源 ID 做流式统计（对应 roadmap「平台日志解析器」）
- **要求**：
  - 输入一行格式 `(时间戳) 采集节点 ID#HEX数据`（如 `(1700000000.100) node0 123#0100000000000000`）；ID 为 hex，数据最多 8 字节
  - 必须**流式**：逐行产出，不得 `readlines()` 整读（生成器或逐行 for 均可）
  - 统计每来源 ID 的记录数、首/末记录时间戳、平均周期（`(末-首)/(条数-1)`）
  - 注释行（`#` 开头）与格式非法行跳过不中断，统计出「脏行数」
  - 至少写一个可复现的样例日志生成函数（落 /tmp）
- **验收**：给定内置样例输出 `0x123: 3 条, 平均周期 0.040s` 且脏行数正确；`python3 -m pytest sol-01-log-parser.py -q` 全绿（把实际输出写进验证块）

## 练习 2：指标数据清洗工具（★★★）

- **目标**：做一个 CSV → CSV 的指标数据清洗工具，输出「干净数据 + 可审计的清洗报告」（对应 roadmap「指标数据清洗工具」）
- **要求**：
  - 输入列：`ts, service_id, latency_ms, cpu_pct, mem_used_gb, disk_temp_c, net_io_mb_s, power_w`
  - 清洗动作按顺序：① 按 `(ts, service_id)` 去重 ② 非法数值（空/非数字/缺列）拒收为解析错误 ③ 按物理量程剔除（自行定义合理量程并写进常量表）
  - 每一步都要计数（报告里有明细），保留行写干净 CSV —— 「清洗可审计」是硬要求
  - 加 CLI：`--input` / `--output`；加一个生成脏样例 CSV 的入口（含重复行/越界值/坏数值）
  - 加分项：证明工具「幂等」——干净数据再过一遍清洗不应丢行
- **验收**：样例含 10 正常行 + 1 重复 + 2 越界 + 1 坏值 → 输出恰 10 行且各剔除计数为 1；`python3 -m pytest sol-02-metrics-clean.py -q` 全绿

## 练习 3：发布测试报告生成（★★★）

- **目标**：把一次服务发布的逐实例结果汇总成「版本级验收」测试报告（对应 roadmap「发布测试报告生成」，呼应必会概念「自动化测试要可重复和可审计」）
- **要求**：
  - 数据形态：每行一次发布尝试（服务实例、目标版本、结果 success/failed/rollback/timeout、失败原因码、耗时）
  - 产出内容：总体成功率、**分目标版本**成功率表、失败原因分布表、发布耗时统计
  - 报告为固定格式 Markdown 文本（可归档进 CI 做自动比对——golden 化）
  - 用 dataclass 表达一次尝试；清洗/统计函数与报告渲染分离，统计函数可单独单测
  - 构造一组**确定性**样例（不靠随机，断言要能写出精确值）
- **验收**：报告含三个必要章节与版本成功率行（如 `| 1.2.0 | 8 | 6 | 75.0% |`）；`python3 -m pytest sol-03-release-report.py -q` 全绿

## 练习 4：MQTT 数据采集服务（★★★）

- **目标**：实现一个 MQTT 指标采集服务：订阅 → 校验/去重 → 按日分桶 JSONL 落盘（对应 roadmap「MQTT 数据采集服务」）
- **要求**：
  - 主题树 `svc/<service_id>/metrics`；载荷为 JSON（至少含 `ts, latency_ms, cpu_pct, mem_used_gb, power_w`）
  - 非法 JSON、缺字段、量程越界 → 拒收并计数（采集审计）；主题不匹配同样计数
  - **去重**：QoS1 会重复投递，同一 `(service_id, ts)` 只收一次，重复要计数
  - **按日分桶**：JSONL 文件名含 UTC 日期（如 `data-20231115.jsonl`），跨日自动换文件
  - 业务逻辑与 broker 解耦：不给离线单测添麻烦——参考实现提供 FakeBroker 直投通道；真实 paho 通道单独文件/函数、带依赖与 broker 说明（未在本环境验证如实标注）
  - 加分项：采集统计做成可审计的 Counter（accepted/duplicate/invalid/bad_topic）
- **验收**：离线通道喂 3 合法 + 1 重复 + 2 非法 + 1 错主题 → 统计分别为 3/1/2/1；`python3 -m pytest sol-04-mqtt-service.py -q` 全绿
