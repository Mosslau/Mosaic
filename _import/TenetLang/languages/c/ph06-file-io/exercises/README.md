# exercises —— 文件操作阶段练习

完成顺序建议：按 1~4 顺序完成。参考实现在 `sol-*` 文件中，做完再看。

## 练习 1：读取配置文件

- **目标**：实现 key=value 配置文件读取器
- **要求**：
  - 支持空行与 `#` 注释
  - 兼容 `key = value` 与 `key=value` 两种写法（首尾空白剔除）
  - 错误行（缺 `=`、key/value 为空、超长）报告行号并跳过，不中断
- **验收**：对含注释/空行/两种写法/错误行的配置文件，正确解析全部有效项并报告错误行号

## 练习 2：CSV 文件解析

- **目标**：解析 CSV（`name,age,score` 三列），统计有效记录与跳过行
- **要求**：
  - 兼容 `\r\n` 与 `\n` 行尾；跳过空行
  - 字段数校验（拒绝多余列）、`sscanf` 数字格式校验、名字长度上限校验
  - 坏行报告行号并跳过
- **验收**：对含空行/坏行/多余列的 CSV，正确输出有效记录与"共 N 行: 有效 X 条, 跳过 Y 行"

## 练习 3：日志系统

- **目标**：实现带时间戳的 append-only 日志写入
- **要求**：
  - `"a"` 模式追加，每次写入带 `%Y-%m-%d %H:%M:%S` 时间戳
  - 每次写入后 `fflush`（用户态缓冲 → 内核）
  - 写入失败返回 -1 且不留下半行
- **验收**：连续写 3 条日志，文件内容含时间戳且追加正确；再次运行不覆盖旧记录

## 练习 4：二进制文件读写结构体数据

- **目标**：用 `fwrite`/`fread` 读写定长结构体记录，并支持随机读
- **要求**：
  - 结构体只含定长字段（数值 + 定长 `char` 数组，不含指针）
  - `fwrite` 检查短写、`fread` 检查返回值
  - 用 `fseek(fp, N * sizeof(Record), SEEK_SET)` 随机读第 N 条
- **验收**：写入 3 条记录读回一致；`fseek` 直接读第 2 条返回正确数据；运行后无泄漏
