# ph01 基础语法 练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。
> 验证环境：Go 1.22.2 darwin/arm64（建议 Go 1.21+）。每个练习单文件即可运行：`go run sol-XX-*.go`。全部参考实现已在本环境验证通过（go vet + go run，gofmt 无差异）。

## 练习 1：计算器（★）

**目标**：写一个支持四则运算的命令行计算器。
**要求**：读入形如 `3 + 4` 的算式（操作数 运算符 操作数），输出结果保留两位小数；除零时给出错误提示；不支持的运算符给出提示。
**验收**：输入 `3 + 4` 输出 `7.00`；输入 `10 / 4` 输出 `2.50`；输入 `1 / 0` 输出除零错误；输入 `5 ^ 2` 提示不支持。

## 练习 2：判断素数（★★）

**目标**：打印 1~100 内全部素数。
**要求**：把判断逻辑写成 `isPrime(n int) bool` 函数；只需试除到 √n（`i*i <= n`）。
**验收**：输出以 `2 3 5 7 11` 开头，共 25 个素数，最后一个是 `97`。

## 练习 3：字符串反转（★★）

**目标**：反转一个字符串，要求正确处理 Unicode（含中文）。
**要求**：先按 `rune` 切片反转，不要按 byte 反转（否则中文会乱码）；用函数 `reverse(s string) string` 实现，`main` 中打印反转结果。
**验收**：输入 `hello, 世界` 输出 `界世 ,olleh`（反转按字符不是按字节）。

## 练习 4：map 统计词频（★★）

**目标**：统计一段文本中各单词出现次数，按出现次数从高到低输出。
**要求**：用 `map[string]int` 计数；排序时把 map 转成切片再排（提示：可以定义一个小的 struct 存单词和次数，用 `sort.Slice`）。
**验收**：对文本 `apple banana apple orange banana apple`，第一行输出 `apple: 3`，第二行 `banana: 2`，第三行 `orange: 1`。
