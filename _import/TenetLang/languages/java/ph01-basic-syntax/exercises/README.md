# ph01 基础语法 练习

> 先自己做，再对照 sol-* 参考实现。每题标注难度（★~★★★）。
> 验证环境：OpenJDK 17.0.16（建议 JDK 17+）。编译 `javac <文件>.java`，运行 `java <类名>`（见各文件头注释）。

## 练习 1：计算器（★）

**目标**：写一个支持四则运算的命令行计算器。

**要求**：用 `Scanner` 读入形如 `3 + 4` 的算式（操作数、运算符、操作数），输出结果；除零时给出错误提示；不支持的运算符给出提示。

**验收**：输入 `3 + 4` 输出 `7.00`；输入 `1 / 0` 输出除零错误；输入 `5 ^ 2` 提示不支持。

## 练习 2：九九乘法表（★）

**目标**：打印标准九九乘法表。

**要求**：用嵌套循环；每行只打到行号（如第 3 行打 `1×3 2×3 3×3`）；乘积左对齐占两位（`%-2d`）。

**验收**：输出 9 行，首行为 `1×1=1`，最后一行以 `1×9=9` 开头、`9×9=81` 结尾。

## 练习 3：判断素数（★★）

**目标**：打印 1~100 内全部素数。

**要求**：把判断逻辑写成 `static boolean isPrime(int n)` 方法；只需试除到 √n（`i * i <= n`）。

**验收**：输出以 `2 3 5 7 11` 开头，共 25 个素数，最后一个是 `97`。

## 练习 4：数组最大值、最小值、平均值（★★）

**目标**：对一组成绩求最大值、最小值、平均值。

**要求**：成绩用数组存储（如 `{78, 92, 85, 63, 99, 71}`）；用一次循环同时求出三个值；平均值保留两位小数（注意整数除法截断问题）。

**验收**：输出人数、平均分、最高分、最低分四项；对样例数组，平均分约 `81.33`，最高 `99`，最低 `63`。
