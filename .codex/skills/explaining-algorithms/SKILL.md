# Explaining Algorithms

## 使用边界

此 skill 用于以下任务：

- 解释一个算法的设计动机和核心思想
- 说明一个数据结构的性质、操作和复杂度
- 为仓库中的实验代码补充算法文档
- 对比两个相近算法并说明适用边界

此 skill 不用于：

- 解释语言语法、语言特性或框架 API
- 写系统架构总览
- 写软件项目 README
- 写通用教程或完整课程

## 写作前确认

开始正文前先确定以下信息，并把结论记录到工作笔记中：

- 读者：学习算法的人、实现者、代码评审者，还是工程负责人
- 文档目的：理解原理、复现实验、选型，还是维护实现
- 文档类型：理论学习文档、实验实现说明、源码算法注释，还是对比说明
- 事实来源：权威教材、论文、源码文件、已有文档或实验代码
- 非目标：本算法文档明确不解释什么

## 写作流程

1. 检查仓库是否有现成的算法文档模板，例如 `algorithms/TEMPLATE.md`；有模板时优先沿用仓库约定。
2. 阅读至少一个同目录相似文档，匹配现有标题层级、语气和验证方式。
3. 如果算法已有实现，先读源码，再写文档，不能只凭记忆解释代码。
4. 在起草前加载 `references/algorithm-template.md`，只选择与当前任务相关的部分。
5. 按“结论先行”写作：文档、章节和段落先给结论，再给依据。
6. 对每个结论标注来源或验证方式。

## 写作质量门

最终交付前必须满足：

- 输入、输出和假设写得足够具体，读者能判断该算法是否适用于自己的问题
- 核心思想可以用一句话说清
- 正确性论证不是“看起来对”，而是有可检查的步骤或不变量
- 复杂度说明给出前提，例如数据规模、稀疏图还是稠密图、最好/最坏/平均情形
- 实现部分与仓库真实代码对应，不虚构文件或函数
- 示例覆盖正常例、边界例或反例
- 明确写出局限、失效场景和相近算法的替代关系
