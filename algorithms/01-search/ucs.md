# UCS 一致代价搜索

> 状态：📖 理论文档（与 dijkstra.md 互为镜像：UCS 是 AI 视角，Dijkstra 是图论/工程视角）

## 设计原理

**解决什么问题**：边权不一致的图中，找**累计代价最小**的路径——而非 BFS 的"步数最少"。

**核心思想一句话**：边界集改用优先队列，永远扩展**当前累计代价 g(n) 最小**的节点。代价小的一律先走，不管它离起点几步。

**为什么存在**：BFS 的"按层扩展"隐含假设"每步代价相同"。现实里走高速 10 公里可能比走小路 2 公里更省时间——一旦边权有异，"层数最少"不等于"代价最小"，BFS 的最优性立刻失效。UCS 把排序标准从"步数"换成"累计代价"，恢复了最优性保证。

## 数学推导

**记号**：

- g(n)：起点到 n 的实际累计代价
- c(n, n')：边 (n, n') 的代价，要求 **c ≥ ε > 0**（正的下界）

**最优性定理**：所有边权非负时，节点 n 第一次被**弹出**（不是被发现）时，g(n) 即为最短距离。

**证明思路（归纳 + 反证）**：设弹出 n 时存在更短路径 P'，P' 上必有一个节点 n'' 仍在队列中且 g(n'') ≤ P' 的代价 < g(n)（沿最优路径的前缀代价单调不增）。那优先队列应弹出 n'' 而非 n——矛盾。

**为什么要求正下界 ε**：若有零代价边，可以构造无限条代价相同的零环，算法不终止；若有负权边，"弹出的 g 已最小"不再成立（Bellman-Ford 处理的场景）。

**复杂度**：时间 O((b + E) log V)，空间 O(V)。有效复杂度取决于 C*/ε（最优代价 / 最小边权）——决定了要扩展多少个"代价环"。

## 手写实现要点

```python
import heapq

def ucs(start, goal, neighbors):
    heap = [(0, start)]            # (g, node)
    best_g = {start: 0}
    while heap:
        g, node = heapq.heappop(heap)
        if node == goal:
            return g
        if g > best_g.get(node, float('inf')):
            continue               # 过期堆项：跳过
        for nb, cost in neighbors(node):
            g2 = g + cost
            if g2 < best_g.get(nb, float('inf')):
                best_g[nb] = g2
                heapq.heappush(heap, (g2, nb))
    return None
```

**容易踩的坑**：

- **弹出时判最优，而非入队时**：入队时的 g 可能之后被更短路径刷新；第一次弹出才是最短
- **过期堆项处理**：heapq 不支持 decrease-key，标准做法是允许重复入堆、弹出时与 best_g 比对跳过旧值。别试图在堆里改值
- **heapq 平局**：(g, node) 中 g 相同时会去比 node，若 node 不可比（如自定义对象）会抛 TypeError——加单调计数器 `(g, counter, node)` 解决
- 目标判断必须在**弹出时**做，不能在入队时（入队顺序不保证最优）

## 框架对照

| 场景 | 对应物 |
|---|---|
| 网络路由 OSPF | Dijkstra（UCS 同物）算最短路径树 |
| 地图导航 | 地基算法，实际用 A* 加速 |
| `scipy.sparse.csgraph.dijkstra` | scipy 现成实现 |
| `networkx.single_source_dijkstra` | NetworkX 现成实现 |

**与 BFS 的对照**：同一张图，先让所有边权为 1（UCS 应退化为 BFS 的行为与结果），再改成异质边权（BFS 找到步数最少但代价非最小的路径，UCS 找到代价最小路径）——**这组实验直接展示"加权"带来的本质差异**。

## 实验结果（预期）

- 异质边权图上：UCS 路径总代价 ≤ BFS 路径总代价（常常严格更小），步数可能更多
- 扩展节点数多于 A*，少于暴力枚举；波前仍是圆形（无方向感）
- 记录弹出顺序可画出"等代价等高线"

## 局限与延伸

- **局限**：只回头看 g，不向前看终点方向——单终点场景下做了大量无用功（探索了背离终点的方向）
- **延伸**：
  - 加方向信息 → **A***（f = g + h）
  - 有负权边 → Bellman-Ford / SPFA
  - 全源最短路 → Floyd-Warshall / Johnson
  - 十亿级节点 → 近似算法、地标启发（ALT 算法）
