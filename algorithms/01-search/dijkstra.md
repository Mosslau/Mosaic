# Dijkstra 最短路径算法

> 状态：📖 理论文档 + `a-star/baseline.py` 中的实验对照实现
> 对应文档章节：`roadmap/人工智能代表算法演进路线.md` 第 2.2.1 章

## 设计原理

**解决什么问题**：非负边权图中，从单源点到**所有节点**（或指定终点）的最短路径。

**核心思想一句话**：维护一个"已确定"集合，每一步从未确定节点中挑 g 最小的加入确定集——一旦确定，终身不改。

**为什么存在**：1959 年 Edsger Dijkstra 在设计 ARMAC 计算机时提出（原问题是"从鹿特丹到格罗宁根的最短路线"，他后来自述"20 分钟在咖啡馆里想出来的，没有纸笔"）。它是第一个实用的多项式时间最短路算法，至今仍是路由协议（OSPF、IS-IS）的地基。

**与 UCS 的关系**：**算法上是同一个东西**——UCS 是 AI 教科书（Russell & Norvig《AIMA》）对这类搜索的称呼，面向"状态空间中的目标搜索"；Dijkstra 是图论/工程语境的称呼，面向"显式图上的最短路计算"。细微差别：Dijkstra 的经典表述计算**全源距离表**，UCS 的表述是**找到目标即停**。实现代码可以一模一样。

## 数学推导

**不变式**：已确定集合 S 中每个节点的 g 值 = 从源点到它的真实最短距离。

**正确性（贪心选择性质）**：每次从 S 之外选 g 最小的节点 u。假设存在经 S 外某节点 x 的更短路径到 u：g(x) + c(x,...,u) < g(u)。由于路径上 x 是 u 的前驱且 c ≥ 0，有 g(x) < g(u)——但 x 在 S 外说明弹出时 g(x) ≥ g(u)（优先队列性质），矛盾。故 u 的 g 已最优，可以放心"确定"。

**复杂度**（V = 节点数，E = 边数）：

| 实现 | 时间 |
|---|---|
| 朴素数组找最小 | O(V²) |
| 二叉堆（heapq） | O((V + E) log V) |
| 斐波那契堆 | O(E + V log V)（理论最优，工程少用） |

## 手写实现要点

实验实现见 `a-star/baseline.py`——刻意与 `impl.py` 的 A* 共享同一套代码骨架，唯一区别是启发函数恒为零：

```python
def dijkstra(grid, start, goal):
    return astar(grid, start, goal, heuristic=lambda a, b: 0)
```

这个写法本身就是论点的证明：**Dijkstra = h ≡ 0 的 A***。

若独立实现，要点与 UCS 相同（见 ucs.md）：heapq 最小堆、弹出时判最优、过期堆项跳过、平局计数器。

**容易踩的坑**：

- **负权边是禁区**：贪心确定性的前提被负边破坏，结果错误且难察觉。需要负权支持请用 Bellman-Ford
- "确定即不改"是理解关键：一旦节点出队，后续发现"更短路径"的情况在非负权图中不存在；若代码里出现"出队后还要更新"说明实现有 bug
- 稠密图（E ≈ V²）下朴素 O(V²) 数组实现反而比堆快（常数小）；稀疏图必须用堆

## 框架对照

本实验中的角色：**A* 的基线**。

| 对比维度 | Dijkstra (h ≡ 0) | A* (曼哈顿 h) |
|---|---|---|
| 路径长度 | 最短 | 最短（h 可采纳时） |
| 扩展节点数 | 多（全向膨胀） | 少（定向拉伸） |
| 耗时 | 长 | 短 |
| 波前形状 | 圆形 | 朝终点的椭圆 |

**同图双跑的路径长度必须完全一致**——这是验证 A* 实现正确性的第一道断言。扩展节点数之差 = 启发式贡献的量化。

现成实现：`scipy.sparse.csgraph.dijkstra`、`networkx.single_source_dijkstra`。

## 实验结果（预期）

- 障碍网格上 Dijkstra 扩展节点数 ≈ A* 的 2-10 倍（障碍越多差距越大）
- 两算法路径长度逐项相等（断言验证）
- 扩展顺序可视化：完美的圆形波前，无视终点方向

## 局限与延伸

- **局限**：无方向感（单终点场景浪费）；负权边失效；内存 O(V)
- **延伸**：
  - 加终点方向 → **A***（本目录主实验）
  - 负权 → Bellman-Ford；全源 → Floyd-Warshall / Johnson
  - 路网加速工程化 → 双向 Dijkstra、CH（Contraction Hierarchies）、ALT（地标 + A*）
  - 理论极限：2023 年 Dijkstra 被证明配合足够强的堆是"通用最优"（universally optimal）的——60 多年后仍在发论文的算法
