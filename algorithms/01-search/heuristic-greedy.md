# 启发式搜索（贪心最佳优先搜索）

> 状态：📖 理论文档（无对应实验目录，作为 A* 的对照与前置概念）
> 对应文档章节：`roadmap/人工智能代表算法演进路线.md` 第 2.2.1 章

## 设计原理

**解决什么问题**：利用"离终点还有多远"的领域知识加速搜索——无信息搜索（BFS/UCS）对终点方位一无所知，启发式搜索把这层信息用起来。

**核心思想一句话**：优先扩展**估计离终点最近**的节点——只看 h(n)，不看已经付出的代价 g(n)。

**术语澄清**：

- **启发式搜索（heuristic search）** 是一个**大类**：任何用启发函数 h(n) 指导搜索方向的方法都属于它，成员包括贪心最佳优先、A*、IDA*、爬山法、模拟退火等
- **贪心最佳优先（greedy best-first）** 是这个大类里最朴素的成员：纯粹按 h 排序，通常口语里说的"启发式搜索"多半指它

**为什么存在**：无信息搜索的扩展节点数随深度指数爆炸，而人对问题常有直觉（"往东北走"）。启发函数把这种直觉形式化，用**可能牺牲最优性**换取**数量级的提速**。

## 数学推导

**启发函数 h(n)**：节点 n 到终点的估计代价。它是关于问题的**外部知识**，不来自图结构本身。常用例子：

| 问题 | h(n) |
|---|---|
| 网格寻路（四方向） | 曼哈顿距离：\|x₁-x₂\| + \|y₁-y₂\| |
| 网格寻路（八方向） | 对角距离：max(Δx,Δy) + (√2-1)·min(Δx,Δy) |
| 欧氏空间 | 直线距离：√(Δx² + Δy²) |
| 8 数码 | 错位方块数 / 各块曼哈顿距离和 |
| TSP | 最小生成树代价 |

**贪心最佳优先的扩展规则**：f(n) = h(n)。每次弹出 h 最小的节点。

**性质**：

| 性质 | 结论 | 原因 |
|---|---|---|
| 完备性 | 有限图 + 环检测下完备 | 与 DFS 类似的系统性 |
| 最优性 | **不保证** | 无视 g，可能被"看起来近"的节点带偏 |
| 时间 | O(b^m)，好 h 可近 O(b·m) | 完全依赖 h 的质量 |
| 空间 | O(b^m) | frontier 全存 |

**为什么快但可能错**：h 只反映"局部看起来近"，不反映"走过去要花多少"。典型翻车场景：一堵 U 形墙横在终点正前方——贪心会一头扎向墙根（h 最小），再被迫绕一大圈回来，而 UCS 会平滑地绕墙走。

## 手写实现要点

与 UCS 同构，仅把堆排序键从 g 换成 h：

```python
heap = [(h(start), counter(), start)]
...
heapq.heappush(heap, (h(nb), counter(), nb))
```

**容易踩的坑**：

- h 必须是**纯函数**：只依赖节点本身，不依赖到达路径——否则无法做图搜索的判重
- h 为 0 时要有确定行为：等于终点判断要显式做，不能依赖 h 排序
- 与 A* 共用代码时，**贪心和 A* 的差别只有一个参数**：f = w_g·g + w_h·h 中取 (0,1) vs (1,1)
- 不要给 h 加随机扰动来"破平局"——破坏可复现性；平局用计数器固定

## 框架对照

无框架接口，但作为"参照系"角色重要：

**同一地图三方对照（启发式贡献的拆解实验）**：

| 算法 | 排序键 | 路径最优? | 扩展节点 | 速度 |
|---|---|---|---|---|
| Dijkstra/UCS | g | ✅ | 多 | 慢 |
| 贪心 | h | ❌ | 最少（h 好时） | 最快 |
| A* | g + h | ✅（h 可采纳） | 中 | 中 |

这组对照是理解 A* 的关键：**A* 是贪心的"安全带"**——加上 g 项后，方向感保留，最优性恢复。

## 实验结果（预期）

- 开阔地图上贪心扩展节点最少、最快，但路径可能略绕
- U 形障碍地图上贪心明显翻车：路径远长于最优，甚至陷入死胡同后大绕路
- 同一 h 下 A* 与 Dijkstra 路径相同，贪心路径更短于等于或长于——不保证任何界

## 局限与延伸

- **局限**：不保证最优；h 质量差时可能不如 Dijkstra；局部极小值死锁（h 引导的方向全是墙）
- **延伸**：
  - 加回 g 项保最优 → **A***（本目录主实验）
  - 纯局部搜索 → 爬山法（每次只走最好邻居，无回溯）
  - 跳出局部最优 → 模拟退火、禁忌搜索
  - LLM 时代回响：Beam Search（每层保 top-k）本质也是"贪心的折中"——用宽度换质量
