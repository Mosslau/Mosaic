# DFS 深度优先搜索

> 状态：📖 理论文档（无对应实验目录，作为 01-search 家族基础篇）
> 对应文档章节：`roadmap/人工智能代表算法演进路线.md` 第 2.2.1 章

## 设计原理

**解决什么问题**：在图/树结构中系统地遍历或搜索所有可达节点，找一条到目标的路径（不保证最短）。

**核心思想一句话**：一条道走到黑，撞墙再回头——永远优先扩展最新加入的节点（栈，LIFO），沿单条路径扎到最深处，无路可走时回溯到最近的岔路口。

**为什么存在**：它是最朴素的系统化搜索。相比 BFS 的一次性铺开，DFS 只需要存储当前一条路径，内存代价极小；在解很深、分支很宽（如棋类博弈树、约束满足问题）的场景里，BFS 的内存会先爆炸，DFS 反而是唯一可行的遍历方式。

## 数学推导

设分支因子为 b（每个节点平均邻居数），最大深度为 m，解所在深度为 d。

| 量 | 复杂度 | 说明 |
|---|---|---|
| 时间 | O(b^m) | 最坏情况遍历整棵树到最大深度 |
| 空间 | O(b·m) | 只需存当前路径 + 每层未探索的兄弟节点 |

对比 BFS 的 O(b^d) 空间：当 d 大、b 大时（如 8 数码 b≈2-4、棋类 b≈35），b^d 是天文数字，b·m 只是线性倍——**DFS 用时间换空间**。

**不完备性**：若状态空间含无限深分支（或图中无环检测），DFS 可能沿一条无限路径永远走下去，错过浅层的解。因此标准 DFS **不完备、不最优**；加上深度限制（DFS 的受限变体）或环检测后可缓解。

**回溯的数学本质**：DFS 等价于对状态空间树做先序遍历（pre-order），每个节点恰好入栈一次、出栈一次，每条边至多被检查两次。

## 手写实现要点

两种形态，建议都写一遍感受差异：

**递归版（隐式栈）**

```python
def dfs(node, goal, visited):
    if node == goal: return [node]
    visited.add(node)
    for nb in neighbors(node):
        if nb not in visited:
            path = dfs(nb, goal, visited)
            if path: return [node] + path
    return None
```

**迭代版（显式栈）**

```python
stack = [(start, [start])]
while stack:
    node, path = stack.pop()
    if node == goal: return path
    for nb in neighbors(node):
        if nb not in visited:
            stack.append((nb, path + [nb]))
```

**容易踩的坑**：

- 递归版有 Python 递归深度限制（默认 1000），深图要用迭代版或 `sys.setrecursionlimit`
- 环检测的 `visited` 集合：树搜索可以不要，图搜索必须加，否则死循环
- 迭代版把 `(node, path)` 一起入栈会复制路径，内存退化；更省的做法是存父指针最后回溯（与 A* 相同的手法）
- 出栈顺序 = 入栈逆序：邻居入栈顺序决定搜索方向，想要"从左到右"搜就要逆序压栈

## 框架对照

DFS 无现成框架接口（它是太基础的原语），但出现在各处：

| 场景 | 对应物 |
|---|---|
| 树的先序/中序/后序遍历 | 本质都是 DFS |
| 拓扑排序 | DFS + 出栈逆序 |
| 强连通分量 | Tarjan / Kosaraju，基于 DFS |
| 回溯法（N 皇后、数独） | DFS + 剪枝 |
| Minimax（本目录实验） | 博弈树上的 DFS |

**对照基线**：BFS。同一张图上跑 DFS vs BFS，对比：找到解的路径长度（BFS 最短、DFS 任意）、访问节点数、峰值内存。

## 实验结果（预期）

- DFS 找到的解通常明显长于最短路径（可能绕远）
- 深图宽分支场景下 DFS 内存远低于 BFS；浅解宽图场景下 BFS 更快
- 网格寻路中 DFS 的"蛇形走位"路径直观展示其无方向性

## 局限与延伸

- **局限**：不完备（无限深度）、不最优（任意深度解）、对解的位置无感知
- **延伸**：
  - 深度受限 DFS（DLS）→ **迭代加深 IDDFS**：以 0,1,2,... 的深度上限反复跑 DFS，兼具 BFS 的最优性与 DFS 的低内存，是大状态空间无信息搜索的标配
  - 回溯 + 剪枝 → 约束满足问题（CSP）求解
  - 与启发式结合 → IDA*（迭代加深版 A*，解决 A* 内存爆炸）
  - 博弈树上的 DFS → Minimax（本目录下一个实验）
