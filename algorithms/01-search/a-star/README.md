## 实验结果

**地图参数**：21×21 网格，30% 障碍率，四方向移动，固定种子保证起点 (1,1) 与终点 (19,19) 连通。

| 指标 | A* | Dijkstra | 结论 |
|---|---|---|---|
| 路径长度 | 47 | 47 | **完全一致**——最优性断言通过 |
| 扩展节点 | 214 | 239 | A* 少扩展 25 个（10.5%） |
| 耗时 | 0.62 ms | 0.60 ms | 小图上持平，大图差距才显现 |

多种子（42 / 7 / 13 / 99 / 2026）验证：UCS = Dijkstra = A* 代价全部一致，最优性稳定。

**可视化结论**：ASCII 渲染中 Dijkstra 的 closed 集（`o`）呈对称菱形波前，A* 的 closed 集朝终点方向明显拉伸——**启发式把搜索从"全向膨胀"拉成"定向收缩"**。

**六算法同台对比**（`../compare_all.py`）：

| 算法 | 路径长 | 扩展节点 | 最优? |
|---|---|---|---|
| DFS | 85 | 101 | ✗ 绕远 |
| BFS | 47 | 239 | ✓ |
| UCS | 47 | 239 | ✓ 退化为 BFS |
| Dijkstra | 47 | 239 | ✓ |
| 贪心 | 63 | 145 | ✗ 被障碍带偏 |
| A* | 47 | 214 | ✓ 最优且最快扩展最少 |

## 局限与延伸

- **内存瓶颈**：open 集可能指数膨胀 → IDA*（迭代加深，内存线性）
- **h 设计**：可采纳性是安全线；多个可采纳 h 取 max 仍可采纳
- **牺牲最优换速度**：加权 A*（f = g + w·h，w>1 时 w-次优界）
- **网格专用加速**：JPS（Jump Point Search，利用对称性剪枝）
- **Agent 语境**：A* 是"符号规划"经典代表，与 LLM Agent 的搜索规划（Tree of Thoughts、MCTS）一脉相承 → 本目录下一实验：`../minimax-alphabeta/`、`../mcts/`
