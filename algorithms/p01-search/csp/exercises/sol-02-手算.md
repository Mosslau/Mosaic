# 参考解：第 2 题（走通）

## 设定

4 皇后：$q_0, q_1, q_2, q_3$（第 0~3 行），域都是 $\{0,1,2,3\}$。
约束：$c_i \ne c_j$ 且 $|c_i - c_j| \ne |i - j|$。

前向检查的做法：给一个变量赋值后，把它**未赋值的邻居**域里不相容的值删掉；某域空了就立刻回退。

## 1. 依次尝试 $q_0$

**$q_0 = 0$**：删掉 $q_1..q_3$ 中与它同列（0）或同斜线的值。

| 变量 | 原始域 | 删掉 | 剩余域 |
|---|---|---|---|
| $q_1$ | {0,1,2,3} | 0（同列）、1（斜线 $|1-0|=1$） | **{2,3}** |
| $q_2$ | {0,1,2,3} | 0（同列）、2（斜线 $|2-0|=2$） | **{1,3}** |
| $q_3$ | {0,1,2,3} | 0（同列）、3（斜线 $|3-0|=3$） | **{1,2}** |

继续：$q_1 = 2$（MRV 下域最小的先选，这里 $q_1,q_2,q_3$ 域大小都是 2，按顺序取 $q_1$）：

- 删 $q_2$：与 $q_1=2$ 同列删 2、斜线 $|2-2|=0$ 无额外 → $q_2$ 剩 **{1,3}**（2 本来就不在）
  实际 $q_2$ 域 {1,3}，2 不在其中 → 不变
- 删 $q_3$：与 $q_1=2$ 同列删 2 → $q_3$ 剩 **{1}**
- $q_2 = 1$：$q_3$ 域 {1} 中 1 与 $q_2=1$ 同列 → 删掉 → **$q_3$ 域空 → 回退**
- $q_2 = 3$：$q_3$ 域 {1} 中 1 与 $q_2=3$：不同列、$|3-1|=2 \ne |2-3|=1$ → 保留
  → $q_3 = 1$：检查与 $q_0=0$：$|1-0|=1 \ne 3$ ✓；与 $q_1=2$：$|1-2|=1\ne2$ ✓；与 $q_2=3$：$|1-3|=2\ne1$ ✓
  → **找到一个解：$q = (0, 2, 3, 1)$**

（也可以先试 $q_1=3$，会走到另一条路；标准解为 $(0,2,3,1)$ 与 $(1,3,0,2)$ 的旋转/镜像。）

**解**：$(q_0,q_1,q_2,q_3) = (0, 2, 3, 1)$ → 列号 0-2-3-1，两两不同列、不同斜线 ✓

**$q_0 = 1$ 会怎样**：$q_1$ 域删到只剩 {3}，$q_2$ 剩 {0}? 让我们算：

| 变量 | 删掉 | 剩余域 |
|---|---|---|
| $q_1$ | 1（同列）、0 与 2（斜线） | **{3}** |
| $q_2$ | 1（同列）、3（斜线 $|2-1|=1$） | **{0,2}** |
| $q_3$ | 1（同列）、2（斜线 $|3-1|=2$） | **{0,3}** |

$q_1 = 3$ → 删 $q_2$：同列删 3（不在域中）、斜线 $|2-3|=1$ 删 2 → $q_2$ 剩 **{0}**；
删 $q_3$：同列删 3 → $q_3$ 剩 **{0}**。$q_2 = 0$ → $q_3$ 域 {0} 与 $q_2=0$ 同列 → 空 → 回退。
$q_1$ 无其他取值 → 回退 $q_0$。

所以 $q_0=1$ 走不通。

## 2. 最终解

$(0, 2, 3, 1)$（另一组本质不同的解是 $(1, 3, 0, 2)$）。

## 3. 不用前向检查（纯回溯）会多走几步？

纯回溯在 $q_0=1$ 这条路上：它**不删域**，所以给 $q_1$ 赋值时只能靠"与已赋值的 $q_0$ 相容"判断：

- 试 $q_1=0$：与 $q_0=1$ 斜线冲突 → 拒绝（1 次失败尝试）
- 试 $q_1=1$：同列 → 拒绝
- 试 $q_1=2$：斜线冲突 → 拒绝
- 试 $q_1=3$：相容 → 进入 $q_2$，再试 $q_2=0,1,2,3$…

而前向检查在**给 $q_0=1$ 赋值之后**就已经看到"$q_1$ 只剩 3"，把 3 次失败的赋值尝试
直接省掉了。这就是"提前一步"的实际收益：**省掉的是失败的赋值尝试，而不只是省时间**。
