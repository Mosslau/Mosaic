# 参考解：第 2 题（走通）

## 0. 约定

- 库恩扑克：J<Q<K，各下 1 注底池；终局（player1 视角）：
  对手弃牌 +1；自己弃牌 −1；过牌-过牌摊牌 ±1；跟注后摊牌 ±2。
- 初始策略：`("", 我的牌, p1)` 上「过牌 0.5 / 下注 0.5」；
  其余信息集（对手的应对、自己面对下注）也都按 0.5/0.5 起手（便于手算）。
- 只算**一次**迭代的后悔更新（对手按它当前的 0.5/0.5 策略应对）。

## 1. player1 拿到 K（最强的牌）

「下注」这条路：对手（player2）面对下注按 0.5 弃牌 / 0.5 跟注。

| 对手的反应 | 概率 | player1 收益 |
|---|---|---|
| 弃牌 | 0.5 | +1 |
| 跟注 → 摊牌（K 必胜） | 0.5 | +2 |

下注的期望 = 0.5×1 + 0.5×2 = **+1.5**

「过牌」这条路：对手面对过牌按 0.5 过牌 / 0.5 下注。

| 对手的反应 | 概率 | 之后 | player1 收益 |
|---|---|---|---|
| 过牌 → 摊牌（K 必胜） | 0.5 | 结束 | +1 |
| 下注 → 我再决定（0.5 跟/0.5 弃） | 0.5 | 跟注 → 摊牌胜 | +2 |
| | | 弃牌 | −1 |

对手下注后我的期望 = 0.5×2 + 0.5×(−1) = +0.5
过牌的期望 = 0.5×1 + 0.5×0.5 = 0.5 + 0.25 = **+0.75**

节点平均 = 0.5×1.5 + 0.5×0.75 = **+1.125**

| 动作 | 期望 | 后悔（= 期望 − 平均） |
|---|---|---|
| 下注 | +1.5 | **+0.375** |
| 过牌 | +0.75 | **−0.375** |

下一轮：下注概率 = 0.375 / (0.375 + 0) = **1.0**。
→ **拿到 K，以后总是下注。**

## 2. player1 拿到 J（最弱的牌）

「下注」这条路：对手 0.5 弃 / 0.5 跟。

| 对手的反应 | 概率 | player1 收益 |
|---|---|---|
| 弃牌 | 0.5 | +1 |
| 跟注 → 摊牌（J 必输） | 0.5 | −2 |

下注期望 = 0.5×1 + 0.5×(−2) = **−0.5**

「过牌」这条路：

| 对手的反应 | 概率 | 之后 | player1 收益 |
|---|---|---|---|
| 过牌 → 摊牌（J 必输） | 0.5 | 结束 | −1 |
| 下注 → 我 0.5 跟 / 0.5 弃 | 0.5 | 跟 → 摊牌输 | −2 |
| | | 弃 | −1 |

对手下注后期望 = 0.5×(−2) + 0.5×(−1) = −1.5
过牌期望 = 0.5×(−1) + 0.5×(−1.5) = −1.25

节点平均 = 0.5×(−0.5) + 0.5×(−1.25) = **−0.875**

| 动作 | 期望 | 后悔 |
|---|---|---|
| 下注 | −0.5 | **+0.375** |
| 过牌 | −1.25 | **−0.375** |

下一轮：下注概率 = **1.0**。

## 3. 为什么两者都变成"总是下注"？与 1:3 什么关系？

在这次手算里 **K 和 J 的下注概率都升到 1**——注意这**不是均衡**，只是"第一轮迭代"的结果：
起手策略太被动（0.5 过牌），所以任何牌都发现"下注比过牌好"。

均衡不是一步到位的，而是**多轮迭代后 K 与 J 的比例被锁到 3:1**。机制是：

- **K 下注**：纯粹的价值下注（我大概率赢），所以它一路升到很高；
- **J 下注**：这是**诈唬**——它的价值完全来自"对手会不会弃牌"。
  如果 J 下注太频繁，对手就会一直跟注，诈唬失效；如果从不诈唬，
  对手面对我的下注就总是弃牌（我拿 K 时赚不到钱）。均衡要求
  **对手对"跟注还是弃牌"恰好无差异**，这个条件把 J 的下注率锁成 K 的 **1/3**。

**本实验实测（`demo.py`，50000 轮训练）**：J 下注 0.221、K 下注 0.661，比值 **2.99 ≈ 3**。
这就是"手算一步看不出均衡、必须迭代到收敛"的最好例证。
