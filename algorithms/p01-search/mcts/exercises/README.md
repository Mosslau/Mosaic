## 第 3 题（判断）回传符号写反了

**目标**：练第 3 级——能定位"不报错但结果全错"的实现错误。

**要求**：下面是把 `_backpropagate` 写错的版本：

```python
def _backpropagate(self, node, reward_for_mover):
    while node is not None:
        node.visits += 1
        node.value += reward_for_mover     # ← 注意：没有翻转符号
        node = node.parent
```

1. 这个写法错在哪？用一句话说清"每个节点的 value 应该表示什么"。
2. **实测后果**：写个小脚本，把错误版本与 `impl.MCTS` 分别在井字棋上**对精确搜索**
   （`../../minimax-alphabeta/impl.py` 的 `alphabeta(depth=9)`）各下 40 局，
   报告两者的"和棋 / 负"数字。**这个 bug 不会报错**——请说明它会以什么现象暴露出来。
3. 另外给一个**更小的**验证方法：构造一个"赢家一定是某一方"的小局面，
   直接检查根与子节点的 `value` 符号关系（不必对局）。

**验收标准**：第 2 问给出实测数字；第 3 问给出可断言的不变式。

**提示**：想想"胜率项 = value / visits"在父子两层分别代表谁的胜率。

## 第 4 题（实现）把 UCB1 换成 PUCT

**目标**：练第 4 级——把教学实现改造成工程上真正会用的形态。

**要求**：新建 `sol-04-PUCT.py`（只用标准库），实现一个 `PUCTMCTS`：

1. 选择规则改成 **PUCT**：`Q(s,a) + C · P(s,a) · √N / (1 + n)`
   （`Q` = 平均收益、`P` = 先验概率、`N` = 父访问数、`n` = 子访问数）；
2. 先验概率用一个**任何棋类都能算的简单启发式**给（例如"走完后我方的即时威胁数"），
   在**根节点一次性算好**、之后再往下用均匀分布——只要能让靠近根的分支带上先验就够；
3. 自检断言：
   - 对精确搜索（先手、`iterations=100`）**不输**；
   - 与 `impl.MCTS`（同迭代数）相比，**不输率不低于它**；
4. 打印一张对照表：`UCB1` vs `PUCT` 在 `iterations ∈ {10, 50, 100}` 上的和棋 / 负。

**验收标准**：脚本能独立运行（`python3 sol-04-PUCT.py`），断言全部通过，并打印对照表。

**提示**：UCB1 的问题在实验三里已经暴露（探索项与总次数强耦合）。PUCT 把"均匀探索"换成
"按先验探索"，这就是 AlphaZero 的选择规则。先验不必很强，**有方向就行**。
