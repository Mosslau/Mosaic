# 参考解：第 2 题（走通）

树（三层：**根 = 我方 max → 对手 min → 叶子终局分**）：

```text
                    我方 (max)
              ┌────────┼────────┐
              招法 a   招法 b   招法 c
        对手 (min)  对手 (min)  对手 (min)
         4  2  6    4  8  3    1  8  3
          r1 r2 r3   r4 r5 r6   r7 r8 r9
```

> 因为树是三层，搜索深度必须取 **`depth = 3`** 才能走到叶子；给 2 会在对手层截断（那时用的是局面评估）。
> 这是本题第一号坑。

## 1. 不剪枝

| 招法 | 对手的三个应对 | 对手取最小 | 我方取值 |
|---|---|---|---|
| a | 4, 2, 6 | 2 | |
| b | 4, 8, 3 | 3 | |
| c | 1, 8, 3 | 1 | |
| **根（max）** | | | **max(2, 3, 1) = 3 → 选 b** |

展开叶子数：**9**（全部）。

## 2. 加 alpha-beta（从左到右；α = −∞、β = +∞ 起步）

**关键点：`α` 是"我方在已经算完的兄弟分支里能保证拿到的最好值"，所以它是算完 a 之后才带进 b 的**
——这一点最容易写错。真实轨迹如下（可用 `sol-02-手算.py` 逐行核对）：

| 顺序 | 运算 | 窗口变化 |
|---|---|---|
| a 的 r1 | v = 4 | α = −∞，β = 4 |
| a 的 r2 | v = min(4, 2) = 2 | α = −∞，β = 2 |
| a 的 r3 | v = min(2, 6) = 2 | α = −∞，β = 2 |
| **a 结束** | v = 2 → **α ← max(−∞, 2) = 2** | **α = 2** |
| b 的 r4 | v = 4 | α = 2，β = 4 |
| b 的 r5 | v = min(4, 8) = 4 | α = 2，β = 4 |
| b 的 r6 | v = min(4, 3) = **3** | α = 2，β = **3** ⇒ 检查 `β(3) ≤ α(2)`？**否**，不剪 |
| **b 结束** | v = 3 → **α ← max(2, 3) = 3** | **α = 3** |
| c 的 r7 | v = 1 | α = 3，β = 1 |
| 检查 | **`β(1) ≤ α(3)` ⇒ 整支剪掉**：c 的 r8、r9 不展开 | α = 3，β = 1 |
| **根** | max(a = 2, b = 3, c = 1) = **3 → 选 b** | |

**被剪掉的分支**：`c/r8`、`c/r9` —— 9 个叶子只展开了 **7** 个。

**剪枝时满足的不等式：`β(1) ≤ α(3)`。** 含义：对手在 c 的第一个应对 r7 就只给 1，
而我在 b 那里已经保证能拿到 3 —— **c 无论如何都不会被选中**，剩下的应对不必展开。

> 为什么 b 内部**没有**剪枝？因为 b 的第二个应对 r5 之后 β = 4、α = 2，`4 ≤ 2` 不成立；
> 第三个应对 r6 = 3 只是让 β 降到 3，仍然 `3 ≤ 2` 不成立。**要剪枝，对手得把值压到 α 以下。
> 很多人的手算会在这里多剪一刀——本参考解以真实轨迹为准。

## 3. 结论对比

| | 不剪枝 | Alpha-Beta |
|---|---|---|
| 根的取值 | 3 | 3 **（必须相同）** |
| 选中的招法 | b | b |
| 展开的叶子 | 9 | **7** |

- **剪枝改了什么**：展开了多少叶子（9 → 7，少约 22%）。
- **没改什么**：根的选择与取值。这就是剪枝合法性的全部内容。

这棵树很小、剪枝收益也小（22%），恰好说明一件事：**剪枝收益依赖树的大小与遍历顺序**——
教学目录的实验二（depth 1→9 省下 0%→96.4%）才是这条规律的真实规模。
