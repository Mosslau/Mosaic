# 参考解：第 1 题（说清）

## 1. 用自己的话讲三个算法（120 字内，不用"栈/队列/优先队列"）

> 三个人在迷宫里找出口。第一个人认准一个方向一直走，撞墙才回头换一个岔路；
> 第二个人每到一个地方，先把周围新看到的岔路都记下来，然后按"记得最早"的顺序去看；
> 第三个人也记下来，但每次挑"到目前为止走得最省力"的那条去看。

三者唯一的区别是**"先看哪条已发现的路"**。

## 2. 共用的主循环骨架

```
1. 把起点放进边界
2. 边界空了吗？空 → 无解
3. 从边界取出一个节点          ← ★ 分歧点：取谁
4. 是终点吗？是 → 返回路径
5. 不是 → 把未发现的可走邻居放进边界（记录前驱）
6. 回到第 2 步
```

**分歧点在第 3 步**：DFS 取"最后放进去的"、BFS 取"最早放进去的"、
UCS 取"累计代价最小的"。第 1、2、4、5、6 步三者**完全一样**。

## 3. 两个"为什么"

**为什么 BFS 一定最短、DFS 不一定？**
关键判据是：**终点第一次被取出时，是不是已经找到了最好的路。**
BFS 的队列保证"走 k 步能到的点"一定比"走 k+1 步能到的点"先被取出，
所以终点第一次被取出时不可能还有更短的路没被考虑 → 一定最短。
DFS 的栈只保证"后放先取"，跟"离终点多远"毫无关系——终点可能碰巧很早就被取出，
也可能被压到最后 → 只能保证"找得到"（有限图上），**不保证最短**。

**为什么 UCS 要求单步代价非负？**
它的最优性证明依赖"新算出的 `g` 不会比当前的小"，而这来自
`g(邻居) = g(当前) + c ≥ g(当前)`（要求 `c ≥ 0`）。
一旦有负权边，这个不等式失效，堆就不再保证"先出的距离已最优"，
于是可能提前锁定一个不是最优的距离——证明塌了，实际也会给出错解
（这类图要用 Bellman-Ford）。
