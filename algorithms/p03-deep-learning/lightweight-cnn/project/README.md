# 迁移项目：3200 参数预算内的轻量分类器

## 需求

把深度可分离卷积用到端侧约束上：为 16×16 digits 训练一个**参数量 ≤3200** 的
10 类分类器。与主实验相比多了三个约束：

1. **参数硬预算**：超预算的模型结构不能进入候选；
2. **验证集选型**：只用训练集切出的 300 张验证集挑宽度，测试集 397 张只在最后报告；
3. **同预算对照**：标准 3×3 CNN 也要压到 3200 以内，才能公平比较"结构 vs 预算"。

## 功能清单

- [x] DS 宽度候选枚举（4 组），用 `impl` 的 `init()+n_params()` 数参数
- [x] 超预算候选直接淘汰（`(8,16,36,36)` → 3294）
- [x] 1100 / 300 训练-验证切分，按验证 acc 选型
- [x] 同预算标准 CNN `(6,8,10,16)` 对照
- [x] 测试 acc、macro F1、预算余量与 5 条断言

## 验收标准

1. 选中模型参数量 **≤3200**；
2. 测试 acc **≥0.95**；
3. 测试 macro F1 **≥0.95**；
4. 与同预算标准 CNN 的测试 acc 差 **≥ −0.02**；
5. 超预算候选被跳过，不参与选型。

脚本 `budget.py` 内逐条 `assert`。

## 运行方式

```bash
cd algorithms/p03-deep-learning/lightweight-cnn/project
uv run python budget.py      # 约 45 秒，CPU
```

依赖：numpy + scikit-learn（手写实现，不需要 torch）。

## 实测结果（已验证）

环境：`algorithms/.venv`（uv），Python 3.13.15 / numpy 2.5.4 / scikit-learn 1.9.1，CPU；
seed 0，10 轮，batch 64，lr 0.01。

| 候选 | 参数量 | 验证 acc | 测试 acc | macro F1 |
|---|---|---|---|---|
| DS (8,16,32,32) | 2858 | 0.9600 | — | — |
| DS (12,16,32,32) | 3010 | 0.9667 | — | — |
| **DS (8,20,32,32)** | **3070** | **0.9700** | **0.9824** | **0.9825** |
| DS (8,16,36,36) | 3294 | ✗ 超预算 | — | — |
| 标准 CNN (6,8,10,16) | 2896 | — | 0.9673 | 0.9671 |

**三条结论**：

1. **预算内 DS 胜出**：3070 参数、测试 0.9824，比同预算标准 CNN 高 0.0151；
   后者为了装进 3200 只能压到 `(6,8,10,16)`，三个块都很窄。
2. **宽度比深度更值**：`(8,20,32,32)` 把第二块加宽到 20，验证 acc 从 0.9600 升到
   0.9700；加宽 block3 的 `(8,16,36,36)` 直接超预算，被淘汰。
3. **波动不可忽视**：8→10 轮、单次种子就能让同结构差 ±0.01（对比练习 5）；
   预算选型应多次种子 + 交叉验证，否则会把噪声当结论。

## 扩展方向

- **预算扫描**：把 2000 / 3200 / 5000 / 10000 画成"预算-精度"曲线，找拐点；
- **延迟约束**：把单批延迟也纳入选型（本实验证明参数少不等于快）；
- **结构化剪枝 / 量化**：对选中模型做通道剪枝或 int8 量化，再测精度与延迟；
- **换数据**：16×16 上采样换成 28×28 MNIST/Fashion-MNIST，看 DS 的精度代价是否变大。
