# 参考解 1：说清两个卷积

**1. depthwise 3×3**：`groups=in_channels=C`，每个输出通道只卷**自己的**输入通道，
不跨通道求和。权重形状 `(C,1,3,3)`，参数 `9C`（不含 bias；本实验卷积无 bias）。

**2. pointwise 1×1**：`Cin→Cout` 的普通卷积，每个输出像素是全部输入通道的加权和；
权重 `(Cout,Cin,1,1)`，参数 `Cin·Cout`。它负责通道混合，不利用空间邻域。

**3. 参数量与压缩比**：

- DS 块 = depthwise `9Cin` + BN `2Cin` + pointwise `Cin·Cout` + BN `2Cout`；
- 标准块 = `9Cin·Cout + 2Cout`；
- 单块压缩比 `9CinCout / (9Cin + CinCout) = 9Cout/(9+Cout) < 9`。

**4. 为什么 stem / 线性头不压缩**：stem 是 `1→w0` 的标准 3×3（没有 depthwise 可拆），
线性头是 `w[-1]→10` 的全连接；两者在 DS 与标准 CNN 里完全相同，压缩只发生在
三个 DS 块。因此总压缩比（5.44×）小于单块压缩比（6.4×）。

**自测答案**：8→16 的 3×3 换 DS，卷积权重从 1152 降到 200（约 5.8×）；
若把 `groups` 误设成 1、权重仍是 `(16,8,3,3)`，不会报错——它退化成标准卷积，
静默地跨通道求和，训练仍能跑，只是不再是 depthwise。
