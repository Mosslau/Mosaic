# 参考解 4：stride-2 depthwise

MobileNet 用 stride-2 depthwise 下采样，而不是"先池化"：卷积同时完成特征提取与 2× 缩小。

**前向**（pad=1，stride=2）：输出位置 `(i,j)` 取输入窗口
`Xp[:, :, 2i:2i+3, 2j:2j+3]`，与 `K[c]` 逐元素相乘求和：

```
out[n,c,i,j] = Σ_{u,v} Xp[n,c,2i+u,2j+v]·K[c,u,v]
```

**反向**：每个输出位置只对应一个输入窗口，窗口之间**不重叠**（stride=2 = 核宽），
所以 `dX` 是"把 `dout·K` 放回对应窗口"，一般不会重叠；但同一实现要能处理
stride<k 的情形，仍用累加最稳妥：

```
dK[c] += Σ_{n,i,j} dout[n,c,i,j]·Xp[n,c,2i:2i+3,2j:2j+3]
dXp[n,c,2i:2i+3,2j:2j+3] += dout[n,c,i,j]·K[c]
```

`sol-04-步长2.py` 的实测：

```
shape: (2, 3, 4, 4)
K 最大梯度误差: 3.12e-10
X 最大梯度误差: 1.87e-10
```

**和池化的区别**：stride-2 depthwise 的权重可学习，池化是固定的 max/mean；
MobileNet 因此比"CNN + pool"更省参数，也更灵活。**坑**：`pad=1` 时最后一列/行
要落在 `2i+1`，不能越界；用 `H//2` 计算输出尺寸可避免多算一格。
