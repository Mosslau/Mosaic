# 迁移项目：latent 容量与模式覆盖

## 需求

把 GAN 的“模式崩塌”变成可复现的容量实验。与单次 demo 的差别：

1. **固定数据/轮数**：2D 4-Gaussians、500 轮；
2. **扫 latent 容量**：1/2/8/16；
3. **统一指标**：覆盖数、熵、NN 距离、D acc。

## 功能清单

- [x] 4 组 latent 容量训练
- [x] 覆盖/熵/NN 距离指标
- [x] 3 条验收断言

## 验收标准

1. 最大覆盖 **≥3/4**；
2. latent=1 的覆盖 **<** 最佳；
3. 最佳熵 **≥1.0**。

## 运行方式

```bash
cd algorithms/p03-deep-learning/gan/project
uv run python latent_sweep.py
```

运行约 15 秒（CPU）。

## 实测结果（已验证）

| latent | 覆盖 | 熵 | NN 距 | D acc |
|---|---|---|---|---|
| 1 | 2/4 | 0.69 | 0.01 | 0.78 |
| 2 | 0/4 | 0.00 | 2.40 | 0.50 |
| 8 | 0/4 | 0.00 | 0.16 | 0.50 |
| 16 | **4/4** | **1.34** | 0.06 | 0.47 |

**三条结论**：

1. **容量太小会限制覆盖**：latent=1 只覆盖 2/4。
2. **但不是单调的**：latent=2/8 反而崩到 0/4——GAN 对初始化/优化路径极敏感。
3. **指标要组合看**：只看 D acc 或 loss 会误判；覆盖/熵/NN 一起看。
