## 第 1 题（说清）前向、反向与非线性

**目标**：能力 1——复述 MLP 的训练规则。

**要求**：不看文档，写出：

1. 一层的前向式与 ReLU；
2. softmax + 交叉熵的梯度为什么化简成 `(p−y)/n`；
3. 隐层反向为什么要乘 `relu_grad(Z)`；
4. 为什么不能全零初始化。

**验收标准**：写出 `Z=A_prev W+b`、`A=ReLU(Z)`、`dZ=(p−y)/n`、
隐层 `dZ=dA·relu_grad(Z)`；提到"对称性无法打破"。

**提示**：链式法则逐层回传。

## 第 2 题（走通）一个隐单元的手算

**目标**：能力 2——手算一次前向 + 反向。

**要求**：`x=(1,0)`，`y=1`（两类），隐层 1 个 ReLU 单元：

- `W1=[[1],[0]]`，`b1=0`；
- `W2=[1,−1]`，`b2=0`；
- 学习率 `η=1`，交叉熵。

求：

1. 前向的 `z1,a1,logits,proba`；
2. `dZ2`、`dW2`、`dA1`、`dZ1`、`dW1`；
3. 一次 SGD 后的 `W1,W2`。

**验收标准**：`a1=1`，`p≈[0.881,0.119]`，`dZ2≈[−0.119,0.119]`，
`dW2≈[−0.119,0.119]`，`dZ1≈−0.238`，`dW1≈[−0.238,0]`。

**提示**：`dA1=dZ2 @ W2.T`；`dZ1=dA1·relu_grad(z1)`。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从精度/数值/初始化反推错误。

**要求**：三个变体：

- **A**：前向不做 ReLU（等价于线性网络）；
- **B**：softmax 不减最大值；
- **C**：全零初始化。

分别回答：症状是什么？用诊断代码确认。

**验收标准**：A 退化成线性模型/精度接近随机；B `exp(1000)` 溢出/nan；
C 测试精度约 0.1（10 类）。

**提示**：A 用 monkeypatch 把 `relu`/`relu_grad` 换成恒等；B 直接算 `exp`；C 正常训练。

## 第 4 题（实现）整网梯度检查

**目标**：能力 4——用有限差分验证手写反向。

**要求**：

1. 构造小网络（3 维输入、4 个隐单元、3 类）；
2. 用 `backward` 算解析梯度；
3. 对每个 `W/b` 做中心差分，算最大相对误差；
4. 断言误差 <1e-5。

**验收标准**：脚本跑通，输出最大相对误差 <1e-5。

**提示**：`eps=1e-6`；只检查 `W` 也能说明问题，但建议 `b` 一起查。

## 第 5 题（迁移）隐层宽度/学习率小扫

**目标**：能力 5——用验证集选超参，而不是拍脑袋。

**要求**：

1. digits 训练集再切 20% 验证；
2. 扫 `hidden_sizes ∈ {(16,), (64,), (128,)}` 与 `lr ∈ {0.005, 0.01, 0.05}`；
3. 用验证准确率选最优，报告测试准确率；
4. 说明"更大/更快"为什么不自动更好。

**验收标准**：最优组合测试 acc ≥0.95；结论提到容量/学习率的权衡。

**提示**：固定 `epochs=20, batch_size=32, optimizer="adam"`。
