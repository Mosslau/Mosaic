# 迁移项目：AE 8 维压缩特征 + 逻辑回归分类

## 需求

把 AE 的 latent 用到下游任务上。与 2D 可视化的差别是三个**新约束**：

1. **8 维 latent**（不是 2 维），保留更多判别信息；
2. **下游分类**：用逻辑回归在 latent 上做 10 类分类；
3. **与 PCA / 原始像素对比**：看“有损压缩”的代价。

## 功能清单

- [x] 训练 AE（64→32→8→32→64）
- [x] 用 `encode(X)` 得到 8 维特征
- [x] 对比 raw-64 / AE-8 / PCA-8 + 逻辑回归
- [x] 4 条验收断言

## 验收标准

1. AE-8 测试 acc **≥ 0.92**；
2. AE-8 比 PCA-8 高；
3. raw-64 仍是上限（≥ AE-8）；
4. AE 重构误差 **< 0.02**。

## 运行方式

```bash
cd algorithms/p03-deep-learning/autoencoder/project
uv run python compression.py
```

依赖：numpy + scikit-learn；运行约 1 秒。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4 / scikit-learn 1.9.1），`seed = 0`；
样本 1797（训练 1200 / 测试 597）。

| 特征 | 维度 | 测试 acc |
|---|---|---|
| raw-64 | 64 | **0.9698** |
| AE-8 | 8 | 0.9229 |
| PCA-8 | 8 | 0.8945 |

AE 训练耗时约 0.46s；重构 MSE 0.0149。

**四条结论**：

1. **8 维保留了大部分判别信息**：AE-8 0.923，只比 raw 低 0.047。
2. **AE 比 PCA 更适合这个下游任务**：0.923 vs 0.894；非线性表示保留了更多可分性。
3. **有损压缩有代价**：raw-64 仍是上限。
4. **重构好 ≠ 分类好**：AE 的目标是重建，不是判别；要按下游指标选表示。
