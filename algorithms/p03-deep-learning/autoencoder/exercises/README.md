## 第 1 题（说清）AE 的四个部件

**目标**：能力 1——复述编码、瓶颈、解码、重构损失。

**要求**：不看文档，写出：

1. 编码器/解码器的映射；
2. 瓶颈维度与压缩率；
3. 重构损失；
4. denoising AE 的输入/目标差别。

**验收标准**：`z=f(x)`、`x_hat=g(z)`、MSE；denoising 输入加噪、目标干净。

---

## 第 2 题（走通）线性 AE 与 PCA

**目标**：能力 2——手算一维线性 AE。

**要求**：`x` 一维，`z=wx`，`x_hat=w²x`：

1. 写重构误差；
2. 求最优 `w`；
3. 解释为什么线性 AE 的 2D 子空间等于 PCA 前两维。

**验收标准**：误差 `x²(w²−1)²`；`w=±1`；线性 AE 学到主成分子空间。

---

## 第 3 题（判断）三个“看起来能跑”的实现

**目标**：能力 3——从重构/训练/去噪反推错误。

**要求**：三个变体：

- **A**：MSE 反传除以 batch size（而不是元素数）；
- **B**：输出层不用 sigmoid，直接线性输出；
- **C**：denoising 时目标也用加噪图。

分别回答：症状是什么？为什么？

**验收标准**：A 梯度放大、训练不稳；B 重构越界/难收敛；C 学成恒等映射，去噪失败。

---

## 第 4 题（实现）加噪函数

**目标**：能力 4——实现 denoising AE 的输入损坏。

**要求**：

1. 对 `[0,1]` 图像加高斯噪声 `N(0,σ²)`；
2. 截断到 `[0,1]`；
3. 用同一个 AE 比较“加噪训练 vs 干净训练”在加噪测试集上的 MSE。

**验收标准**：加噪训练在加噪测试集上 MSE 更低。

---

## 第 5 题（迁移）latent 分类

**目标**：能力 5——把 AE 表示用到下游任务。

**要求**：

1. 训练 8 维 AE；
2. 用 `encode` 得到训练/测试特征；
3. 训练逻辑回归，报告 acc；
4. 与 PCA-8、raw-64 对比。

**验收标准**：AE-8 ≥0.92；AE-8 > PCA-8；raw-64 仍是上限。
