# 参考解 01：概念复述

- **objectness**：该网格单元内是否有目标中心。单类检测只回答"有/没有"，不分类别；`σ(o)` 是它的概率。
- **bbox 偏移**：正格输出 4 个数 `tx,ty,tw,th`，解码为
  `cx=(gx+σ(tx))·4`、`cy=(gy+σ(ty))·4`、`w=σ(tw)·32`、`h=σ(th)·32`，
  再由中心与宽高得到 `(x1,y1,x2,y2)`。σ 把偏移压回 (0,1)，保证中心不跑出本格。
- **IoU**：交集面积 / 并集面积。用途：判断一个预测框是否命中（≥0.5 记为 TP），以及 NMS 里判断两个框是否重复。
- **NMS**：① 所有候选按分数降序；② 取最高分框加入保留集；③ 删掉与它 IoU > 阈值的其余框；④ 重复直到候选为空。
- 为什么只有中心格是正样本：一个目标只让一个格子负责，避免同一目标产生多套回归目标；邻格的重复预测交给 NMS 处理。代价是中心格必须能从局部上下文里被认出来——这也是本实现先做 4×4 池化、再让 3×3 卷积看 12×12 上下文的原因。
