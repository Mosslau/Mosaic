# 参考解 02：手算编码 / IoU / NMS

## 1. bbox (7,6,15,14) 的编码

中心 `cx=(7+15)/2=11`，`cy=(6+14)/2=10`。格边长为 4，所以
`gx=floor(11/4)=2`、`gy=floor(10/4)=2`（第 2 列第 2 行，覆盖 8..12）。

| 量 | 计算 | 值 |
|---|---|---|
| fx | (11−8)/4 | 0.75 |
| fy | (10−8)/4 | 0.5 |
| w | (15−7)/32 | 0.25 |
| h | (14−6)/32 | 0.25 |

回归目标（logit）：`tx=log(0.75/0.25)=log 3 ≈ 1.0986`，`ty=log(0.5/0.5)=0`，
`tw=th=log(0.25/0.75)=log(1/3) ≈ −1.0986`。这四项就是 `encode_targets` 写进
`tbox[2,2]` 的值。

## 2. 与预测框 (8,7,16,15) 的 IoU

两框都是 8×8：交集 `x∈[8,15]`、`y∈[7,14]`，面积 `7×7=49`；并集 `64+64−49=79`；
**IoU = 49/79 ≈ 0.620**（低于 0.5 才算没命中；这里 ≥0.5，是 TP）。

## 3. NMS（IoU 阈值 0.5）

按分数：A(.9) → B(.8) → C(.4)。

1. 保留 A；B 与 A 的交集 9×9=81，并集 100+100−81=119，IoU≈0.681>0.5 → 抑制 B。
2. C 与 A 不相交，保留 C。

**保留集合 = {A, C}**。若把阈值改成 0.95，B 会留下——这就是练习 3 的反例。
