# 参考解 03：失效变体诊断

## 变体甲：删掉 NMS

**先坏的是 precision。** 一个目标只有中心格是正样本，但邻格的 3×3 上下文与中心格相似，
objectness 也会过阈值；这些框彼此高度重叠，都是同一目标的重复检测。

反例：目标 `(10,10,18,18)`，中心格与右邻格各输出一个框：
`(10,10,18,18)` 与 `(11,10,19,18)`，IoU≈0.78。不抑制就产生 1 TP + 1 FP，
P 从 1.0 掉到 0.5，R 不变。

## 变体乙：NMS 阈值 0.95

**重复框会留下，precision 下降，且更隐蔽。** 上例 IoU 0.78 < 0.95，两个都保留。
阈值越接近 1，NMS 越接近"不做事"；阈值越低，越容易把相邻的真实目标误抑制（recall 下降）。
所以 0.3–0.5 是常见折中，且必须用 val 选。

## 阈值为什么不能在 test 上选

在 test 上扫阈值再报告最好结果，等于把测试集当验证集：指标会偏乐观，也无法回答
"换一批数据还能不能用"。正确做法：train 学参数 → val 选 conf/NMS/基线参数 →
test 只评估一次。
