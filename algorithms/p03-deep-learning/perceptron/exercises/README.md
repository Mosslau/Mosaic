## 第 1 题（说清）规则与收敛

**目标**：能力 1——复述感知机的判决、更新与收敛条件。

**要求**：不看文档，写出：

1. 判决式与 `sign(0)` 的约定；
2. 错分条件与更新式；
3. 收敛定理成立的前提；
4. 为什么感知机没有"损失函数"也能学习。

**验收标准**：写出 `ŷ=sign(w·x+b)`、`y(w·x+b)≤0` 时更新、仅线性可分收敛；
提到"错分驱动、不优化概率/间隔"。

## 第 2 题（走通）两个点的两轮更新

**目标**：能力 2——手算在线更新。

**要求**：`x1=(1,0), y1=+1`；`x2=(0,1), y2=−1`；`lr=1`，`w=0,b=0`，按 x1→x2：

1. 第一轮每个样本是否更新？更新后 `w,b`；
2. 第二轮是否还有错分？
3. 最终边界方程。

**验收标准**：第一轮 x2 后 `w=(1,−1), b=0`；第二轮零错误；边界 `x0=x1`。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从报错/边界/收敛反推错误。

**要求**：三个变体：

- **A**：标签用 `{0,1}`；
- **B**：每个 epoch 不打乱顺序；
- **C**：判决用 `sign(0)=−1`，但更新仍用 `y·score≤0`。

分别回答：症状是什么？用诊断代码确认。

**验收标准**：A 报标签错误；B 结果对固定顺序敏感/无随机性；C 边界上的点判决与更新条件矛盾。

**提示**：A 看校验；B 比较不同初始顺序；C 构造一个恰好落在边界上的点。

## 第 4 题（实现）Pocket 算法

**目标**：能力 4——给不可分数据加"保留历史最优"。

**要求**：

1. 每个 epoch 记录当前 `w,b` 的训练准确率；
2. 保留历史最优（Pocket）；
3. 在重叠数据上比较"最后一次更新"与 Pocket 的准确率；
4. 说明它是否解决收敛问题。

**验收标准**：Pocket 准确率 ≥ 最后一次更新；结论提到"不保证收敛，只是保留更好快照"。

**提示**：每轮结束在训练集上评估一次。

## 第 5 题（迁移）一对多感知机

**目标**：能力 5——把二分类器扩展到多分类。

**要求**：

1. 取 digits 的 3 个类别；
2. 每类训练一个"该类 vs 其余"的感知机；
3. 预测时取 `decision_function` 最大的类；
4. 与逻辑回归的一对多比较准确率。

**验收标准**：多分类准确率 ≥0.9；解释"感知机没有概率，只能比分数"。

**提示**：标签转成 ±1；`StandardScaler` 后训练。
