# 迁移项目：乳腺癌数据上的感知机 vs 逻辑回归

## 需求

把感知机用到真实二分类数据上。与教学示例（二维线性可分）的差别是三个**新约束**：

1. **真实 30 维特征**：sklearn `breast_cancer`（569 条，恶性/良性）；
2. **线性不可分**：误差不会归零，要看感知机在重叠数据上的真实表现；
3. **与逻辑回归对照**：感知机只有硬判决/分数，逻辑回归有概率与间隔。

## 功能清单

- [x] 手写感知机在真实数据上训练
- [x] 与 sklearn 感知机、逻辑回归并排比较
- [x] 准确率 / F1 / AUC / 轮数 / 误差 / 间隔
- [x] 6 条验收断言

## 验收标准

1. 手写感知机 acc **≥ 0.90**；
2. 与 sklearn acc 差 **≤ 0.02**；
3. 逻辑回归不差于感知机（允许 0.02 回退）；
4. 手写 AUC **≥ 0.95**；
5. 真实数据上**误差不归零**；
6. 间隔 **> 0**。

脚本 `breast_cancer.py` 内逐条断言。

## 运行方式

```bash
cd algorithms/p03-deep-learning/perceptron/project
uv run python breast_cancer.py
```

依赖：numpy + scikit-learn；运行约 1 秒。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4 / scikit-learn 1.9.1），`seed = 0`。
样本 569（训练 398 / 测试 171），特征 30 维。

| 方法 | acc | F1 | AUC |
|---|---|---|---|
| 手写感知机 | 0.947 | 0.957 | 0.995 |
| sklearn 感知机 | 0.930 | 0.946 | 0.965 |
| 逻辑回归 | **0.959** | **0.967** | **0.996** |

手写感知机：200 轮，最后一轮仍有 **2** 个错误，间隔 0.019；逻辑回归间隔 0.579（标准化空间）。

**四条结论**：

1. **感知机在真实重叠数据上仍可用**：acc 0.947、AUC 0.995，但误差不归零。
2. **与 sklearn 差距在可接受范围**：acc 0.947 vs 0.930，差 0.017（随机顺序/停止规则不同）。
3. **逻辑回归更稳**：acc/F1/AUC 都略高，且有概率；感知机只给分数。
4. **间隔很小**：0.019，说明它停在一条"贴得很近"的分隔面；不最大化间隔。

## 扩展方向
