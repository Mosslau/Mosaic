## 第 1 题（说清）RNN、LSTM、BPTT、裁剪

**目标**：能力 1——复述循环网络的四件事。

**要求**：不看文档，写出：

1. RNN 的递推式；
2. LSTM 的三个门与细胞状态更新；
3. BPTT 里 `dh` 为什么要累加；
4. 梯度裁剪对方向/范数的影响。

**验收标准**：写出 `h_t=tanh(...)`、`c_t=f⊙c_{t-1}+i⊙g`、`h_t=o⊙tanh(c_t)`；
说明 `dh` 有“未来 + 本步输出”两路；裁剪只缩范数不改方向。

## 第 2 题（走通）两步标量 RNN 的梯度

**目标**：能力 2——手算前向与 `dh0`。

**要求**：`h_t=tanh(0.5h_{t-1}+x_t)`，`h0=0`，`x=[1,0]`，输出 `h2`：

1. 算 `h1,h2`；
2. 算 `∂h2/∂h0`；
3. 若 T=10、每步因子约 0.45，梯度大约是多少？

**验收标准**：`h1≈0.7616`、`h2≈0.3630`、梯度 ≈0.091；T=10 约 `0.45^10≈3e-4`。

## 第 3 题（判断）三个“看起来能跑”的实现

**目标**：能力 3——从梯度/记忆/训练反推错误。

**要求**：三个变体：

- **A**：LSTM 遗忘门恒为 0；
- **B**：BPTT 每步用 `dh = 本步输出梯度`，不累加未来；
- **C**：先更新参数、再裁剪梯度。

分别回答：症状是什么？为什么？

**验收标准**：A 细胞状态无法保留历史；B 梯度只看到最后一步；C 裁剪对本次更新无效。

## 第 4 题（实现）全局梯度裁剪

**目标**：能力 4——手写 `clip_gradients`。

**要求**：

1. 输入参数字典与梯度字典；
2. 算全局范数 `sqrt(Σ‖g‖²)`；
3. 超过 `clip` 时按 `clip/‖g‖` 缩放所有梯度；
4. 验证裁剪后范数 ≤ clip，方向不变（余弦相似度≈1）。

**验收标准**：裁剪后范数 = clip；余弦相似度 >0.999。

---

## 第 5 题（迁移）T 的影响

**目标**：能力 5——用实验看“序列变长”对 RNN/LSTM 的影响。

**要求**：

1. parity 任务，T ∈ {4,8,12,16}；
2. 每个 T 训练 RNN 与 LSTM（各 20 轮）；
3. 记录测试 acc 与 `h0` 梯度范数；
4. 解释 RNN 在哪开始崩、LSTM 是否更稳。

**验收标准**：LSTM 在 T=12 仍 ≥0.9；RNN 明显下降；结论提到梯度衰减。
