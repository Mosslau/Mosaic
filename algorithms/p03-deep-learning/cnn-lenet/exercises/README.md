## 第 1 题（说清）卷积、池化、BN、残差

**目标**：能力 1——复述 LeNet 的核心规则。

**要求**：不看文档，写出：

1. 3×3 卷积 + pad1 + stride1 的输出尺寸；
2. im2col 把卷积变成什么矩阵乘；
3. 最大池化反向的规则；
4. BN 训练/推理的统计量差别；
5. 残差 skip 在通道不匹配时怎么处理。

**验收标准**：输出尺寸不变；`cols @ W`；只回传 argmax；train 用 batch、eval 用 running；
1×1 卷积对齐通道。

---

## 第 2 题（走通）2×2 卷积 + 2×2 池化

**目标**：能力 2——手算卷积和池化。

**要求**：输入 4×4（见 README 手算示例），卷积核 `[[1,2],[3,4]]`，无 pad、stride1：

1. 算 3×3 卷积输出的 9 个数；
2. 对**输入**做 2×2 最大池化，写四个窗口最大值；
3. 若池化反向收到全 1 梯度，原图哪些位置得到梯度？

**验收标准**：输出 `[[9,19,21],[5,9,19],[11,5,9]]`；池化 `2,3,2,3`；
梯度落在四个最大值位置。

---

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从伴随误差/梯度/精度反推错误。

**要求**：三个变体：

- **A**：`col2im` 对重叠窗口用赋值而不是累加；
- **B**：最大池化反向把梯度平均分给窗口；
- **C**：BN 推理时仍用当前 batch 统计。

分别回答：症状是什么？用诊断代码确认。

**验收标准**：A 伴随检查误差变大；B 池化伴随检查失败/梯度位置错；C 推理精度随 batch 波动。

---

## 第 4 题（实现）平均池化

**目标**：能力 4——实现 2×2 平均池化的前向/反向。

**要求**：

1. 前向：每个 2×2 窗口取平均；
2. 反向：每个位置分到 `dout/4`；
3. 用伴随检查验证 `<pool(X),G> == <X,pool'(G)>`。

**验收标准**：伴随误差 <1e-10；与最大池化的反向对比（平均 vs argmax）。

---

## 第 5 题（迁移）BN/残差小对照

**目标**：能力 5——用实验选结构，而不是拍脑袋。

**要求**：

1. digits 取 600 张训练、200 张测试；
2. 对比 baseline / +BN / +Residual / +BN+Residual（30 轮）；
3. 记录测试 acc 与末轮 loss；
4. 说明"BN 稳定训练、残差不一定单独有效"。

**验收标准**：四组都跑通；BN+残差 ≥ baseline；结论提到小数据/小图的限制。

cd algorithms/p03-deep-learning/cnn-lenet/exercises
uv run python sol-03-诊断.py
uv run python sol-04-平均池化.py

**2026-10-22 复跑（uv 环境，Python 3.13.15 / numpy 2.5.4 / torch 2.14.1）观察结果**：

- `sol-03`：A 正确 col2im 伴随误差 8.9e-15，赋值版 2.2e-03；B argmax 伴随 0，

- `sol-05`（600/200，30 轮）：baseline 0.7669、+BN 0.8396、+Residual 0.8438、
  +BN+Residual 0.8254——小数据上组合不保证最好。
