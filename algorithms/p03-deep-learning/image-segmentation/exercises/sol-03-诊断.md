# 参考解 03（判断）：伴随检查与指标背离

运行：`uv run python sol-03-诊断.py`（本目录下）。

## A. 上采样反向"只取左上"

正确反向是"每个 2×2 输出块的梯度求和回一个输入像素"；只取左上等于丢掉另外 3 份梯度。
伴随检查 `<up(X),G> = <X,upᵀ(G)>` 不再成立。

实测：正确版误差 `5.3e-15`（数值零），错误版 `3.78`。
修法：`dout.reshape(N,C,H,2,W,2).sum(axis=(3,5))`。

## B. 最大池化反向"均分梯度"

最大池化前向只保留窗口最大值，反向必须按 `argmax` 路由；把 `dout/4` 均分给 4 个位置，
等于把梯度给了 3 个没有参与前向的位置。

实测：argmax 路由误差 `1.8e-15`，均分版误差 `7.73`。
修法：前向保存 argmax 索引，反向用 `put_along_axis` 只写回那个位置。

## C. 只看 pixel accuracy

测试集前景约 13%，两个极端策略：

| 策略 | pixel acc | IoU |
|---|---|---|
| 全预测背景 | 0.8755 | 0.0000 |
| 最佳全局阈值 | 0.9346 | 0.4779 |

全预测背景拿到 87.55% 的 pixel acc，却一个前景都没有；阈值策略的 pixel acc 只高 6 个点，
IoU 却从 0 涨到 0.48。**pixel acc 被背景主导，不能单独作为分割模型的选型指标。**

修法：报告 IoU/Dice（以及边界带指标）；选型时先看混淆矩阵与 per-class 指标。

## 输出

```text
A 上采样反向：正确伴随误差 5.33e-15；只取左上的误差 3.78e+00

C 指标背离：全预测背景 pixel acc 0.8755 / IoU 0.0000；最佳阈值 pixel acc 0.9346 / IoU 0.4779
```
