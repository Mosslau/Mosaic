# 参考解 06（迁移）：噪声下的鲁棒性

运行：`uv run python sol-06-噪声鲁棒性.py`（本目录下，约 16 秒）。

## 设置

- 用主实验同一训练集（320 张，1–2 形状）训练 TinyUNet，60 轮；
- 只在**测试图**上加高斯噪声 `x' = clip(x + N(0,σ²), 0, 1)`，不重新训练；
- 同一噪声图分别喂给 TinyUNet 与逐像素逻辑回归。

## 结果

| σ | 方法 | pixel acc | IoU | Dice |
|---|---|---|---|---|
| 0.00 | TinyUNet | 0.9803 | 0.8503 | 0.9191 |
| 0.00 | 像素逻辑回归 | 0.9344 | 0.4774 | 0.6463 |
| 0.05 | TinyUNet | 0.9301 | 0.4406 | 0.6117 |
| 0.05 | 像素逻辑回归 | 0.9284 | 0.4466 | 0.6174 |
| 0.10 | TinyUNet | 0.9066 | 0.2504 | 0.4005 |
| 0.10 | 像素逻辑回归 | 0.9053 | 0.3581 | 0.5274 |
| 0.20 | TinyUNet | 0.8816 | 0.0488 | 0.0930 |
| 0.20 | 像素逻辑回归 | 0.8325 | 0.2365 | 0.3825 |

## 解释

1. **深度模型不会自动鲁棒。** 训练集噪声 σ=0.05、形状内部 σ=0.025；测试时再叠 σ=0.05，
   等于把输入分布整体推离训练分布，TinyUNet 的 IoU 从 0.85 腰斩到 0.44。
2. **σ=0.05 时像素基线反超**（0.4466 vs 0.4406）。它只学了一个单调阈值，
   噪声让两类灰度都变宽，但"矩形比背景亮"这个顺序没变，所以它退化得慢；
   CNN 依赖的局部纹理/平滑度被噪声破坏得更彻底。
3. **pixel acc 仍然很好看**（0.93），但 IoU 已经崩了——再次说明类别不平衡下不能只看 pixel acc。
4. 这不代表"CNN 不如阈值"：干净数据上 CNN IoU 高 0.37；它说明**部署分布**决定结论。

## 改进方案（至少一条）

- 训练时做噪声增广（σ 从 0 到 0.1 随机），让模型见过带噪输入；
- 测试时先做去噪/平滑（如 3×3 中值滤波）再分割；
- 用域适应/微调少量带噪标注；
- 监控线上 IoU 与输入噪声水平，而不是只看离线干净测试集。
