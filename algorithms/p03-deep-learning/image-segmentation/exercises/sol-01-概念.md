# 参考解 01（说清）：分割、IoU/Dice 与编码器-解码器

## 1. 分割与分类的输出

- 图像分类：一张图 → 一个类别（或类别概率），输出维度与图像大小无关。
- 语义分割：一张图 → **每个像素一个类别**，输出与输入同尺寸的 mask。
  本实验是二分类分割：每个像素判"前景 / 背景"，输出 `(N,1,32,32)` 的概率图。

## 2. IoU 与 Dice

记预测前景集合为 `P`、真值前景为 `T`：

```text
IoU  = |P∩T| / |P∪T|
Dice = 2|P∩T| / (|P|+|T|)
```

- 完全重合：`|P∩T|=|P|=|T|`，IoU=1，Dice=1。
- 完全错开：交为 0，IoU=0，Dice=0。
- 两者都空：`impl.py` 约定为 1（"没有前景且也没预测前景"算完全正确），
  这是工程约定，不是数学上的唯一答案；评估时要与团队统一。

关系：`Dice = 2·IoU / (1+IoU)`，所以同一预测的 Dice 通常大于 IoU。

## 3. pixel accuracy 为什么会骗人

本实验前景只占约 13%。一个"全预测背景"的模型：

- pixel accuracy ≈ 87%，看起来不错；
- IoU = 0，Dice = 0，因为它一个前景都没找到。

类别不平衡时，pixel accuracy 被背景像素主导；分割任务必须同时看 IoU/Dice
（或 per-class IoU、边界 F1）。这也是练习 3 的 C 变体。

## 4. 编码器、解码器、上采样

- **编码器**：卷积 + 池化，把 32×32 压到 16×16，提取"这里像不像形状的一部分"的语义特征；
- **解码器**：把低分辨率特征还原回 32×32，再卷积分辨边界；
- **上采样**：把小特征图放大。最近邻是"每个像素复制 2×2"，没有参数；双线性按距离加权。
- 本实现：`conv(1→8) → pool → conv(8→16) → upsample → conv(16→8) → 1×1 conv → sigmoid`。

## 5. 与完整 U-Net 的关键差别

完整 U-Net 在编码器和解码器之间有 **skip connection**，把高分辨率浅层特征直接拼给解码器，
所以边界细节保得住。本实验的 TinyUNet-lite **没有 skip**，16×16 瓶颈上采样后只能靠
`conv(16→8)` 猜边界，因此边界带准确率明显低于内部区域（见 README 实验三）。

一句话：**TinyUNet-lite 是编码器-解码器骨架，不是完整 U-Net；讲清了"压缩-还原"，
但没讲 skip 的细节保真。**
