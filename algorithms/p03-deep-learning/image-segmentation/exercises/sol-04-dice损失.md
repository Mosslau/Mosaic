# 参考解 04（实现）：soft Dice loss 与梯度

运行：`uv run python sol-04-dice损失.py`（本目录下）。

## 定义

对一张图（拉平成 `p`、`t`，逐图求 Dice 再对 batch 平均）：

```text
I = Σ p_j t_j
S = Σ p_j + Σ t_j
D = (2I + ε) / (S + ε)
L = 1 - (1/N) Σ_i D_i
```

ε 防止全空图分母为 0。

## 对 logits 的梯度

先对概率求导：

```text
∂D/∂p_j = [2 t_j (S+ε) - (2I+ε)] / (S+ε)²
∂L/∂p_j = -(1/N) · ∂D/∂p_j
```

再乘 sigmoid 的导数：

```text
∂L/∂z_j = ∂L/∂p_j · p_j(1-p_j)
```

脚本把 `∂L/∂z` 接到与 `TinyUNet.backward` 相同的链上（`1×1 conv → conv3 → 上采样反向
→ conv2 → maxpool 反向 → conv1`），所以只换损失、不换网络。

## 数值检验

中心差分对 2×5 的随机 logits 检验，最大误差 `5.2e-11`，梯度实现正确。

## 对比结果（192 训练 / 48 测试，30 轮，同一初始化种子）

| 损失 | 末轮 loss | pixel acc | IoU | Dice |
|---|---|---|---|---|
| BCE | 0.1413 | 0.9585 | 0.6934 | 0.8190 |
| Dice | 0.1100 | 0.9757 | 0.8195 | 0.9008 |

Dice loss 直接优化重叠率，在这个类别不平衡的小数据上 IoU 提升约 0.13。

## 风险

- Dice 是比值，分母 `S` 可能很小（全空或近全空），梯度会放大；
- 小批量下每个 batch 的 Dice 方差大，训练更抖；
- 实践常把 BCE 与 Dice 加权组合（如 `0.5·BCE + 0.5·Dice`），兼顾像素级校准与重叠率。
