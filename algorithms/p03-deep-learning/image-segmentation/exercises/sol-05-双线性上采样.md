# 参考解 05（实现）：双线性上采样与反向

运行：`uv run python sol-05-双线性上采样.py`（本目录下）。

## 公式（align_corners=False）

输出坐标 `o` 对应的输入连续坐标：

```text
src = (o + 0.5) / scale - 0.5
i0  = floor(src),  i1 = i0 + 1
w   = src - i0
```

四个权重是 `(1-wy)(1-wx)`、`(1-wy)wx`、`wy(1-wx)`、`wy·wx`；
越界下标钳到 `[0, H-1]` / `[0, W-1]`，所以边界像素自然退化为复制。

## 2×2 → 4×4 手算

输入 `[[0,1],[2,3]]`：

```text
0    0.25 0.75 1
0.5  0.75 1.25 1.5
1.5  1.75 2.25 2.5
2    2.25 2.75 3
```

例：`out[1,1]` 的 `src=(1.5/2)-0.5=0.25`，y/x 权重都是 0.75/0.25，
`0.75·(0.75·0+0.25·1) + 0.25·(0.75·2+0.25·3) = 0.75`。

## 反向

反向是前向的转置：每个输出像素的梯度按同样四个权重**累加**回四个输入位置：

```text
dX[i0,j0] += g·(1-wy)(1-wx)
dX[i0,j1] += g·(1-wy)wx
dX[i1,j0] += g·wy(1-wx)
dX[i1,j1] += g·wy·wx
```

脚本用随机 `X/G` 做伴随检查，误差 `3.6e-15`；最近邻的伴随误差同量级。

## 双线性 vs 最近邻

- 最近邻：无参数、快、块状边缘；反向只是块求和；
- 双线性：输出平滑，但边界会"糊"一点，且反向要乘四个权重；
- 本实验主模型用最近邻，是为了让"上采样无参数、反向就是求和"这一机制最清楚地暴露出来；
  换双线性不会改变网络结构，只会让解码更平滑（可作扩展）。

代价：双线性每个输出像素要做 4 次乘加并维护 4 个索引；最近邻只需 repeat。
