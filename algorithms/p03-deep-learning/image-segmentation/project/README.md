# 迁移项目：多形状分割与面积测量

## 需求

把 TinyUNet-lite 从"每张图 1–2 个形状"迁到"每张图 1–3 个互不重叠的形状"，
并回答一个工业视觉问题：**分割出来的 mask 能不能直接量面积？**

与教学实验的差别是三个新约束：

1. **多形状**：一张图最多 3 个连通域，模型要同时找全，不能只抓最亮的一个；
2. **后处理**：预测 mask 的 1–2 像素孤立噪点会被误数成形状，必须先清理再计数；
3. **面积测量**：不只算 IoU，还要数组件个数、量每个组件的面积，并换算成物理单位。

## 功能清单

- [x] 复用 `data.make_dataset(max_shapes=3, allow_overlap=False)` 生成 1–3 形状数据
- [x] 复用手写 `TinyUNet` 训练 60 轮（480 训练 / 96 测试）
- [x] 手写四邻域连通域标记与组件面积
- [x] 去掉 <15 像素的小组件后再计数（后处理）
- [x] 按 GT 组件与预测组件的 IoU 做匹配，统计组件面积误差
- [x] 像素面积 × `0.25 mm²/像素` 换算物理面积
- [x] 按 1/2/3 形状分组的 IoU 与面积误差表
- [x] 5 条验收断言

## 验收标准

1. 测试集平均 IoU **> 0.80**；
2. 测试集平均 Dice **> 0.88**；
3. 组件数完全正确的图片比例 **> 70%**；
4. 每张图总面积的相对误差均值 **< 15%**；
5. GT 组件被成功匹配（IoU ≥ 0.5）的比例 **> 75%**。

脚本 `segment_area.py` 末尾逐条断言，任一不满足即非零退出。

## 运行方式

```bash
cd algorithms/p03-deep-learning/image-segmentation/project
uv run python segment_area.py
```

依赖：numpy + scikit-learn（只被 `baseline.py` 间接引用；本项目本身只用 numpy）。
本机约 25 秒（CPU，训练占 24.7 秒，随环境变化）。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4），`random_state=0`，训练 480 张、测试 96 张，
每张 1–3 个互不重叠的矩形/圆，前景占比 0.162。

| 指标 | 数值 |
|---|---|
| 平均 IoU | **0.8239** |
| 平均 Dice | **0.8993** |
| pixel acc | 0.9645 |
| 组件数正确率（清理后） | **71.9%** |
| 总面积相对误差 | **11.57%** |
| 匹配组件的面积误差 | **13.90%** |
| GT 组件匹配率 | **84.5%** |

按形状个数拆分：

| 形状数 | 样本 | 平均 IoU | 面积相对误差 | 组件数完全正确 |
|---|---|---|---|---|
| 1 | 58 | 0.8279 | 10.97% | 65.5% |
| 2 | 30 | 0.8215 | 11.58% | 76.7% |
| 3 | 8 | 0.8032 | 15.87% | 100% |

**后处理是关键**：不做小组件清理时组件数正确率只有 **31.2%**（很多 1 像素预测被数成形状），
去掉 <15 像素的孤立组件后升到 **71.9%**，IoU 也从 0.8037 升到 0.8239。

面积样例（一张 2 形状测试图）：

| | 组件 1 | 组件 2 |
|---|---|---|
| 真值面积（像素 / mm²） | 113 / 28.2 | 149 / 37.2 |
| 预测面积（像素 / mm²） | 101 / 25.2 | 110 / 27.5 |

预测面积系统性偏小：0.5 阈值 + 无 skip 的边界模糊会把边缘往里收。若用于质检，
应按标定样本做面积校准（乘一个 >1 的系数），而不是直接相信原始像素计数。

## 结论

1. 多形状（1–3 个）下 IoU 仍有 0.82，说明编码器-解码器能同时处理多个目标；
2. **组件数**比 IoU 更脆弱：边界处 1 像素的断裂/孤点就能改变计数，必须后处理；
3. 面积误差 ~11.6%，主要来自边界收缩，而不是漏检；工业测量要先标定再换算；
4. 3 形状样本只有 8 张，统计意义有限，结论按"方向"看，不当精确估计。

## 扩展方向

- **面积校准**：用验证集拟合 `true_area ≈ a · pred_area + b`，报告校准后的误差；
- **形态学后处理**：开运算去噪点、闭运算补断裂，对比不同 kernel 的计数/面积；
- **重叠目标**：允许形状重叠时，用分水岭或距离变换拆开粘连组件；
- **噪声鲁棒性**：训练时加高斯噪声增广（见 [../exercises/sol-06-噪声鲁棒性.md](../exercises/sol-06-噪声鲁棒性.md)）；
- **多类别**：把 1×1 conv 的 1 个输出通道扩成"背景/矩形/圆"3 类，用 softmax + 多类 Dice；
- **物理标定**：把 `PIXEL_MM2` 换成相机标定得到的真实值，接入产线尺寸测量。
