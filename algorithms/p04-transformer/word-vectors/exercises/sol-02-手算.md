# 参考解 02：手算一步 SGD

## 设定

dim=2；`v_a=[1,0]`、`u_b=[0,1]`、`u_c=[1,0]`、`u_d=[0.5,0.5]`；
正样本 (a,b)，负样本 c、d；学习率 `η=0.1`。
梯度约定与 `impl._train_epoch` 一致：正样本 `∂J/∂score = σ(score)-1`，负样本 `∂J/∂score = σ(score)`。

## 第 1 步：前向打分

| 项 | 内积 | σ | 损失 |
|---|---|---|---|
| 正样本 (a,b) | `v_a·u_b = 0` | 0.5000 | `-log 0.5000 = 0.6931` |
| 负样本 c | `v_a·u_c = 1` | 0.7311 | `-log(1-0.7311) = 1.3133` |
| 负样本 d | `v_a·u_d = 0.5` | 0.6225 | `-log(1-0.6225) = 0.9741` |

合计 `J = 2.9805`。

## 第 2 步：梯度

```text
g_pos = σ(0) - 1   = -0.5000
g_c   = σ(1)       = +0.7311
g_d   = σ(0.5)     = +0.6225

∂J/∂v_a = g_pos·u_b + g_c·u_c + g_d·u_d
        = -0.5·[0,1] + 0.7311·[1,0] + 0.6225·[0.5,0.5]
        = [0.7311+0.3113, -0.5+0.3113] = [1.0423, -0.1888]

∂J/∂u_b = g_pos·v_a = [-0.5, 0]      ∂J/∂u_c = g_c·v_a = [0.7311, 0]
∂J/∂u_d = g_d·v_a   = [0.6225, 0]
```

## 第 3 步：更新（`p ← p - η·∂J/∂p`）

| 参数 | 更新式 | 新值 |
|---|---|---|
| `v_a` | `[1,0] - 0.1·[1.0423,-0.1888]` | `[0.8958, 0.0189]` |
| `u_b` | `[0,1] - 0.1·[-0.5,0]` | `[0.0500, 1.0000]` |
| `u_c` | `[1,0] - 0.1·[0.7311,0]` | `[0.9269, 0.0000]` |
| `u_d` | `[0.5,0.5] - 0.1·[0.6225,0]` | `[0.4378, 0.5000]` |

读法：`v_a` 的第一维被两个负样本往下压（1 → 0.896），第二维被正样本 `u_b` 往上抬
（0 → 0.019）；`u_b` 反而朝 `v_a` 靠近（第二维不动，第一维 +0.05），
这正是 SGNS 的「正样本互相拉近、负样本互相推远」。

## 复算

```bash
../../.venv/bin/python -c "
import numpy as np
va=np.array([1.,0]); ub=np.array([0.,1.]); uc=np.array([1.,0]); ud=np.array([.5,.5])
s=lambda x:1/(1+np.exp(-x)); lr=.1
p,n1,n2=s(va@ub),s(va@uc),s(va@ud)
print(va-lr*((p-1)*ub+n1*uc+n2*ud), ub-lr*(p-1)*va, uc-lr*n1*va, ud-lr*n2*va)"
```

输出即上表四个新值（`[0.8958 0.0189] [0.05 1.] [0.9269 0.] [0.4378 0.5]`）。
注意 `impl` 默认跑的是**批均值梯度**（batch=512），手算对应 `batch=1` 的逐对 SGD，
两者的更新方向一致、步长尺度不同。
