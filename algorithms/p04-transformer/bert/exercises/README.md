## 第 1 题（说清）双向、MLM、15%

**目标**：能力 1——复述 BERT 的训练目标。

**要求**：

1. BERT 的注意力有没有 causal mask？
2. 15% mask 的 80/10/10 是什么？
3. 哪些位置算 loss？
4. `[CLS]` 的作用？

**验收标准**：双向；80% mask/10% 随机/10% 不变；只算 masked；句向量。

## 第 2 题（走通）mask 数量与 loss

**目标**：能力 2——手算 15% 与交叉熵。

**要求**：

1. 20 个非特殊 token，15% 大约几个？
2. 正确 token 概率 0.8，单点 loss？
3. 3 个 masked 位置平均 loss？

**验收标准**：3 个；0.223；平均。

## 第 3 题（判断）三个“看起来能跑”的实现

**目标**：能力 3——从 loss/梯度/mask 反推错误。

**要求**：

- **A**：所有位置都算 loss；
- **B**：`probs[mask]` 直接取所有类别概率；
- **C**：mask 到 `[CLS]`。

分别回答症状。

**验收标准**：A 学成抄输入；B loss 爆炸/梯度错；C CLS 被破坏。

## 第 4 题（实现）15% mask 函数

**目标**：能力 4——实现 mask 策略。

**要求**：

1. 只选非特殊 token；
2. 80% `[MASK]`、10% 随机、10% 不变；
3. 返回 input/target/mask_pos。

**验收标准**：特殊 token 不被选；target 保留原 token。

## 第 5 题（迁移）[CLS] 探针

**目标**：能力 5——评估表示。

**要求**：

1. MLM 训练 BERT；
2. 取 `[CLS]`；
3. 逻辑回归分类；
4. 与 MLM masked acc 对比。

**验收标准**：探针 >0.85；说明 MLM 与分类是两件事。
