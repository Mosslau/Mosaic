## 第 1 题（说清）GPT 的五个部件

**目标**：能力 1——复述 tokenizer/embedding/Block/LM head/采样。

**要求**：写出从文本到下一个 token 的完整链路。

**验收标准**：tokenize → E+P → N Block → LM head → softmax/采样。

## 第 2 题（走通）softmax/temperature/top-k

**目标**：能力 2——手算采样分布。

**要求**：logits `[2,1,0]`：

1. softmax；
2. T=0.5 后的分布；
3. top-k=2 后的分布；
4. 正确 token 概率 0.665 的 CE。

**验收标准**：`[0.665,0.245,0.090]`；`[0.867,0.117,0.016]`；`[0.731,0.269]`；0.408。

## 第 3 题（判断）三个“看起来能跑”的实现

**目标**：能力 3——从生成/训练反推错误。

**要求**：

- **A**：没有 causal mask；
- **B**：没有位置嵌入；
- **C**：生成时每步都用同一个位置 0 的 logits。

分别回答症状。

**验收标准**：A 偷看未来；B 词袋/顺序混乱；C 生成不随前缀变化。

## 第 4 题（实现）字符 tokenizer

**目标**：能力 4——实现 fit/encode/decode + `<unk>`。

**要求**：

1. 按频次/字符排序建表；
2. 未知字符 → `<unk>`；
3. roundtrip。

**验收标准**：已知字符可逆；未知字符映射到 0。

## 第 5 题（迁移）采样策略对比

**目标**：能力 5——比较 greedy/T/top-k。

**要求**：

1. 训练 80 轮；
2. 两个 prompt；
3. 三种策略各生成 36 字符；
4. 说明质量-多样性权衡。

**验收标准**：acc >0.85；生成非空；结论不把“通顺”等同“理解”。
