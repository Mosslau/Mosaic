## 1. 这个族在讲什么

p03 的 AutoEncoder 能“压缩 + 重构”，p04 的 GPT 能“自回归生成”。
p05 补三条不同的生成路线：

- **VAE**：显式概率 latent，能采样、能插值；
- **DDPM**：从噪声逐步去噪，现代图像生成的主线；
- **RAG**：不改模型权重，把外部知识检索进上下文再生成。

三者不是同一算法的三个变体，而是**三种生成/增强范式**。

## 2. 三个实验一览

| # | 实验 | 章节 | 默认数据 | 核心 | 接口形态 | 状态 |
|---|---|---|---|---|---|---|
| 1 | [VAE](vae/) | 4.5 | digits 8×8 / 2D latent | 重参数化、ELBO、KL、采样/插值 | **模型**：`fit(X)` / `sample` / `reconstruct` | ✅ 2026-10-23 |
| 2 | [DDPM](mini-diffusion/) | 6.3 | digits 8×8 | 前向加噪、反向去噪、采样 + **条件/CFG** | **模型**：`train(X,y)` / `sample` | ✅ 2026-10-23 |
| 3 | [RAG](mini-rag/) | 8.1 | 小型文档/问答 | 检索 → 上下文 → 生成 | **流水线**：`index(docs)` / `query(q)` | ✅ 2026-10-23 |

### DDPM 内的条件生成子实验（不单开目录）

DDPM 主线是**无条件**去噪；在同一目录内增加一个条件生成子实验：

1. **class-conditional DDPM**：噪声预测网络输入 `(x_t, t, y)`，`y` 为类别；
2. **CFG（classifier-free guidance）**：训练时以一定概率把 `y` 置空，学条件/无条件两套预测；
3. 采样时：

   ```text
   ε = ε_uncond + w · (ε_cond − ε_uncond)
   ```

   `w=0` 退化为无条件，`w=1` 为标准条件，`w>1` 强化条件；
4. **对照**：`w ∈ {0, 1, 3, 7}` 的类别一致性 / 多样性 / 视觉网格。

> 这是 DDPM 的“条件生成”章节，不是第 4 个实验目录；状态跟 DDPM 一起记。

## 3. 依赖链

```mermaid
flowchart LR
    AE["p03 AutoEncoder<br/>确定性瓶颈"] --> V["1 VAE<br/>概率 latent + 采样"]
    V --> D["2 DDPM<br/>去噪生成"]
    D --> C["条件生成 / CFG<br/>（DDPM 子实验）"]
    G["p04 GPT<br/>自回归生成"] --> R["3 RAG<br/>检索 + 生成"]
    D --> R
```

- **AE → VAE**：从“能重构”到“能按先验采样”；
- **VAE → DDPM**：从显式 latent 到“噪声 → 去噪”的生成；
- **GPT/DDPM → RAG**：生成模型 + 外部知识检索；
- RAG 不是训练新生成模型，而是应用流水线。

## 4. VAE 与 p03 AutoEncoder 的边界

| 维度 | AutoEncoder（p03） | VAE（p05） |
|---|---|---|
| latent | 确定性 `z=f(x)` | 分布 `q(z|x)=N(μ,σ²)` |
| 目标 | 重构 MSE | ELBO = 重构 + KL |
| 采样 | 不能直接采样 | 从先验 `N(0,I)` 采样 |
| 插值 | latent 可能不连续 | 先验约束使插值更平滑 |
| 用途 | 压缩/去噪/表示 | 生成/插值/概率表示 |

> VAE 不是“带噪声的 AE”；关键是**变分下界 + 重参数化 + 先验**。

## 8. 范围边界

## 10. 阶段横向对照（成本/质量/边界）

**口径**：VAE/DDPM/RAG 的任务不同，不能把 MSE/acc/Recall 硬排成一张榜。  
下表只比较**参数量、训练/构建、采样/查询、质量代理**；复现：`uv run python p05-generative/stage_benchmark.py`。

| 方法 | 参数/索引 | 训练/构建 | 采样/查询 | 质量代理 |
|---|---|---|---|---|
| VAE | 4420 | 400ms | 0.1ms（16 样本） | MSE 0.0608（2D latent） |
| DDPM | 36248 | 537ms | 27.8ms（200 样本，100 步） | CFG acc 0.995（w=3） |
| RAG | 12 chunks / 512d | 0.3ms | 0.2ms（12 query） | Recall@3 1.000，MRR 0.958 |

**四条结论**：

1. **VAE 最便宜**：一步解码，采样 O(1)；代价是 2D latent 下重构/生成模糊。
2. **DDPM 最贵**：参数约 VAE 的 8 倍，采样要 100 步串行；换来的条件/CFG 能力最强。
3. **RAG 不训练生成模型**：成本在“建索引 + 检索”；质量强依赖语料和检索，不是模型容量。
4. **三者不是同一任务**：VAE 学 latent，DDPM 学去噪，RAG 学“检索 + 组织上下文”。
