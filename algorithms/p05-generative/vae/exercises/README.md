## 第 1 题（说清）μ/logσ²、重参数化、ELBO

**目标**：能力 1——复述 VAE 的四个量。

**要求**：

1. 编码器输出什么？
2. 重参数化公式？
3. ELBO 两项各是什么？
4. 为什么用 logσ² 而不是 σ？

**验收标准**：四问答对，公式与符号一致；数值稳定。

## 第 2 题（走通）KL 与 z

**目标**：能力 2——手算 KL/重参数化。

**要求**：

1. `μ=0, logσ²=0` 的 KL；
2. `μ=1, logσ²=0` 的 KL；
3. `μ=0, σ=1, ε=0.5` 的 z。

**验收标准**：三个极限值答对，且能解释边界。

## 第 3 题（判断）三个“看起来能跑”的实现

**目标**：能力 3——从 loss/latent/采样反推错误。

**要求**：

- **A**：直接 `z~N(μ,σ²)` 后反传；
- **B**：只算重构，不加 KL；
- **C**：beta 设得极大。

分别回答症状。

**验收标准**：三个失效机制分别答对。

## 第 4 题（实现）KL 闭式

**目标**：能力 4——实现 KL 并做有限差分。

**要求**：

1. `-0.5 Σ(1+lv-mu²-exp(lv))`；
2. 对 μ 的梯度 `mu/N`（按 batch 平均）；
3. 与有限差分比对。

**验收标准**：零点/非负；梯度误差 <1e-8。

## 第 5 题（迁移）采样 + 插值

**目标**：能力 5——生成与 latent 连续性。

**要求**：

1. 训练 2D VAE；
2. 先验采样；
3. 两张图的 μ 插值；
4. 报告 MSE/形状。

**验收标准**：MSE <0.05；采样有限；插值连续。
