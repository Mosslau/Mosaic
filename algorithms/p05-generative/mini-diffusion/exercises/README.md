## 第 1 题（说清）前向/反向/CFG

**目标**：能力 1——复述四个量。

**要求**：

1. `q(x_t|x_0)` 闭式；
2. 训练目标；
3. 反向均值由什么推出；
4. CFG 公式。

**验收标准**：四个公式/量答对且符号一致。

## 第 2 题（走通）一步加噪

**目标**：能力 2——手算 `x_t`。

**要求**：`beta=[1e-4,2e-4]`，`x0=0.5`，`ε=1`，算 `x1`。

**验收标准**：手算结果与闭式公式一致（容差 1e-3）。

## 第 3 题（判断）三个“看起来能跑”的实现

**目标**：能力 3——从 loss/采样反推错误。

**要求**：

- **A**：训练时 t 固定；
- **B**：条件训练不 dropout；
- **C**：CFG 用 `ε_un + w(ε_c-ε_un)` 但 w 设 100。

分别回答症状。

**验收标准**：三个实现的症状分别答对。

## 第 4 题（实现）CFG 组合

**目标**：能力 4——实现 CFG 并验证 w。

**要求**：

1. 条件/无条件 eps；
2. `w=0/1/3` 组合；
3. 验证 w=0 退化为无条件，w=1 为条件。

**验收标准**：公式正确；形状一致。

## 第 5 题（迁移）条件生成评估

**目标**：能力 5——条件采样 + 代理评估。

**要求**：

1. 训练条件 DDPM；
2. 每类采样；
3. 分类器 acc；
4. 说明 acc 的局限。

**验收标准**：acc >0.9；不把 acc 等同视觉质量。
