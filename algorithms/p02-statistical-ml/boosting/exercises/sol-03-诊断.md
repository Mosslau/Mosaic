# 参考解：第 3 题（判断）

| 变体 | 症状 | 诊断 |
|---|---|---|
| A：η=1.0 | 每棵树全盘接受，训练 MSE 极低、测试误差比小 lr 差 | 固定 100 棵，比较 lr=0.05 与 1.0 的测试 MSE |
| B：拟合 y 而非残差 | 每轮都在学同一个目标，`F` 很快"卡住"、残差不再下降 | 打印 staged 训练 MSE，几乎不动 |
| C：用测试集早停 | "早停轮数"和测试误差都偏乐观（选择泄漏） | 对比验证集早停与测试集早停的树数/测试 MSE |

**根因**：A 没有 shrinkage；B 弄错了拟合目标；C 把"用来报告的数据"拿来调参。
运行 `uv run python sol-03-诊断.py` 看具体数字。
