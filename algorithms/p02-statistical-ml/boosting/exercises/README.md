## 第 1 题（说清）加法、残差、学习率、早停

**目标**：能力 1——复述 GBDT 的四要素。

**要求**：不看文档，写出：

1. 加法模型的递推式；
2. 平方损失下"负梯度"为什么等于残差；
3. 学习率与树数的关系；
4. 早停的 patience 与回滚是什么意思。

**验收标准**：写出 `F_m=F_{m-1}+ηh_m`；解释 `−∂L/∂F=y−F`；
提到"η 小需要更多树"；早停要"回滚到验证最优轮"。

**提示**：想想"接力改错"。

## 第 2 题（走通）四个点、一棵树桩

**目标**：能力 2——手算一轮提升。

**要求**：`y=[1,2,3,4]`、`x=[0,1,2,3]`、`η=0.5`：

1. 算基线 `F_0` 与残差；
2. 用 `x≤1.5` 切树桩，算左右叶子值；
3. 写出 `F_1` 与预测；
4. 算更新前后的 MSE。

**验收标准**：`F_0=2.5`、残差 `[−1.5,−0.5,0.5,1.5]`；左 −1、右 +1；
预测 `[2,2,3,3]`；MSE 1.25 → 0.5。

**提示**：叶子值是残差均值；学习率乘在树上。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从误差曲线反推错误。

**要求**：三个变体都能跑：

- **A**：学习率 `η=1.0`（不缩放）；
- **B**：每轮树拟合 `y` 而不是残差；
- **C**：早停直接用测试集当验证集（没有独立验证集）。

分别回答：症状是什么？用诊断代码确认。

**验收标准**：A 训练 MSE 更低但测试更差；B 训练 MSE 很快不再下降/预测几乎不变；
C 的"早停"轮数与测试误差都偏乐观。

**提示**：A 看 lr 0.05 vs 1.0；B 看 staged 曲线是否"卡住"；C 对比验证集早停与测试集早停。

## 第 4 题（实现）特征子采样（colsample）

**目标**：能力 4——给 GBDT 加"每棵树随机看一部分特征"。

**要求**：

1. 每轮随机抽 `m` 个特征（`m < p`），只用这些特征拟合残差树；
2. 预测时按各自的特征子集走树；
3. 在 `p=10`、4 个真特征的数据上，比较 `m=p` 与 `m=6` 的测试 MSE；
4. 说明它和随机森林的"逐划分特征随机"有什么不同。

**验收标准**：两种实现都能跑通；`m=6` 的测试 MSE 不比 `m=p` 差太多（≤15%）；
结论提到"GBDT 的特征子采样是每棵树一次，随机森林是每次划分一次"。

**提示**：树只看到子集列，`predict` 也要用同一子集列。

## 第 5 题（迁移）用验证集选 `(lr, n_estimators)`

**目标**：能力 5——把学习率与树数一起选。

**要求**：

1. 在 1D 数据上切 train/val/test；
2. 对 `lr ∈ {0.05, 0.1, 0.2}`、`n_estimators ∈ {50, 100, 200}` 做网格；
3. 每个组合在 val 上算 MSE，选最优；
4. 报告选中组合的测试 MSE，并与"随手 lr=0.1、100 棵"比较。

**验收标准**：选中的组合测试 MSE 不差于默认组合；结论提到"lr 与树数强耦合，
要在验证集上一起选"。

**提示**：早停也可以叠加，但本题先做网格。
