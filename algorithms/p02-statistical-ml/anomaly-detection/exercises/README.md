## 第 1 题（说清）三种分数与阈值

**目标**：能力 1——复述三种异常分数与 contamination。

**要求**：不看文档，写出：

1. 孤立森林的路径长度与分数关系；
2. LOF 的局部可达密度与 LOF 值；
3. KDE 的分数方向（为什么用负 log 密度）；
4. contamination 与阈值分位的关系。

**验收标准**：能写出 `s=2^{−h/c}`、`lrd` 与 `LOF=邻居lrd均值/自己lrd`、
`score=−log p`；阈值是 `1−contamination` 分位。

**提示**：想想"谁最容易被单独圈出来"。

## 第 2 题（走通）路径长度与分数

**目标**：能力 2——手算孤立森林分数。

**要求**：`ψ=4`，`c(4)=2(ln3+γ)−1.5≈1.852`：

1. 算 `h=1` 与 `h=3` 的异常分数；
2. 哪个更异常？
3. 若 `c(4)` 变成 `3.0`，两个分数各是多少？

**验收标准**：`0.688` 与 `0.326`；`h=1` 更异常；`c=3` 时约 `0.794` 与 `0.5`。

**提示**：`2^{-h/c}`，h 越小分数越高。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从阈值/召回/排序反推错误。

**要求**：三个变体都能跑：

- **A**：训练集里混入 5% 异常；
- **B**：把密度/距离分数当成"越大越正常"（方向反了）；
- **C**：阈值用测试集分数定（不是训练集）。

分别回答：症状是什么？用诊断代码确认。

**验收标准**：A 阈值被抬高、召回下降；B AUC 变成 <0.5；C 测试指标偏乐观。

**提示**：A 比较干净/污染训练集的阈值与召回；B 看 AUC；C 比较训练/测试阈值。

## 第 4 题（实现）Mahalanobis 距离检测器

**目标**：能力 4——用协方差做"全局密度"基线。

**要求**：

1. 在正常训练集上估计均值 `μ` 与协方差 `Σ`；
2. 新样本分数 `d(x)=√((x−μ)ᵀΣ⁻¹(x−μ))`；
3. 阈值取训练分数的 `1−contamination` 分位；
4. 在二维异常数据上与孤立森林比较 AUC。

**验收标准**：AUC ≥0.9；结论提到"Mahalanobis 假设单峰高斯，多峰/局部异常会吃亏"。

**提示**：`np.linalg.inv` 或 `solve`；分数越大越异常。

## 第 5 题（迁移）阈值怎么选

**目标**：能力 5——用 F1/业务代价选 contamination。

**要求**：

1. 在 digits one-class 数据上（0 正常、其他异常）训练 IF；
2. 扫 `contamination ∈ {0.01,0.02,0.05,0.1,0.2}`，算测试精确率/召回率/F1；
3. 找 F1 最优的 contamination；
4. 解释"为什么不能只看 AUC"。

**验收标准**：最优 F1 ≥0.9；结论提到"AUC 与阈值无关，F1 依赖 contamination"。

**提示**：AUC 只排序；F1 需要具体阈值。
