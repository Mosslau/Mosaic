# 迁移项目：真实数据上的 SVM —— 乳腺癌诊断 + C/γ 交叉验证

## 需求

把 SVM 用到真实临床数据上。与教学示例（二维合成数据）的差别是三个**新约束**：

1. **真实数据**：sklearn `load_breast_cancer`，569 个样本、30 维特征，正类占 62.7%；
2. **特征尺度差异大**：细胞核半径/纹理/凹度量纲不同，必须标准化；
3. **两个超参数**：C 与 γ 必须在训练集内用 5 折 CV 选，测试集只报告最终结果。

## 功能清单

- [x] 线性核基线（C=1）
- [x] RBF 的 C × γ 网格（C∈{1,10,100}，γ∈{0.003,0.01,0.03,0.1}）
- [x] 训练集内 5 折 CV 选参；测试集只做最终报告
- [x] 支持向量占比作为复杂度指标
- [x] 6 条验收断言

## 验收标准

1. 线性核测试准确率 **≥ 0.93**；
2. RBF 的 5 折 CV **≥ 0.95**；
3. RBF 测试准确率 **≥ 0.95**；
4. RBF 不差于线性核 **1 个百分点以上**；
5. 支持向量占比 **≤ 60%**；
6. 选中的 γ **不是网格边界**（说明最优点在网格内部）。

脚本 `breast_cancer.py` 内逐条断言。

## 运行方式

```bash
cd algorithms/p02-statistical-ml/svm/project
uv run python breast_cancer.py
```

依赖：numpy + scikit-learn（数据加载用）；运行约 10–20 秒。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4 / scikit-learn 1.9.1），`seed = 0`（切分与 CV）。

| 方法 | 测试准确率 | 支持向量 | 备注 |
|---|---|---|---|
| 线性核（C=1） | 0.9532 | — | 基线 |
| RBF（CV 选参 C=1, γ=0.03） | **0.9532** | 95/398（23.9%） | CV 0.9823 |

**CV 表（部分）**：

| C | γ=0.003 | γ=0.01 | γ=0.03 | γ=0.1 |
|---|---|---|---|---|
| 1 | 0.9547 | 0.9798 | **0.9823** | 0.9647 |
| 10 | 0.9773 | 0.9798 | 0.9798 | 0.9622 |
| 100 | 0.9799 | 0.9798 | 0.9698 | 0.9622 |

**四条结论**：

1. **真实数据上线性核已经很强（0.9532）**：30 维特征里有大量线性可分的信号，
   RBF 没有带来测试集上的提升（同样 0.9532）——这与合成同心圆的结论不冲突：
   核的收益取决于数据是否真的非线性。
2. **CV 选出的 (C, γ) 在内部**（1, 0.03），不是网格边界；CV 0.9823 与测试 0.9532
   之间的差距说明 398 个训练样本上 CV 仍有乐观偏差。
3. **支持向量占 23.9%**：模型复杂度可解释——接近四分之一个训练集参与决定边界。
4. **标准化是必要的**：30 维里"面积"与"平滑度"量级差几个数量级；
   不标准化时 RBF 的 γ 几乎无法选。

## 扩展方向

- 加 **Platt 校准**，把间隔转成概率，比较 Brier 分数；
- 用 **嵌套 CV** 重新估计泛化误差，量化"选参带来的乐观偏差"；
- 换 `load_digits` 的多分类，比较 one-vs-rest 与 one-vs-one；
- 把核矩阵换成 **Nyström 近似**，在更大数据上比较速度/精度。
