# 参考解：第 3 题（判断）

| 变体 | 症状 | 诊断 |
|---|---|---|
| A：标签用 {0,1} | `y·s` 不再是 ±s；`y=0` 的样本 hinge 恒 ≥1，模型被"多数类"拖住，准确率接近随机 | 打印 `y·s` 的符号分布；与 ±1 版本对比 |
| B：梯度漏乘 C | 间隔不随 C 变化（C 形同虚设） | 扫 C={0.1,1,10}，看间隔是否变化 |
| C：RBF 用 +γ | 核值 `exp(+γd²)` 随距离爆炸，数值溢出或矩阵接近奇异 | 打印核矩阵的 min/max；正常应在 (0,1] |

**A 的根因**：hinge 的推导假设 `y∈{−1,+1}`，这样"分对"才对应 `y·s≥1`。
`y=0` 时约束变成 `0≥1−ξ`，永远"违反"，梯度方向也失去意义。

**B 的根因**：C 是正则项与损失项的**相对权重**；漏乘 C 等于固定 C=1。

运行 `uv run python sol-03-诊断.py` 可以看到三种症状的具体数值。
