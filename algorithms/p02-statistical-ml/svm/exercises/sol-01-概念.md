# 参考解：第 1 题（说清）

1. **三个量**
   - 几何间隔：`2/‖w‖`，两条间隔边界之间的距离；最大化间隔 = 最小化 `½‖w‖²`。
   - hinge：`max(0, 1 − y·(w·x+b))`，违反间隔的代价；间隔外为 0。
   - C：每个样本违反间隔的罚金；C 小 → 宽间隔、容忍压线；C 大 → 窄间隔、贴训练集。

2. **为什么只有支持向量决定边界**
   KKT 条件：`α_i=0` 的样本满足 `y_i f(x_i) ≥ 1`，对 `w=Σα_i y_i x_i` 没有贡献；
   只有 `α_i>0`（压线或违反间隔）的样本进入 `w`。

3. **对偶与核**
   `w = Σ α_i y_i x_i`；对偶目标只通过内积 `x_i·x_j` 使用数据，
   把内积换成 `K(x_i,x_j)` 就得到核版本，不需要显式构造 `φ(x)`。
