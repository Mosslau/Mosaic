## 第 1 题（说清）间隔、损失、对偶

**目标**：能力 1——复述 SVM 的核心量与求解路线。

**要求**：不看文档，写出：

1. 几何间隔、hinge 损失、C 各是什么；
2. 为什么只有支持向量决定边界；
3. 对偶问题里 `w` 怎么由 `α` 表示，核技巧替换的是哪一步。

**验收标准**：能写出 `margin=2/‖w‖`、`hinge=max(0,1−y·s)`；第 2 问提到 KKT 的 `α=0`；
第 3 问提到"内积换成核函数"。

**提示**：想想"路宽"和"压线的房子"。

## 第 2 题（走通）三个点、一条竖线

**目标**：能力 2——手算 margin、hinge 和目标值。

**要求**：`w=(1,0)`、`b=0`，三个点 `A=(2,0), y=+1`、`B=(0.5,0), y=+1`、`C=(−1,0), y=+1`：

1. 算每个点的 score、`y·score`、hinge；
2. 算几何间隔；
3. 取 `C=1`，算目标值 `½‖w‖² + CΣhinge`；
4. 指出哪些点是支持向量。

**验收标准**：score = 2 / 0.5 / −1；hinge = 0 / 0.5 / 2；间隔 2；目标值 3.0；
支持向量是 B、C。

**提示**：`y·score ≥ 1` 的点的 hinge 是 0。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从行为反推错误。

**要求**：三个变体都能跑：

- **A**：标签用 `{0,1}` 而不是 `{−1,+1}`；
- **B**：原始问题的梯度里忘记乘 `C`（C 被忽略）；
- **C**：RBF 核写成 `exp(+γ‖x−z‖²)`（符号反了）。

分别回答：会发生什么？怎么用一小段诊断代码确认？

**验收标准**：A 的 hinge 定义失效、准确率接近随机；B 的间隔不随 C 变；C 的核值爆炸/溢出。

**提示**：A 看 `y·s` 的符号；B 扫两个 C 比间隔；C 打印核矩阵的范围。

## 第 4 题（实现）多项式核

**目标**：能力 4——用核函数处理线性不可分，并与框架对拍。

**要求**：

1. 用 XOR 数据（四个点）训练 `KernelSVM(kernel="poly", degree=2, coef0=1)`；
2. 与 sklearn `SVC(kernel="poly", degree=2, coef0=1, C=…)` 对比准确率；
3. 比较 degree=1 与 degree=2 的准确率，解释为什么 1 次分不开。

**验收标准**：degree=2 时两边准确率都是 1.0；degree=1 时 ≤ 0.75；
结论里出现"核把特征映射到高维，使线性可分"。

**提示**：XOR 的四个点在二维里线性不可分，但 `x1·x2` 这个特征能分开它们。

## 第 5 题（迁移）RBF 的 γ 怎么选

**目标**：能力 5——用交叉验证选核参数。

**要求**：

1. 用 `demo.make_circles()` 的数据；
2. 固定 `C=10`，在 `γ ∈ {0.01, 0.1, 0.5, 1, 5}` 上做 5 折 CV；
3. 选出 CV 最优的 γ，报告其测试准确率；
4. 解释 γ 太小/太大分别会发生什么。

**验收标准**：最优 γ 的 CV 准确率 ≥ 0.95；γ 太小时接近线性（<0.75），太大时训练准但泛化差。

**提示**：γ 控制"单个点的影响半径"；`γ→∞` 时每个点自成一体。
