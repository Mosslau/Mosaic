# 参考解：第 2 题（走通）

`w=(1,0)`、`b=0`，所以 `score = x₁`，几何间隔 `2/‖w‖ = 2`。

| 点 | x | y | score | y·score | hinge |
|---|---|---|---|---|---|
| A | (2, 0) | +1 | 2 | 2 | 0 |
| B | (0.5, 0) | +1 | 0.5 | 0.5 | 0.5 |
| C | (−1, 0) | +1 | −1 | −1 | 2 |

目标值（C=1）：

```
½‖w‖² + C·Σhinge = 0.5 + 1·(0 + 0.5 + 2) = 3.0
```

**支持向量**：B（`0<y·score<1`，压线）与 C（`y·score<0`，分错）。
A 在间隔外，hinge=0，不影响解（KKT 的 `α=0` 情形）。
