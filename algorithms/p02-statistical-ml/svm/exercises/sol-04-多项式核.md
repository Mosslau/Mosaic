# 参考解：第 4 题（实现）——多项式核与 XOR

XOR 的四个点：`(−1,−1)`、`(1,1)` 为 −1 类，`(−1,1)`、`(1,−1)` 为 +1 类。
在二维里找不到一条直线分开它们（线性核 ≤ 0.75）。

多项式核 `K(x,z) = (γ x·z + c)^d` 等价于把特征扩展到 `[x1, x2, x1x2, …]`；
`d=2` 时 `x1·x2` 这个特征就能把 XOR 分开。

```python
KernelSVM(C=10, kernel="poly", degree=2, coef0=1, gamma=1, standardize=False)
```

**结果**：degree=1 准确率 0.5；degree=2 准确率 1.0（手写与 sklearn 一致）。
核函数不需要真的构造高维特征，只需要在原始空间算 `(γx·z+c)^d`。
