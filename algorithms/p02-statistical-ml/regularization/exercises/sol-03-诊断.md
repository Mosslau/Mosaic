# 参考解：第 3 题（判断）

| 变体 | 症状 | 诊断 |
|---|---|---|
| A：`XcᵀXc + λI`（漏 n） | 正则偏弱：`‖w‖` 比正确版大，λ 要放大 n 倍才等效 | 对比同一 λ 下的系数模长 |
| B：惩罚截距 | 截距被压向 0；大均值数据上预测整体偏低/偏高，MSE 明显变差 | 打印 `b` 与 `ȳ − x̄w` 的差 |
| C：软阈值漏符号 | 负系数被压成 0 或正数，模型方向错 | 看真实负系数的特征是否变成非负 |

**为什么 A 错**：目标函数是 `(1/n)‖·‖² + λ‖w‖²`，对 w 求导后惩罚项是 `2λw`，
乘 n 后正规方程里出现 `nλ`。写成 `λI` 相当于把正则强度缩小了 n 倍。

**为什么 B 错**：截距不是"斜率"，惩罚它会迫使模型穿过原点附近；正确做法是先中心化，
让截距不被惩罚。

**为什么 C 错**：软阈值是 `sign(ρ)·max(|ρ|−λ, 0)`；漏掉 `sign` 等于假设所有系数非负。

运行 `uv run python sol-03-诊断.py` 可以看到三种症状的具体数字。
