# 参考解：第 1 题（说清）

1. **三个概念**
   - L1 惩罚 `λ‖w‖₁ = λΣ|w_j|`：把不重要的系数压到恰好 0（稀疏）。
   - L2 惩罚 `λ‖w‖² = λΣw_j²`：把系数整体缩小，但不为 0。
   - λ：正则强度。λ=0 退化为普通最小二乘；λ 越大惩罚越重。

2. **为什么不能用训练误差选 λ**
   训练误差 `(1/n)‖Xw−y‖²` 随 λ 增大单调不减（约束越强，能拟合得越差），
   所以最小化训练误差一定选 λ=0。

3. **交叉验证在估计什么**
   把训练集切成 k 份，轮流用 k−1 份训练、1 份验证，平均 k 次验证误差，
   估计"模型在没见过的数据上的误差"。它不碰测试集，所以可以用来选 λ；
   测试集只用于最终报告。
