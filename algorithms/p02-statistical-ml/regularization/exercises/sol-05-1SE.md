# 参考解：第 5 题（迁移）——1-SE 规则

普通做法是选 CV 均值最低的 λ*。**1-SE 规则**更保守：

1. 对每个 λ 记 `mean(λ)` 与 `SE(λ) = std(λ)/√k`；
2. 算 `threshold = mean(λ*) + SE(λ*)`；
3. 在 `mean(λ) ≤ threshold` 的 λ 里，选**最大**的那个（模型最简单）。

**直觉**：CV 曲线在最低点附近往往很平，多个 λ 的差异在"一个标准误"以内，统计上分不出谁更好；
这时优先选更简单的模型——正则化更强、方差更小、更不容易过拟合选择过程本身。

**代价**：λ_1se 的偏差略大；在数据很多、CV 很稳时，它和 λ* 的差别会很小。

运行 `sol-05-1SE.py` 可以看到两套 λ 的测试 MSE 与选择结果。
