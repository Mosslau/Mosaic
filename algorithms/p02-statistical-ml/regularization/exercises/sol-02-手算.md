# 参考解：第 2 题（走通）

`x = [1, 2, 3]`、`y = [1, 3, 5]`，`n = 3`。

**中心化**：`x̄ = 2`、`ȳ = 3`，所以 `Xc = [−1, 0, 1]`、`yc = [−2, 0, 2]`。

**公共量**：

- `XcᵀXc = (−1)² + 0² + 1² = 2`
- `Xcᵀyc = (−1)(−2) + 0·0 + 1·2 = 4`

**λ = 0**：

- `w = 4 / 2 = 2`
- `b = ȳ − x̄w = 3 − 2·2 = −1`
- 预测：`2x − 1 = [1, 3, 5]`（完全拟合）

**λ = 1**：

- `A = XcᵀXc + nλ = 2 + 3 = 5`
- `w = 4 / 5 = 0.8`
- `b = 3 − 2·0.8 = 1.4`
- 预测：`0.8x + 1.4 = [2.2, 3.0, 3.8]`

**解释**：L2 把 `w` 从 2 压到 0.8，预测从"完全贴合 [1,3,5]"变成"向均值 3 靠拢"。
λ 越大，这条线越平。
