## 第 1 题（说清）三个概念、一条规则

**目标**：能力 1——能复述正则化与模型选择的核心。

**要求**：不看文档，写出：

1. L1 惩罚、L2 惩罚、正则强度 λ 各是什么；
2. 为什么"用训练误差选 λ"一定会选到 0；
3. 交叉验证在估计什么，为什么它能用来选 λ。

**验收标准**：能说出 L1 稀疏、L2 收缩的定性差别；第 2 问提到"训练误差随 λ 单调变差"；
第 3 问提到"用没参与训练的部分估计泛化误差"。

**提示**：想想"平时练习"和"期末新题"。

## 第 2 题（走通）三个点、两个 λ

**目标**：能力 2——手解一次 Ridge 闭式解。

**要求**：`x = [1, 2, 3]`、`y = [1, 3, 5]`，分别取 `λ = 0` 与 `λ = 1`：

1. 中心化 X、y；
2. 算 `XcᵀXc`、`Xcᵀyc`、`nλ`；
3. 解出 `w`、`b`，并写出两个 λ 下的预测值。

**验收标准**：`λ=0` 时 `w=2, b=−1`，预测 `[1,3,5]`；`λ=1` 时 `w=0.8, b=1.4`，
预测 `[2.2, 3.0, 3.8]`；能解释"为什么 λ 变大后预测被拉平"。

**提示**：`A = XcᵀXc + nλ`；`b = ȳ − x̄w`。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从系数/预测反推错误。

**要求**：三个变体都能跑：

- **A**：Ridge 的矩阵写成 `XcᵀXc + λI`（漏了 `n`）；
- **B**：把截距也当成普通特征一起惩罚（不中心化）；
- **C**：Lasso 的软阈值写成 `max(ρ − λ, 0)`（漏了符号）。

分别回答：系数/截距会有什么症状？用一段诊断代码确认。

**验收标准**：A 的 `‖w‖` 比正确版大（正则偏弱）；B 的截距被压向 0、预测整体偏移；
C 的负系数被错误地压成 0 或正数。

**提示**：A 看 `nλ`；B 看 `b` 与均值的关系；C 看真实负系数的特征。

## 第 4 题（实现）ElasticNet：L1 + L2

**目标**：能力 4——在坐标下降里同时处理两种惩罚。

**要求**：

1. 目标改为 `(1/(2n))‖Xw+b−y‖² + λ₁‖w‖₁ + (λ₂/2)‖w‖²`；
2. 推导坐标更新式（提示：分母多一个 `λ₂`）；
3. 实现后验证两个极限：`λ₂=0` 应与 Lasso 一致，`λ₁=0` 应与 Ridge（λ=λ₂/2）一致；
4. 在"两个高度相关特征"的数据上，比较 Ridge / Lasso / ElasticNet 的系数稳定性。

**验收标准**：两个极限的系数差 < 1e-6；相关特征上 Lasso 倾向只留其中一部分、ElasticNet 会同时保留。

**提示**：`w_j = soft(ρ_j, λ₁) / (d_j + λ₂)`。

## 第 5 题（迁移）1-SE 规则

**目标**：能力 5——把"选 λ"从"选最低点"升级为"选更简单的模型"。

**要求**：

1. 对一组 λ 做 5 折 CV，记录每折 MSE；
2. 算 `mean` 与 `SE = std / sqrt(k)`；
3. 找到 CV 最低的 λ*，取阈值 `mean(λ*) + SE(λ*)`；
4. 在"CV 均值 ≤ 阈值"的 λ 里选**最大**的那个（最简模型），记为 λ_1se；
5. 比较 λ* 与 λ_1se 的测试 MSE，并解释为什么 1-SE 规则更保守。

**验收标准**：`λ_1se > λ*`；两者的测试 MSE 相差不大（1-SE 用一点偏差换稳定性）；
结论里出现"更简单的模型 / 避免过拟合选择"。

**提示**：CV 曲线在最低点附近很平，选大一点的 λ 通常不会更差。
