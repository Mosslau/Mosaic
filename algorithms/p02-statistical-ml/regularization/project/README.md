# 迁移项目：p > n 的高维小样本 —— Lasso 特征选择 + 稳定性筛选

## 需求

把正则化用到"高维小样本"上。与教学示例的差别是三个**新约束**：

1. **p > n**：80 个样本、100 个特征——普通最小二乘没有唯一解；
2. **只有 8 个真实特征**：其余 92 个是噪声，目标是把它们压掉；
3. **CV 只优化预测**：它选出的 λ 不一定稀疏，需要额外的稳定性筛选。

数据为合成（`n = 80`，`p = 100`，`seed = 0`），真实系数：

```
x0..x7 = [5, −4, 3, 2, −2, 1.5, −1, 0.8]，其余 92 个为 0，噪声 σ = 1.5
```

## 功能清单

- [x] Ridge 的 CV 选 λ（对照：不会稀疏）
- [x] Lasso 的 CV 选 λ + 1-SE 规则
- [x] 比较两者的测试 MSE、非零特征数、真实特征命中数
- [x] Bootstrap 稳定性筛选（30 次重采样，频率 ≥ 0.6 入选）
- [x] 6 条验收断言

## 验收标准

1. Lasso 测试 MSE **≤ Ridge 的 1/2**（p≫n 时 L1 的选择优势）；
2. Lasso 非零特征 **≤ 60**（100 维里压掉至少 40 个）；
3. 稳定性筛选后 **≤ 20** 个特征；
4. 稳定性筛选 **命中 ≥ 6/8** 个真实特征；
5. 真实特征的**平均选中频率 ≥ 0.70**；
6. Ridge **几乎不稀疏**（非零 ≥ 90）。

脚本 `high_dim.py` 内逐条断言。

## 运行方式

```bash
cd algorithms/p02-statistical-ml/regularization/project
uv run python high_dim.py
```

依赖：numpy（`uv sync --extra dev` 已含）。运行时间约 30–60 秒（Lasso 的坐标下降要跑很多次）。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4），`seed = 0`。

| 方法 | 选中的 λ | 测试 MSE | 非零特征 | 命中真实特征 |
|---|---|---|---|---|
| Ridge（CV） | 0.0100 | 50.869 | 100 | 8/8 |
| Lasso（CV） | 0.0022 | **5.604** | 55 | 8/8 |

Lasso 的 1-SE λ = 0.0215（更保守，但非零数仍在 50 上下）。

**稳定性筛选**（λ = 0.1，bootstrap 30 次，频率阈值 0.6）：

| 特征 | 频率 | 真假 |
|---|---|---|
| x0 | 1.00 | 真实 |
| x1 | 1.00 | 真实 |
| x2 | 1.00 | 真实 |
| x3 | 0.97 | 真实 |
| x4 | 0.93 | 真实 |
| x5 | 0.90 | 真实 |
| x6 | 0.70 | 真实 |
| x16 | 0.80 | 噪声 |
| x14 | 0.80 | 噪声 |
| x60 | 0.77 | 噪声 |
| x94 | 0.70 | 噪声 |
| x48 | 0.70 | 噪声 |

选中 **12 个**（7 真 + 5 假），真实特征平均频率 **0.85**，噪声最高 **0.80**。

**四条结论**：

1. **p≫n 时 Ridge 会"全留"**：100 个特征全部非零，测试 MSE 50.9——这不是 Ridge 的错，
   它的目标本来就不含稀疏，小样本下还会过拟合。
2. **Lasso 的选择优势巨大**：测试 MSE 5.6（约为 Ridge 的 1/9），并把非零数压到 55。
3. **CV 选的是"预测最优"，不是"最稀疏"**：CV 最优 λ 只有 0.0022，1-SE 也只到 0.0215；
   想要更稀疏，必须显式加稳定性筛选或按业务约束设 λ。
4. **稳定性筛选会漏也会错**：12 个候选里 7 真 5 假——假阳性来自"偶然与 y 相关"的噪声特征。
   小样本上这很常见，需要更多数据、正交设计或先验知识。

## 扩展方向

- 用**重复 CV**（repeated K-fold）降低 λ 选择的方差；
- 把稳定性筛选的阈值从 0.6 调到 0.8，看假阳性/漏检如何权衡；
- 加**ElasticNet**，比较相关特征下的选择稳定性；
- 换成真实高维数据（基因表达/文本 TF-IDF），验证结论是否成立。
