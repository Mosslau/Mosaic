# 迁移项目：真实三分类数据上的决策树 —— 葡萄酒产地

## 需求

把决策树用到真实多分类数据上。与教学示例（二维 moons）的差别是三个**新约束**：

1. **真实数据**：sklearn `load_wine`，178 个样本、13 维化学特征、3 个产地类别；
2. **三个旋钮**：`max_depth`、`criterion`、`ccp_alpha` 都要在训练集内用 5 折 CV 选；
3. **不稳定性**：除了准确率，还要用 bootstrap 量化"换样本后预测会变多少"。

## 功能清单

- [x] 深度扫描（1–8）的 5 折 CV
- [x] gini vs entropy 的 CV 对比
- [x] `ccp_alpha` 扫描（同分时选最简单的模型）
- [x] 完整树 vs 剪枝树的测试准确率、叶子数
- [x] bootstrap 20 棵树的预测分歧
- [x] 6 条验收断言

## 验收标准

1. CV 最优深度在 **2–6** 之间；
2. 完整树测试准确率 **≥ 0.85**；
3. 剪枝后测试准确率 **≥ 0.85**；
4. 剪枝后叶子数 **< 完整树**；
5. 测试集覆盖 **3 个类别**；
6. bootstrap 预测分歧 **≥ 0.02**（树确实不稳定）。

脚本 `wine.py` 内逐条断言。

## 运行方式

```bash
cd algorithms/p02-statistical-ml/decision-tree/project
uv run python wine.py
```

依赖：numpy + scikit-learn（数据加载与剪枝路径用）；运行约 5–10 秒。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4 / scikit-learn 1.9.1），`seed = 0`。

**深度 CV**：

| depth | 1 | 2 | 3 | 4 | 5–8 |
|---|---|---|---|---|---|
| CV acc | 0.5957 | 0.8717 | 0.8713 | **0.8957** | 0.8957 |

**criterion**：gini **0.8957** / entropy 0.8877。

**ccp_alpha CV**：

| alpha | 0.0000 | 0.0142 | 0.0246 | 0.0659 | 0.2196 | 0.2548 |
|---|---|---|---|---|---|---|
| CV acc | 0.8957 | 0.8957 | **0.8957** | 0.8790 | 0.8150 | 0.7110 |

三个 alpha 打平，按"同分选最简单"取 **0.0246**。

**最终模型**：

| 模型 | 测试 acc | 叶子 |
|---|---|---|
| 完整树（depth=4, gini） | 0.8889 | 9 |
| 剪枝（ccp_alpha=0.0246） | **0.9259** | 5 |

**稳定性**：bootstrap 20 棵剪枝树，测试预测两两分歧 **0.1746**（约 17%）。

**四条结论**：

1. **深度 2 之后收益递减**：depth 2 已到 0.8717，depth 4 到 0.8957，再深不再提升。
2. **剪枝在这里是净收益**：9 叶→5 叶，测试 0.8889→0.9259；小样本上"少切几刀"比"多背几个样本"更值。
3. **gini 与 entropy 接近**（0.8957 vs 0.8877），与 README 的说法一致：多数数据上排序相同。
4. **不稳定性真实存在**：换一批训练样本，约 17% 的测试预测会变——单棵树的方差需要集成来降。

## 扩展方向

- 用 **网格 CV** 同时选 `(depth, ccp_alpha)`，而不是分两步；
- 加 **类别权重**，看少数类召回如何变化；
- 用 **置换重要性** 与 `feature_importances_` 对照，检查重要性是否稳定；
- 换成随机森林，验证"同样的深度，分歧是否下降"。
