# 参考解：第 4 题（实现）——基于验证集的剪枝（REP）

**减少误差剪枝（Reduced Error Pruning）**：

1. 用 train 长一棵完全树；
2. 用验证集 val 评估当前树的准确率；
3. 自底向上遍历内部节点：把该节点的子树临时替换成叶子（叶子取节点多数类），
   若 val 准确率不下降，就保留剪枝；否则恢复；
4. 最后在 test 上只报告一次。

与 `ccp_alpha` 的区别：REP 不需要重新训练，直接看"剪掉后验证误差变不变"；
它更激进，也更容易在验证集小的时候过拟合验证集。

**预期**：剪枝后叶子数减少，val 准确率不降，test 与完全树相差在 2 个百分点内。
