# 参考解：第 3 题（判断）

| 变体 | 症状 | 诊断 |
|---|---|---|
| A：不处理 p=0 | `0*log2(0)` 产生 `nan`，整棵树的不纯度变 `nan`，切分增益全失效 | 打印 `entropy([0,0,1])`，正常 0.918，错误版 nan |
| B：允许空孩子 | 一边为空；若继续递归，同一批样本被反复切分，最终不收敛 | 脚本只演示空孩子这个根因；递归不收敛是它的推论 |
| C：α 分母用叶子数 | 分母偏大 → `α_eff` 偏小 → 该剪的节点不剪，叶子数偏多 | 同一 α 下对比正确/错误实现的叶子数 |

**A 的根因**：`p=0` 的项按极限应为 0，必须显式跳过。
**B 的根因**：划分必须保证左右都至少有 `min_samples_leaf` 个样本。
**C 的根因**：剪掉子树减少的叶子数是 `|T_t|−1`，不是 `|T_t|`。

运行 `uv run python sol-03-诊断.py` 查看三种症状。
