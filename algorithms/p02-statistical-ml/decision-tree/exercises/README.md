## 第 1 题（说清）不纯度、增益、剪枝

**目标**：能力 1——复述决策树的核心量与生长逻辑。

**要求**：不看文档，写出：

1. 熵、基尼、信息增益各是什么；
2. 递归建树的三条终止条件；
3. `ccp_alpha` 在剪什么，α 太大/太小分别会怎样。

**验收标准**：能写出熵/基尼公式；终止条件含"纯/深度/样本数"；第 3 问提到"叶子数罚金"。

**提示**：想想二十问游戏和"多切一刀值不值"。

## 第 2 题（走通）六个样本、两种切法

**目标**：能力 2——手算熵/基尼增益。

**要求**：标签 `[0,0,0,1,1,1]`（`n=6`）：

1. 算划分前的熵与基尼；
2. 切法 A：左 `[0,0,0]`、右 `[1,1,1]`，算两种准则的增益；
3. 切法 B：左 `[0,0,1]`、右 `[0,1,1]`，算两种准则的增益；
4. 说明两种准则是否选出同一个切法。

**验收标准**：A 的熵增益 1、基尼增益 0.5；B 的熵增益约 0.082、基尼增益约 0.056；
两种准则都选 A。

**提示**：`H(2/3,1/3)≈0.918`；`1−2·(1/3)²−2·(2/3)²` 的计算要细心。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从结果反推错误。

**要求**：三个变体都能跑：

- **A**：熵的计算直接写 `p * log2(p)`，没有处理 `p=0`；
- **B**：切分时允许一边为空（不检查 `min_samples_leaf`）；
- **C**：剪枝的 `α_eff` 用"叶子数"而不是"叶子数−1"作分母。

分别回答：会发生什么？用一段诊断代码确认。

**验收标准**：A 出现 `nan`；B 产生空孩子（继续递归会不收敛）；C 的剪枝阈值整体偏小、
该剪的没剪（叶子数偏多）。

**提示**：A 构造含未出现类别的标签数组；B 用 `max_depth=None`；C 对比同一 α 下的叶子数。

## 第 4 题（实现）基于验证集的剪枝（REP）

**目标**：能力 4——用独立验证集做"减少误差剪枝"。

**要求**：

1. 用 60/20/20 切出 train/val/test；
2. 在 train 上长一棵完全树；
3. 自底向上：把每个内部节点试剪成叶子，若验证集准确率不下降就保留剪枝；
4. 比较剪枝前后的叶子数、验证/测试准确率。

**验收标准**：剪枝后叶子数明显减少；验证准确率不降；测试准确率不低于完全树 2 个百分点。

**提示**：先剪子树再判断父节点；叶子用节点上的多数类。

## 第 5 题（迁移）深度与不稳定性

**目标**：能力 5——量化"树越深越不稳"。

**要求**：

1. 用 `make_moons(n=300, noise=0.5, seed=0)`（噪声要足够大，深树才会追噪声）；
2. 对 depth=2 与 depth=8，各做 20 次 bootstrap 重采样训练；
3. 在固定测试集上算两两预测分歧的均值；
4. 比较两个深度，并解释为什么深树更不稳。

**验收标准**：depth=8 的分歧明显大于 depth=2（至少高 0.05）；结论提到"噪声大时深树切分更多、
对样本扰动更敏感"。

**提示**：分歧 = 两棵树预测不同的测试样本比例。
