# 参考解：第 2 题（走通）

标签 `[0,0,0,1,1,1]`，两类各 3 个。

**划分前**：熵 `H=1`，基尼 `G=1−2×(1/2)²=0.5`。

**切法 A**：左 `[0,0,0]`、右 `[1,1,1]`，两个子节点都纯。

- 熵：`1 − (3/6×0 + 3/6×0) = 1`
- 基尼：`0.5 − 0 = 0.5`

**切法 B**：左 `[0,0,1]`、右 `[0,1,1]`，两边都是 `p=(2/3,1/3)`。

- 熵：`H(2/3,1/3)=0.918`；加权 `0.918`；增益 `1−0.918=0.082`
- 基尼：`1−(2/3)²−(1/3)²=0.444`；加权 `0.444`；增益 `0.5−0.444=0.056`

两种准则都认为 A 远好于 B，选 A。
