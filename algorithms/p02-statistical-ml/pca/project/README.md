# 迁移项目：真实数据上的 PCA —— 手写数字 + kNN

## 需求

把 PCA 用到真实高维数据上。与教学示例（二维相关高斯）的差别是三个**新约束**：

1. **真实数据**：sklearn `load_digits`，1797 个 8×8 手写数字、64 维、10 类；
2. **不能泄漏**：先切分 train/test，PCA 只在训练集上 fit；k 用训练集内 5 折 CV 选；
3. **下游任务**：用 kNN 比较"原始像素 vs PCA 降维"的准确率与重建误差。

## 功能清单

- [x] 原始像素 kNN 基线
- [x] k∈{10,15,20,25,30,40} 的 5 折 CV
- [x] 训练集内选 k，PCA fit 只在训练集
- [x] 测试准确率、累计方差、重建 MSE
- [x] 6 条验收断言

## 验收标准

1. 选中的 k 在 **10–40**；
2. PCA + kNN 测试 **≥ 0.90**；
3. PCA 不差于原始像素 **2 个百分点**；
4. 5 折 CV **≥ 0.90**；
5. 测试重建 MSE **< 5**；
6. 累计方差 **≥ 0.85**。

脚本 `digits.py` 内逐条断言。

## 运行方式

```bash
cd algorithms/p02-statistical-ml/pca/project
uv run python digits.py
```

依赖：numpy + scikit-learn（数据与 kNN）；运行约 5–10 秒。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4 / scikit-learn 1.9.1），`seed = 0`。

**原始像素 kNN**：测试 **0.9796**。

**k 的 5 折 CV**：

| k | 10 | 15 | 20 | 25 | 30 | 40 |
|---|---|---|---|---|---|---|
| CV acc | 0.9722 | 0.9785 | 0.9809 | 0.9849 | **0.9857** | 0.9833 |

选中 **k=30**：测试 **0.9833**，累计方差 **0.959**，测试重建 MSE **0.814**。

**四条结论**：

1. **30/64 个主成分保留 95.9% 方差**，kNN 从 0.9796 略升到 0.9833——降维几乎不损精度，
   还省了 53% 的特征。
2. **PCA 没有"提分"义务**：它的目标是压缩/去噪；这里提升来自去掉噪声维度后的距离更干净。
3. **必须防泄漏**：PCA 的均值/主成分若用全量数据 fit，测试折信息会进入降维，
   CV 会偏乐观（练习 3 有量化）。
4. **重建误差与分类精度不是一回事**：k=20 的重建 MSE 已 <2，但 CV 最优在 k=30；
   选 k 要看下游指标。

## 扩展方向

- 先 **标准化** 再做 PCA，比较 kNN 与重建误差（像素同量纲，未必更好）；
- 用 **whiten=True**，看 kNN 的距离是否更合理；
- 换 **逻辑回归/SVM**，比较不同下游模型对 k 的敏感度；
- 用 **核 PCA** 处理非线性结构，比较重建与分类。
