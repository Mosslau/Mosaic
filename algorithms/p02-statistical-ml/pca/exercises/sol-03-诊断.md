# 参考解：第 3 题（判断）

| 变体 | 症状 | 诊断 |
|---|---|---|
| A：不中心化 | PC1 指向均值方向，方差占比被"整体偏移"主导 | 比较 PC1 与 `X.mean(0)` 的夹角；夹角接近 0 即中招 |
| B：全量 fit PCA | 测试集信息进入均值/主成分，CV/测试偏乐观 | 对比"先切分再 fit"与"全量 fit"的 CV 准确率 |
| C：不排序特征值 | 取到的前 k 个方向不是方差最大的，重建误差大 | 检查 `explained_variance_` 是否降序、占比是否最大在前 |

**根因**：A 少了中心化；B 数据泄漏；C 忘了 `eigh` 返回升序、需要反转。
