## 第 1 题（说清）主成分、方差、重建

**目标**：能力 1——复述 PCA 的核心。

**要求**：不看文档，写出：

1. 主成分与协方差矩阵特征向量的关系；
2. 方差占比的定义；
3. 中心化为什么必须；
4. 重建误差与被丢弃特征值的关系。

**验收标准**：写出 `Σv=λv`；`ratio=λ_j/Σλ`；中心化去掉均值方向；
重建误差等于丢弃的 λ 之和（逐元素还要除以 d）。

**提示**：想想"拍照片找角度"。

## 第 2 题（走通）2×2 协方差手算

**目标**：能力 2——手算特征分解与方差占比。

**要求**：协方差矩阵 `[[1, 0.9], [0.9, 1]]`：

1. 求两个特征值；
2. 求对应的单位特征向量；
3. 算方差占比；
4. 只保留 PC1 时，丢掉多少方差？

**验收标准**：`λ=1.9, 0.1`；向量 `(1,1)/√2` 与 `(−1,1)/√2`；
占比 `0.95/0.05`；丢掉 5% 方差。

**提示**：对称矩阵特征向量正交；`λ` 是投影方差。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从方向/占比/下游效果反推错误。

**要求**：三个变体都能跑：

- **A**：忘记中心化，直接对 `XᵀX` 做特征分解；
- **B**：在划分训练/测试之前，用全量数据 fit PCA；
- **C**：特征值没有降序排列，直接取前 k 列。

分别回答：症状是什么？用诊断代码确认。

**验收标准**：A 的 PC1 指向均值方向；B 的测试集信息泄漏、CV 偏乐观；
C 的"第一主成分"不是方差最大的方向。

**提示**：A 看 PC1 与均值向量的夹角；B 比较正确/泄漏的 CV；C 看 explained_variance_ 是否降序。

## 第 4 题（实现）用 SVD 实现 PCA

**目标**：能力 4——理解"协方差特征分解"与"SVD"的等价性。

**要求**：

1. 中心化 `Xc`，做 `np.linalg.svd(Xc, full_matrices=False)`；
2. 用 `Vᵀ` 的前 k 行作为主成分，`S²/(n−1)` 作为特征值；
3. 与 `PCA`（协方差 eigh）比较：主成分方向、方差占比、投影坐标；
4. 说明 SVD 在数值稳定性上的优势。

**验收标准**：两种实现的主成分（允许符号翻转）与方差占比一致到 1e-8；
投影坐标一致；结论提到"SVD 不必显式形成协方差"。

**提示**：`Xc = U S Vt`，`Vt` 的行就是主成分。

## 第 5 题（迁移）按重建误差选 k

**目标**：能力 5——用"重建误差目标"而不是只看累计方差。

**要求**：

1. 在 digits 上计算 k=1..40 的重建 MSE；
2. 找第一个 MSE ≤ 2.0 的 k，记为 k_mse；
3. 找累计方差 ≥ 90% 的 k，记为 k_var；
4. 比较两者的 kNN（k=5）测试准确率，并解释差异。

**验收标准**：两个 k 都 ≤ 40；kNN 准确率都 ≥ 0.9；
结论区分"保留方差"与"保留对任务有用的信息"。

**提示**：重建误差是逐元素 MSE；累计方差看 `explained_variance_ratio_`。
