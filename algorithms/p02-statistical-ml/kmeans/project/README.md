# 迁移项目：真实数据上的 K-Means —— 手写数字聚类

## 需求

把 K-Means 用到真实高维数据上。与教学示例（二维 3 团）的差别是三个**新约束**：

1. **真实数据**：sklearn `load_digits`，1797 个 8×8 手写数字、64 维像素、10 个真实类别；
2. **无监督选 K**：用轮廓系数选 K，不看真实标签；再用 ARI 做事后评估；
3. **初始化稳定性**：比较随机初始化与 K-Means++ 的 8 个种子分布。

## 功能清单

- [x] k=10 的手写 K-Means（n_init=10）与 sklearn 对照
- [x] K=6..12 的 inertia / 轮廓系数 / ARI 扫描
- [x] 轮廓系数选 K（与真实类别数对照）
- [x] 随机 vs K-Means++ 的 8 种子 inertia 对比
- [x] 6 条验收断言

## 验收标准

1. k=10 的 ARI **≥ 0.55**；
2. inertia 与 sklearn 差 **< 1%**；
3. 轮廓系数选出的 K 在 **8–10**；
4. K-Means++ 的平均 inertia **更低**；
5. 簇心数量 = 10；
6. 轮廓系数已计算（有限数）。

脚本 `digits.py` 内逐条断言。

## 运行方式

```bash
cd algorithms/p02-statistical-ml/kmeans/project
uv run python digits.py
```

依赖：numpy + scikit-learn（数据加载与 ARI）；运行约 1–2 秒。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4 / scikit-learn 1.9.1），`seed = 0`。

**k=10**：inertia **1,165,462.7**（sklearn 1,165,188.9，差 0.02%），
ARI **0.6627**，迭代 17，耗时 0.10s。

**K 扫描**：

| k | inertia | 轮廓系数 | ARI |
|---|---|---|---|
| 6 | 1,404,977.1 | 0.1516 | 0.4283 |
| 7 | 1,348,695.9 | 0.1601 | 0.4999 |
| 8 | 1,266,730.2 | 0.1750 | 0.5600 |
| 9 | 1,202,461.1 | **0.1894** | 0.5935 |
| 10 | 1,167,825.0 | 0.1874 | **0.6627** |
| 11 | 1,132,309.5 | 0.1835 | 0.7378 |
| 12 | 1,103,743.4 | 0.1854 | 0.7371 |

**初始化（8 个种子，n_init=1）**：

| 初始化 | inertia 均值 | 标准差 |
|---|---|---|
| random | 1,189,579 | 25,422 |
| kmeans++ | **1,174,275** | **13,628** |

**四条结论**：

1. **K-Means 与 sklearn 的 inertia 几乎相同**（差 0.02%），实现对齐。
2. **轮廓系数选中 k=9**，不是真实的 10：无监督选 K 与"真实类别数"不必一致；
   k=10 的 ARI 反而更高（0.663 vs 0.594）。
3. **ARI 只有 0.66**：像素空间的"球形簇"不能完全对应数字类别；同类数字有多个书写模式，
   不同类也可能像素相近。
4. **K-Means++ 更稳**：均值 inertia 更低、标准差约减半。
