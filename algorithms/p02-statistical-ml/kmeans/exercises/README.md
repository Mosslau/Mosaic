## 第 1 题（说清）目标、两步、初始化

**目标**：能力 1——复述 K-Means 的核心。

**要求**：不看文档，写出：

1. inertia 的定义；
2. 分派步与更新步各做什么；
3. K-Means++ 的采样概率；
4. 轮廓系数的含义与取值范围。

**验收标准**：写出 `J=Σ‖x−μ‖²`；更新步是簇内均值；采样按 `D(x)²` 加权；
轮廓系数在 `[-1,1]`，越大越好。

**提示**：想想"棋子分堆"。

## 第 2 题（走通）四个点、一轮迭代

**目标**：能力 2——手算分派、更新与 inertia。

**要求**：一维点 `[0,1,2,10]`，`K=2`，初始簇心 `0` 与 `10`：

1. 第一轮分派；
2. 更新后的簇心；
3. 更新前后的 inertia；
4. 第二轮还会不会变？

**验收标准**：分派 `{0,1,2}` 与 `{10}`；新簇心 `1` 与 `10`；
inertia 5 → 2；第二轮不变（收敛）。

**提示**：均值是簇内所有点的平均。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从 inertia/标签/ARI 反推错误。

**要求**：三个变体都能跑：

- **A**：`n_init=1` + 随机初始化；
- **B**：最后一轮更新簇心后，不再重新分派，直接返回旧 labels；
- **C**：一个特征量纲是另一个的 1000 倍，且不标准化。

分别回答：症状是什么？用诊断代码确认。

**验收标准**：A 的 inertia 分布很宽；B 的 labels 与 centers 错位（有样本离别的簇心更近）；
C 的 ARI 明显低于标准化后。

**提示**：A 看 20 个种子的 inertia；B 比较 `‖x−μ_own‖` 与最近簇心距离；C 造两个尺度差 1000 的特征。

## 第 4 题（实现）自动找肘部

**目标**：能力 4——把"看拐点"写成可复现的规则。

**要求**：

1. 对 `k=1..8` 跑 K-Means，记录 inertia；
2. 把 `k` 与 `inertia` 都归一化到 `[0,1]`；
3. 连首尾两点成一条直线，找离直线**最远**的点，其 k 就是肘部；
4. 在 3 团数据上验证返回 `k=3`。

**验收标准**：函数返回 3；同时打印各 k 的 inertia 以证明拐点确实在 3。

**提示**：点到直线距离用叉积/面积公式；归一化避免量纲影响。

## 第 5 题（迁移）标准化到底有没有用

**目标**：能力 5——验证"标准化"这个常见建议。

**要求**：

1. 在 `load_digits` 上，用原始像素做 k=10 聚类，算 ARI；
2. 用 `StandardScaler` 标准化后再做 k=10，算 ARI；
3. 比较两者，并解释为什么标准化**不一定**更好；
4. 结论要区分"距离度量需要尺度可比"与"这个数据上标准化是否真的提升"。

**验收标准**：两种都跑通；报告两个 ARI；结论不是简单一句"标准化总是更好"。

**提示**：像素值本身量纲一致；标准化会放大低方差像素，可能破坏结构。
