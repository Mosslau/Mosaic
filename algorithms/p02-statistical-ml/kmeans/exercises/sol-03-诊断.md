# 参考解：第 3 题（判断）

| 变体 | 症状 | 诊断 |
|---|---|---|
| A：n_init=1 + 随机 | 不同种子 inertia 差异很大，偶尔落到差局部最优 | 20 个种子的 inertia 分布，max 远高于 n_init=10 |
| B：最后不重新分派 | labels 是"旧簇心"下的分派，与最终 centers 错位 | 统计"到自有簇心距离 > 到最近簇心距离"的样本数 > 0 |
| C：不标准化 | 大尺度特征主导距离，真实结构被淹没，ARI 低 | 造尺度差 1000 的特征，比较原始 vs 标准化的 ARI |

**根因**：A 没有多重启；B 少了最后一次分派；C 忽略了距离对量纲的敏感性。
运行 `uv run python sol-03-诊断.py` 看具体数字。
