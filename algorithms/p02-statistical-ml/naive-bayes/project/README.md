# 迁移项目：文本垃圾短信分类 —— 词袋 + 多项式 NB

## 需求

把朴素贝叶斯用到文本分类上。与教学示例（二维高斯）的差别是三个**新约束**：

1. **文本 → 计数矩阵**：手写 `CountVectorizer` 做词袋，30 词词表；
2. **合成但可控的语料**：每类 200 条、50% 噪声词，准确率不会"白送"到 100%；
3. **alpha 用 5 折 CV 选**，测试集只报告一次。

> 数据说明：语料由固定模板/词表合成（`demo.make_corpus`），不是真实短信库；
> 验收阈值（0.92）按这份语料设定，**不是**真实短信场景的行业标准；
> 目的是走通"文本 → 词袋 → NB → 评估 → 解释"的完整链路，而不是刷某个榜单。

## 功能清单

- [x] 手写词袋（小写化、`\w+` 切词、词频）
- [x] 多项式 NB + 拉普拉斯平滑
- [x] alpha 的 5 折 CV（0.01–10）
- [x] 测试准确率、与 sklearn 对照
- [x] top spam 词（log 概率差）
- [x] 6 条验收断言

## 验收标准

1. 测试准确率 **≥ 0.92**；
2. 5 折 CV **≥ 0.92**；
3. 选中的 alpha **> 0**；
4. 手写与 sklearn 测试差 **≤ 1 个百分点**；
5. 词表 **≥ 20** 个词；
6. top 词里包含已知 spam 词。

脚本 `spam.py` 内逐条断言。

## 运行方式

```bash
cd algorithms/p02-statistical-ml/naive-bayes/project
uv run python spam.py
```

依赖：numpy + scikit-learn（交叉验证切分与对照）；运行约 1 秒。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4 / scikit-learn 1.9.1），`seed = 0`。

语料 400 条（训练 280 / 测试 120），词表 **30** 个词。

**alpha 的 5 折 CV**：

| alpha | 0.01 | 0.10 | 0.50 | 1.00 | 5.00 | 10.00 |
|---|---|---|---|---|---|---|
| CV acc | **0.9607** | 0.9607 | 0.9607 | 0.9607 | 0.9607 | 0.9607 |

六个 alpha 完全打平，按"第一个最大"选 **alpha=0.01**。

**测试结果**：手写 **0.9417**；sklearn **0.9417**（差 0）。

**最像 spam 的词**：offer(+2.56)、prize(+2.37)、win(+2.24)、urgent(+1.99)、free(+1.76)。

**四条结论**：

1. **文本分类里 alpha 很鲁棒**：0.01–10 的 CV 全部 0.9607；这份语料对平滑不敏感。
2. **准确率不是 100%**：50% 噪声词让一部分短信"两边都像"，NB 会错；这比"满分"更真实。
3. **概率可解释到词**：`log P(w|spam) − log P(w|ham)` 直接给出 top 词，符合直觉。
4. **词袋丢语序**：合成语料没有否定/反讽，真实短信上会吃亏（见 README 局限）。

## 扩展方向

- 换成真实 SMS Spam Collection（需自行下载），看 alpha 是否仍然平坦；
- 用 **TF-IDF** 替代词频，比较长文档/高频词的影响；
- 试 **BernoulliNB**（只看词出现与否），比较短文本效果；
- 做 **概率校准**，把后验转成可解释的风险分数。
