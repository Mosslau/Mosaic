## 第 1 题（说清）先验、似然、平滑

**目标**：能力 1——复述 NB 的四件事。

**要求**：不看文档，写出：

1. 贝叶斯公式与"条件独立"假设；
2. 多项式 NB 的条件概率估计式；
3. 拉普拉斯平滑的分子/分母；
4. 为什么要在对数域计算。

**验收标准**：写出 `P(c|x)∝P(c)∏P(x_j|c)`；平滑式 `(count+α)/(Σcount+αV)`；
提到"连乘下溢，log 后相加"。

**提示**：想想"看到免费就猜垃圾短信"。

## 第 2 题（走通）两条短信、两个词

**目标**：能力 2——手算平滑与后验。

**要求**：训练集：A 类 `["good good","good"]`、B 类 `["bad bad","bad"]`，词表 `{good,bad}`：

1. 先验 `P(A), P(B)`；
2. `α=1` 时 `P(good|A)`、`P(good|B)`；
3. 测试短信只有 `good`，算未归一化的 `P(A|good)` 与 `P(B|good)`；
4. 归一化后的后验。

**验收标准**：先验各 0.5；`P(good|A)=0.8`、`P(good|B)=0.2`；
未归一化 `0.4 / 0.1`；归一化 `0.8 / 0.2`。

**提示**：平滑分母是 `类内总词数 + αV`。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从概率/准确率反推错误。

**要求**：三个变体都能跑：

- **A**：`α=0`（不平滑）；
- **B**：先验用"类内总词数 / 总词数"，而不是"类文档数 / 总文档数"；
- **C**：不用对数域，直接连乘概率。

分别回答：症状是什么？用诊断代码确认。

**验收标准**：A 出现 `−inf`/后验 0；B 的先验偏向长文档类；C 在长文档上概率下溢为 0。

**提示**：A 看未见词的 log 概率；B 造"少而长 vs 多而短"的两类；C 乘 500 个 0.01。

## 第 4 题（实现）Bernoulli NB

**目标**：能力 4——把"词频"换成"词是否出现"。

**要求**：

1. 把计数矩阵二值化（>0 → 1）；
2. 每个类估计 `P(w=1|c)` 与 `P(w=0|c)`（拉普拉斯平滑）；
3. 对数似然 = `Σ x·log p + (1−x)·log(1−p)`；
4. 在短信语料上与 MultinomialNB 比较准确率，说明各自适合的场景。

**验收标准**：Bernoulli 版能跑，测试准确率 ≥0.9；与 Multinomial 的差异有解释
（Bernoulli 只看出现与否，适合短文本）。

**提示**：`P(w=0|c)=1−P(w=1|c)`；两类都要平滑。

## 第 5 题（迁移）alpha 与 top 词

**目标**：能力 5——用 CV 选 alpha，并把模型解释到词。

**要求**：

1. 用 `make_corpus` 生成语料，切 train/test；
2. 对 `α ∈ {0.01,0.1,1,10}` 做 5 折 CV，选最优；
3. 用最优 α 训练，输出测试准确率；
4. 计算 `log P(w|spam) − log P(w|ham)`，列出 top 5 词。

**验收标准**：测试 ≥0.9；top 5 里至少 3 个是已知 spam 词（`demo.SPAM`）；
结论提到"alpha 在这份语料上不敏感"。

**提示**：`feature_log_prob_` 的行对应 `classes_` 的顺序。
