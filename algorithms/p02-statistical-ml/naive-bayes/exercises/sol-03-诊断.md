# 参考解：第 3 题（判断）

| 变体 | 症状 | 诊断 |
|---|---|---|
| A：α=0 | 某类没见过的词 → `log P=−∞`，整类后验为 0 | 打印 `feature_log_prob_` 里的 `−inf` |
| B：先验按总词数 | 长文档类先验被抬高，即使文档数少 | 造"2 条长 A、8 条短 B"，对比两种先验 |
| C：直接连乘 | 长文档概率下溢为 0，所有类都 0 | 500 个 0.01 连乘，打印结果 |

**根因**：A 没有平滑；B 先验口径错（应该按文档数）；C 没有用对数域。
