# 参考解：第 4 题（实现）——交叉熵 + L2

目标函数：

$$J(w,b) = \text{BCE}(w,b) + \frac{\lambda}{2}\lVert w\rVert^2$$

梯度只多一项 `λw`（**不惩罚 b**）：

$$\nabla_w J = \frac{1}{n}X^\top(p-y) + \lambda w,\qquad
\frac{\partial J}{\partial b} = \frac{1}{n}\sum(p-y)$$

**为什么能阻止权重发散**：完全可分时，BCE 可以无限逼近 0，`‖w‖` 会一直涨。
加上 `λ‖w‖²/2` 后，最优解必须让"损失下降"与"权重惩罚"平衡，`‖w‖` 被压在一个有限范围。
从贝叶斯视角看，这等价于给 `w` 加高斯先验（L2 = 高斯，L1 = 拉普拉斯）。

**预期结果**（`sol-04-L2.py`）：`λ` 从 0 增到 10，`‖w‖` 单调下降、训练 BCE 单调上升；`λ ≤ 1` 时 accuracy 基本不变，
`λ = 10` 开始欠拟合（准确率明显下降）——正则化不是越大越好。

代码里 `grad_w = X.T @ (p - y) / n + lam * w` 对应上面的第一行。
