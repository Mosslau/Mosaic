## 第 1 题（说清）四个量、一个决策

**目标**：能力 1——能复述模型与训练规则。

**要求**：不看文档，写出：

1. logit、sigmoid、交叉熵、阈值各是什么（各一句话）；
2. 为什么梯度是 `p − y`，而不是 `z − y`；
3. 为什么"阈值"不属于模型参数。

**验收标准**：能说清 `p = σ(z)` 与 `z = log(p/(1−p))` 的互逆关系；第 2 问提到链式法则与
`σ' = σ(1−σ)`；第 3 问提到"模型只给概率，阈值是业务策略"。

**提示**：想想"预测概率 0.7"和"判不判正类"是两件事。

## 第 2 题（走通）三个点、两步手算

**目标**：能力 2——不靠电脑走通一次交叉熵更新。

**要求**：数据 `x = [1, 2, 3]`、`y = [0, 1, 1]`；初始化 `w = 0`、`b = 0`，学习率 `lr = 0.5`。
填一张逐步表：每一步的 `z`、`p`、BCE、`grad_w`、`grad_b`、更新后的 `w/b`。**走两步**。

**验收标准**：第一步 `grad_w = −0.6667`、`grad_b = −0.1667`，更新后 `w = 0.3333`、`b = 0.0833`；
第二步后 `w ≈ 0.4663`、`b ≈ 0.0785`；BCE 从 0.6931 降到 0.5338。

**提示**：`p = σ(z)`；梯度 `mean((p−y)·x)` 与 `mean(p−y)`；注意 `p` 是概率，不是 `z`。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从症状反推错误原因。

**要求**：下面三个变体都能跑完不报错：

- **A**：梯度写成 `mean((z − y)·x)`（用 logit 代替概率），其余正确；
- **B**：更新写成 `w = w + lr·grad_w`（方向反了）；
- **C**：训练正确，但 `predict` 用 `z >= threshold`（把概率阈值套在 logit 上）。

分别回答：会不会收敛？预测会有什么系统性偏差？怎么用一段诊断代码确认？

**验收标准**：A 的 loss 下降很慢或停在错误位置；B 发散；C 在 `threshold=0.5` 时边界从
`z=0` 偏到 `z=0.5`，预测为正的比例明显偏低。诊断代码要能打印 loss 曲线与预测分布。

**提示**：A 看梯度公式里的 `p` 是否被换掉；B 看 loss 是否单调上升；C 把 `z` 与 `p` 的分布都打印出来。

## 第 4 题（实现）给交叉熵加 L2

**目标**：能力 4——在新目标函数下改实现，并解释几何效果。

**要求**：

1. 目标改为 `BCE + (λ/2)·‖w‖²`（**不惩罚 b**）；
2. 在 `impl.Model` 基础上写一个带 `lam` 的版本（继承或复制）；
3. 在可分数据上跑 `λ ∈ {0, 0.01, 0.1, 1, 10}`，报告 `‖w‖`、训练 BCE、测试 accuracy；
4. 解释：为什么 L2 能阻止"完全可分时权重发散"。

**验收标准**：`λ` 增大时 `‖w‖` 单调下降；训练 BCE 单调上升；accuracy 在合理范围内不崩
（本数据上应保持在 0.95 以上）。结论要提到"限制模型复杂度 / 等价于高斯先验"。

**提示**：梯度多一项 `λ·w`；这也叫 weight decay。

## 第 5 题（迁移）按业务代价选阈值

**目标**：能力 5——把概率模型接到"代价不对称"的业务上。

**要求**：

1. 用 `demo.make_imbalanced()` 的数据训练一个模型，取测试集概率；
2. 设 **漏判（FN）代价 20、误判（FP）代价 1**，定义总代价 `20·FN + 1·FP`；
3. 在阈值 `0.05 … 0.95` 上扫描，打印代价表，选出代价最低的阈值；
4. 回答：最优阈值与 0.5 差多少？如果 FN 代价改成 2，阈值会往哪边移？

**验收标准**：最优阈值明显低于 0.5；该阈值下的总代价低于默认 0.5；
能解释"代价比 = 阈值该往哪边偏"。

**提示**：代价最低点通常出现在召回较高的一侧；`FN` 越贵，阈值越低。

**2026-10-21 复跑（uv 环境，Python 3.13.15 / numpy 2.5.4）观察结果**：

- `sol-03`（三个 bug）：A 用 `z−y` 后 BCE 0.4938 → 0.6701、accuracy 0.7667 → 0.5067；
  B 前 5 轮 BCE 0.6931 → 0.9376 单调上升；C 把阈值套在 logit 上，`threshold=0.5` 时判正比例
  0.453 → 0.350（系统性偏负），`threshold=0.9` 时反而 0.070 → 0.243。
- `sol-04`（L2）：λ = 0 / 0.01 / 0.1 / 1 / 10 时 `‖w‖` 5.0993 → 3.1169 → 1.3342 → 0.3039 → 0.0366，
  训练 BCE 0.2465 → 0.6792；λ ≤ 1 时测试 accuracy 保持 0.9000，λ=10 掉到 0.6100（欠拟合）。
- `sol-05`（代价阈值）：测试集 1200、正类 8%、AUC 0.9189；FN:FP=20:1 时最优阈值 **0.04**、
  代价 409（默认 0.5 是 1181）；FN:FP=2:1 时最优阈值右移到 **0.30**、代价 126（默认 137）。
