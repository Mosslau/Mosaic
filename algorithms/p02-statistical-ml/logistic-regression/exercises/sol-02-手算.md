# 参考解：第 2 题（走通）

数据 `x = [1, 2, 3]`、`y = [0, 1, 1]`，`w = b = 0`，`lr = 0.5`。

| 步骤 | z | p = σ(z) | BCE | grad_w | grad_b | 更新后 w | 更新后 b |
|---|---|---|---|---|---|---|---|
| 1 | [0, 0, 0] | [0.5000, 0.5000, 0.5000] | 0.6931 | −0.6667 | −0.1667 | 0.3333 | 0.0833 |
| 2 | [0.4167, 0.7500, 1.0833] | [0.6027, 0.6792, 0.7471] | 0.5338 | −0.2659 | 0.0097 | 0.4663 | 0.0785 |

**逐格核对**（第 1 步）：

- `grad_w = mean((p−y)·x) = [(0.5−0)·1 + (0.5−1)·2 + (0.5−1)·3] / 3 = (0.5 − 1 − 1.5)/3 = −0.6667`
- `grad_b = mean(p−y) = (0.5 − 0.5 − 0.5)/3 = −0.1667`
- `w = 0 − 0.5×(−0.6667) = 0.3333`，`b = 0 − 0.5×(−0.1667) = 0.0833`

第 2 步先算新的 `z = w·x + b`，再 `p = σ(z)`，重复同一套公式。
**关键**：梯度里的 `p` 是 sigmoid 之后的概率，不是 `z`。
