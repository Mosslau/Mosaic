# 参考解：第 5 题（迁移）——按业务代价选阈值

**为什么不能默认 0.5**：0.5 等价于"FN 与 FP 代价相同、且正负先验各半"。风控/转化/故障预警里，
这两条几乎都不成立。

**做法**：对每个阈值 `t` 算混淆矩阵，再按业务代价求总成本：

$$\text{cost}(t) = C_{FN}\cdot FN(t) + C_{FP}\cdot FP(t)$$

选使 `cost(t)` 最小的 `t`。阈值越低，召回越高、FN 越少，但 FP 越多——最优点由代价比决定。

**直觉**：`C_FN / C_FP` 越大（漏判越贵），最优阈值越往左（越低）。
本实验里 `C_FN = 20, C_FP = 1`，所以最优点会明显低于 0.5；把 `C_FN` 改成 2 时，
它应该往右移、靠近 0.5。

运行 `uv run python sol-05-代价阈值.py` 可以看到代价表与两个代价比下的最优阈值。
