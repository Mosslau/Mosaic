# 参考解：第 3 题（判断）

三个变体都能跑完，但症状不同：

| 变体 | 会不会收敛 | 症状 | 诊断方法 |
|---|---|---|---|
| A：梯度用 `z−y` | 慢/停在错误位置 | loss 下降但明显高于正确版；预测概率整体偏平 | 对比 loss 曲线与最终 BCE |
| B：更新取加号 | 不会 | loss 单调上升，几轮内溢出 | 打印前几轮 loss；断言单调不增 |
| C：`z >= threshold` | 训练没问题 | 训练正常、预测系统性偏负（阈值被搬到 logit 上） | 打印 `z` 与 `p` 的分位数、预测为正的比例 |

**为什么 C 错**：阈值 0.5 对应的 logit 是 `z=0`，不是 `z=0.5`。
`z >= 0.5` 实际等价于 `p >= σ(0.5) ≈ 0.622`，等于偷偷把阈值调高了。
若用 `z >= 0.9`，等价于 `p >= 0.71`——完全不是用户以为的 0.9。

运行 `uv run python sol-03-诊断.py` 可以看到三种症状与数值。
