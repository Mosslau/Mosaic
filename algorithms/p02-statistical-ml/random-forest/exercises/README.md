## 第 1 题（说清）Bagging 与随机森林

**目标**：能力 1——复述随机性的两个来源与 OOB。

**要求**：不看文档，写出：

1. bootstrap 怎么做、为什么约 36.8% 样本未入袋；
2. 随机森林比普通 bagging 多了什么随机性；
3. OOB 精度怎么算，为什么它"免费"。

**验收标准**：能写出 `(1−1/n)^n≈e^{-1}`；提到"每次划分随机选特征"；
第 3 问提到"只用没见过该样本的树投票"。

**提示**：想想"一群专家随机看材料"。

## 第 2 题（走通）bootstrap 与 OOB 投票

**目标**：能力 2——手算 OOB 集合与投票。

**要求**：`n=6`，某棵树的 bootstrap 下标是 `[0,0,2,4,4,5]`：

1. 写出入袋样本集合与 OOB 样本集合；
2. 三棵树对 OOB 样本 1 的预测是 `[1,0,0]`，真实标签 `0`，算概率平均与最终预测；
3. 样本 3 在 OOB 里只出现 1 次（预测 1，真实 1），样本 1 判对/判错？

**验收标准**：OOB 集合 `{1,3}`；样本 1 概率 `(1+0+0)/3=0.333` → 预测 0 → 判对；
样本 3 单独看，OOB 判对。

**提示**：概率平均后 argmax，不是硬投票。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从 OOB/相关性反推错误。

**要求**：三个变体都能跑：

- **A**：bootstrap 用"无放回抽样"（每个样本只出现一次）；
- **B**：特征随机只在建树前选一次子集，之后每次划分都用这同一子集；
- **C**：OOB 投票时把所有树都算进去（包括见过该样本的树）。

分别回答：会有什么症状？用诊断代码确认。

**验收标准**：A 的 OOB mask 全为空/极少；B 的树间预测分歧明显更小（相关性更高）；
C 的"OOB"精度接近训练精度、明显高于真实 OOB。

**提示**：A 看 `_oob_masks`；B 数两两分歧；C 比较"全树平均"与正确 OOB。

## 第 4 题（实现）置换重要性

**目标**：能力 4——用置换重要性交叉检查不纯度重要性。

**要求**：

1. 在 `p=12`、4 个真特征的数据上训练 100 棵树；
2. 对每个特征：在测试集上随机打乱该列，测准确率下降；重复 5 次取均值；
3. 比较置换重要性与 `feature_importances_` 的排序；
4. 说明为什么相关特征会让两种重要性都"分摊"。

**验收标准**：真特征的置换下降明显大于噪声；两种重要性的前 4 名高度重合；
结论提到"相关特征会分摊重要性"。

**提示**：置换一个特征、其他不变；准确率下降越大越重要。

## 第 5 题（迁移）用 OOB 选树数

**目标**：能力 5——用 OOB 曲线决定"多少棵树够了"。

**要求**：

1. 在 moons 数据上取 `n_trees ∈ {5,10,25,50,100,200}`；
2. 记录 OOB 精度与测试精度；
3. 选"OOB 达到最大值 0.005 以内的最小树数"；
4. 比较该树数与 200 棵的测试精度，解释为什么可以提前停。

**验收标准**：选出的树数 ≤100；其测试精度与 200 棵相差 ≤0.03；
结论提到"OOB 饱和后继续加树收益很小"。

**提示**：OOB 曲线通常比测试曲线更平滑，适合做"够用就好"的决策。
