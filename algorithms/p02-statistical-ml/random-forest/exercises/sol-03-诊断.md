# 参考解：第 3 题（判断）

| 变体 | 症状 | 诊断 |
|---|---|---|
| A：无放回 | 每个样本恰好入袋一次 → OOB 为空；所有树看到同一批数据，集成退化成"重复同一棵树" | 打印 `_oob_masks` 的平均非零比例，应为 0 |
| B：特征子集只在建树前选一次 | 树之间仍高度相关（都围绕同一小撮特征），分歧下降、收益变小 | 脚本用 `max_features=None` **近似**"每棵树固定用全部特征"，分歧明显小于逐划分随机 |
| C：OOB 用所有树 | "OOB"包含见过该样本的树，精度接近训练精度，明显高于真实 OOB | 对比"全树平均训练精度"、正确 OOB、测试精度 |

**根因**：A 破坏了"有放回"；B 把"每次划分随机"降级成"每棵树随机"；
C 混淆了"未入袋"的定义。

运行 `uv run python sol-03-诊断.py` 看具体数字。
