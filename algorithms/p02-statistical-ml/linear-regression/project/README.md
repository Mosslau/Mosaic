# 迁移项目：多特征房价 —— 标准化 + 特征选择 + 正则对照

## 需求

把线性回归/梯度下降用到"接近真实"的表格数据上。与教学示例（`y = 3x + 2`）的差别是三个**新约束**：

1. **6 个特征、尺度差 3 个数量级**：面积 50–200、房龄 0–50、距地铁 1–30、楼层 1–30；
2. **混入一个纯噪声特征**：用来检验"学到的系数能不能识别无效特征"；
3. **不做内部标准化**：直接拿原始尺度训练会怎样，要能量化出来。

数据为合成（`n = 800`，`seed = 0`），真实规律：

```
y = 0.8·面积 + 12·房间数 − 0.6·房龄 − 1.5·距地铁 + 0.4·楼层 + 0·噪声 + 40 + N(0, 8)
```

## 功能清单

- [x] 原始尺度 + `lr = 0.01` 的 GD：复现"发散"
- [x] 标准化后的手写 GD，与闭式解 / sklearn 对比
- [x] 换回原始尺度的系数，与真实系数对照
- [x] 按标准化系数排重要性，识别噪声特征
- [x] 去掉噪声特征后重训，比较测试 MSE
- [x] 手写 Ridge（λ=0.01）与闭式解对照

## 验收标准

1. 标准化 GD 与闭式解的测试 MSE 相差 **≤ 1%**；
2. 不标准化 + `lr = 0.01` 必须**发散**（loss 非有限）；
3. **面积**是标准化重要性第一；
4. 噪声特征的标准化权重 **|w| < 1.5**；
5. 去掉噪声特征后测试 MSE **基本不变（≤ 1%）**。

脚本 `housing_gd.py` 内逐条断言，任一不满足直接报错。

## 运行方式

```bash
cd algorithms/p02-statistical-ml/linear-regression/project
uv run python housing_gd.py
```

依赖：numpy + scikit-learn（`uv sync --extra dev` 已含）。

## 实测结果（已验证）

环境：uv（Python 3.13.15 / numpy 2.5.4 / scikit-learn 1.9.1），`seed = 0`，70/30 切分。

| 方法 | 训练 MSE | 测试 MSE |
|---|---|---|
| 手写 GD（不标准化，lr=0.01） | NaN | NaN（发散） |
| 手写 GD（标准化，lr=0.05） | 64.0373 | **58.7583** |
| 闭式解（手写） | 64.0373 | **58.7583** |
| sklearn `LinearRegression` | 64.0373 | **58.7583** |
| Ridge（手写，λ=0.01） | 64.2050 | 58.4824 |
| 去掉噪声特征后重训 | 64.2011 | 59.2088 |

**学到的系数（换回原始尺度）**：

| 特征 | 真实 | 学到 |
|---|---|---|
| 面积 | 0.80 | 0.80 |
| 房间数 | 12.00 | 12.19 |
| 房龄 | −0.60 | −0.64 |
| 距地铁(km) | −1.50 | −1.49 |
| 楼层 | 0.40 | 0.42 |
| 噪声特征 | 0.00 | 0.41 |

标准化重要性排序：**面积 > 房间数 > 距地铁 > 房龄 > 楼层 > 噪声特征**。

**结论**：

1. **标准化不是可选项**：同一个 `lr = 0.01`，原始尺度直接 NaN；标准化后 GD 与闭式解逐位一致。
2. **系数能识别无效特征**：噪声特征的标准化权重只有 0.41（远小于面积/房间数），去掉它测试误差基本不变。
3. **Ridge 的收益很小**：`n = 800`、信噪比不低，λ=0.01 只带来 0.3 的测试 MSE 改善——
   正则化在"小样本 / 高维 / 强共线"时才明显，这正好衔接下一个实验。

## 扩展方向

- 把"去掉噪声特征"换成**前向选择 / L1**，比较三种特征选择策略；
- 加一个强相关特征（面积 ≈ 房间数×30），观察系数不稳定与 Ridge 的稳定作用；
- 用真实数据集（如 sklearn 的 diabetes）替换合成数据，验证结论是否仍然成立；
- 把标准化换成"训练集统计量"，检查是否发生数据泄漏。
