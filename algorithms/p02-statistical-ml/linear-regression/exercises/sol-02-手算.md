# 参考解：第 2 题（走通）

数据 `x = [0, 1, 2]`、`y = [1, 3, 5]`，`w = b = 0`，`lr = 0.1`。

| 步骤 | 预测 ŷ | 误差 err | MSE | grad_w | grad_b | 更新后 w | 更新后 b |
|---|---|---|---|---|---|---|---|
| 1 | [0, 0, 0] | [−1, −3, −5] | 11.6667 | −8.6667 | −6.0000 | 0.8667 | 0.6000 |
| 2 | [0.6000, 1.4667, 2.3333] | [−0.4000, −1.5333, −2.6667] | 3.2074 | −4.5778 | −3.0667 | 1.3244 | 0.9067 |
| 3（验算） | [0.9067, 2.2311, 3.5556] | [−0.0933, −0.7689, −1.4444] | 0.8954 | −2.4385 | −1.5378 | 1.5683 | 1.0604 |

**逐格核对**（第 1 步）：

- `grad_w = 2/3 · (0·(−1) + 1·(−3) + 2·(−5)) = 2/3 · (−13) = −8.6667`
- `grad_b = 2/3 · (−1 − 3 − 5) = 2/3 · (−9) = −6.0000`
- `w = 0 − 0.1·(−8.6667) = 0.8667`，`b = 0 − 0.1·(−6) = 0.6000`
- 新预测：`0.8667·[0,1,2] + 0.6 = [0.6, 1.4667, 2.3333]`

**观察**：MSE 从 11.6667 → 3.2074 → 0.8954，单调下降；参数朝真值 `w=2, b=1` 靠近。
这组数字与 `demo.py` 的「手算示例」是同一套口径（那里用的是 3 个点、`lr=0.1` 的另一组数据），
也可以直接用 `impl.Model` 跑出来核对。
