# 参考解：第 5 题（迁移）——用线性回归拟合曲线

关键点：**"线性"指对参数线性，不是对输入线性**。把 `x` 扩展成 `[x, x²]` 后，
模型仍是 `w₁x + w₂x² + b`，对 `(w₁, w₂, b)` 依然是线性的，所以 `impl.Model` 原样可用。

```python
def poly_features(x, degree):
    return np.column_stack([x ** k for k in range(1, degree + 1)])
```

**结果**（`sol-05-多项式.py` 实跑）：

| 次数 | 训练 MSE | 测试 MSE | 说明 |
|---|---|---|---|
| 1 | 较高 | 较高 | 欠拟合：用直线拟合抛物线 |
| 2 | 低 | **最低** | 正好匹配数据的真实结构 |
| 9 | **最低** | 最高 | 过拟合：把噪声也拟合进去了 |

**为什么会过拟合**：9 次多项式有 10 个参数，足以穿过训练集的每个点；它在训练集上的误差可以趋近 0，
但学到的是"这批噪声的形状"，换一批数据就崩。高次项还会让 `XᵀX` 的条件数变差，所以更要标准化。

**结论**：特征扩展是"用线性模型做非线性拟合"的标准手段，但**模型复杂度要由验证集来选**，
不能只看训练误差——这正是下一个实验（正则化与模型选择）的主题。
