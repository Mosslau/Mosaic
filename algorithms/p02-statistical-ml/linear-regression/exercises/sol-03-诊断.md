# 参考解：第 3 题（判断）

三个变体都能跑完，但症状完全不同：

| 变体 | 会不会收敛 | 症状 | 诊断方法 |
|---|---|---|---|
| A：少乘 2 | 会，但更慢 | 最终参数正确；达到同一 `tol` 需要约 2 倍轮数（等价于 `lr` 减半） | 打印 `epochs_run` 与 loss 曲线，和正确版对比 |
| B：更新取加号 | 不会 | loss 单调上升，几轮内溢出成 inf/NaN | 打印前 5 轮 loss；或断言 `loss` 单调不增 |
| C：不标准化 + 尺度差 1000 倍 | 不会 | 同一个 `lr` 下，大尺度特征把步长放大到失控；标准化后立即正常 | 打印 `X.std(axis=0)`；对比标准化前后的 loss 首值 |

**为什么 A 只是慢**：`1/n` 与 `2/n` 只差一个常数因子，等价于把学习率乘了 0.5；
梯度的零点没变，所以最终解不变。

**为什么 B 一定炸**：`w ← w + lr·∇L` 是"沿上坡走"，二次函数上每步都放大误差，
`|1 + lr·λ| > 1`，必然发散。

**为什么 C 不是"慢一点"**：特征尺度决定 Hessian 的特征值；`λ_max` 随大尺度特征平方增长，
稳定上界 `2/λ_max` 变得极小。`lr = 0.01` 在标准化空间里安全，在原始空间里远超上界。

运行 `uv run python sol-03-诊断.py` 可以看到三种症状的实际输出。
