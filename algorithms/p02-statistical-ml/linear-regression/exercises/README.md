## 第 1 题（说清）三条规则，用自己的话讲

**目标**：能力 1——能复述核心概念与更新规则。

**要求**：不看文档，写出：

1. 模型、损失、梯度、学习率各是什么（各一句话）；
2. 参数更新为什么是"减"梯度，而不是"加"；
3. 训练在什么情况下停。

**验收标准**：四条定义都能落到公式或代码变量；第 2 问提到"梯度指向上坡"；
第 3 问至少说出"loss 变化小于 tol"与"到达 epochs"两种情况。

**提示**：想想下山——你往哪个方向迈步？

## 第 2 题（走通）三个点、两步手算

**目标**：能力 2——不靠电脑走通一次更新。

**要求**：数据 `x = [0, 1, 2]`、`y = [1, 3, 5]`；初始化 `w = 0`、`b = 0`，学习率 `lr = 0.1`。
填一张逐步表：每一步的预测、误差、MSE、`grad_w`、`grad_b`、更新后的 `w/b`。**走两步**。

**验收标准**：第一步 `grad_w = −8.6667`、`grad_b = −6`，更新后 `w = 0.8667`、`b = 0.6`；
第二步结束后 `w ≈ 1.3244`、`b ≈ 0.9067`；MSE 单调下降。

**提示**：`grad_w = 2/n · Σ xᵢ·errᵢ`，`grad_b = 2/n · Σ errᵢ`，别忘了 `2/n`。

## 第 3 题（判断）三个"看起来能跑"的实现

**目标**：能力 3——从症状反推错误原因。

**要求**：下面三个实现都能跑完不报错，但只有一个是对的：

- **A**：`grad_w = (1/n) * X.T @ err`（少了因子 2），其余同正确版；
- **B**：`w = w + lr * grad_w`（更新方向写反）；
- **C**：正确公式，但在一份"特征尺度差 1000 倍"的数据上**不做标准化**、`lr = 0.01`。

分别回答：它会不会收敛？症状是什么（loss 曲线形状 / 最终参数）？怎么用一行诊断代码确认？

**验收标准**：A 能收敛但更慢（等价于把学习率减半）；B 的 loss 单调上升/溢出；
C 在不标准化时发散、标准化后正常。诊断代码要能打印前几轮 loss 或参数。

**提示**：A 的固定点没变，只是有效步长变了；B 看更新符号；C 看特征标准差。

## 第 4 题（实现）给梯度下降加 L2 正则

**目标**：能力 4——在新约束下改实现，并与闭式解对拍。

**要求**：

1. 目标函数改为 `(1/n)‖Xw + b − y‖² + λ‖w‖²`（**不惩罚 b**）；
2. 在 `impl.Model` 的基础上写一个带 `lam` 参数的版本（可以继承或复制）；
3. 与岭回归闭式解 `w = (XᵀX + nλI)⁻¹Xᵀy` 对比（`b` 用中心化处理或增广矩阵）；
4. 报告 `λ ∈ {0, 0.1, 1, 10}` 时 `‖w‖` 与测试 MSE 的变化趋势。

**验收标准**：同一 `λ` 下，GD 版与闭式解的 `w` 相差 < 1e-4；`λ` 增大时 `‖w‖` 单调下降；
训练 MSE 单调上升（偏差换方差）。

**提示**：梯度多一项 `2λw`；闭式解里惩罚项要乘 `n`（因为损失是 mean 而不是 sum）。

## 第 5 题（迁移）用线性回归拟合曲线

**目标**：能力 5——把"线性模型"用到非线性数据上。

**要求**：

1. 生成 `y = 0.5x² − x + 2 + 噪声`（`x ∈ [−3, 3]`，固定种子）；
2. 用特征扩展 `[x] → [x, x²]`，仍用**线性回归**的 `fit/predict` 拟合；
3. 对比 1 次、2 次、9 次多项式（`[x]`、`[x, x²]`、`[x, …, x⁹]`）的训练/测试 MSE；
4. 解释为什么"9 次多项式训练误差更低、测试误差更高"。

**验收标准**：2 次的测试 MSE 明显低于 1 次；9 次的训练 MSE 最低但测试 MSE 最差；
结论里出现"过拟合"与"特征扩展仍是线性模型（对参数线性）"这两点。

**提示**：对参数线性 ≠ 对输入线性；高次项会让 `XᵀX` 条件数变差，记得标准化。
