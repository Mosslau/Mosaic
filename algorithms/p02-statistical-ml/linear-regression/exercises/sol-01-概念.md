# 参考解：第 1 题（说清）

**1. 四个量**

- 模型：`ŷ = Xw + b`，用特征的线性组合预测标签。
- 损失：`MSE = (1/n) Σ(ŷᵢ − yᵢ)²`，衡量整条线偏离数据多少。
- 梯度：`∂L/∂w = (2/n) Xᵀ(ŷ − y)`、`∂L/∂b = (2/n) Σ(ŷ − y)`，指向 loss **上升最快**的方向。
- 学习率：每一步沿负梯度走多远，`w ← w − lr·∂L/∂w`。

**2. 为什么是"减"**

梯度指向函数值增大的方向。我们要让 loss 变小，所以朝反方向走；取负号等价于"下坡"。

**3. 什么时候停**

- 相邻两轮 loss 变化小于 `tol`（已收敛）；
- 到达 `epochs`（预算用完）；
- 数值溢出（学习率过大，属于失败停止，不是收敛）。

对应 `impl.py` 的循环条件：`if abs(prev - loss) < self.tol: break`，外层 `for _ in range(self.epochs)`。
